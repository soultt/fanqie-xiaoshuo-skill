# 修复技能调用映射表

> **说明**：本文档包含审查发现问题时的修复技能调用映射关系。

---

## 核心原则

**执行要求（强制）**：审查技能只负责发现问题，修复必须调用对应技能完成，不得自行修改。

---

## 修复技能映射表

| 审查节点 | 发现问题类型 | 调用修复技能 | 修复方式 |
|---------|-------------|-------------|---------|
| 节点0：优先审查 | 前后章节冲突（人物/时间/地点/物品） | `novel-chapter-writer` | 重新调用写作技能，传入冲突修复指令 |
| 节点0：字数不足 | 正文<2100非空白字符 | `novel-chapter-writer` | 重新调用写作技能，传入扩写指令 |
| 节点1：章纲符合性 | 正文偏离章纲 | `novel-chapter-writer` | 重新调用写作技能，传入章纲约束清单 |
| 节点2：章节连贯性 | 开头不承接/状态不一致 | `novel-chapter-writer` | 重新调用写作技能，传入前章约束清单 |
| 节点3：人设一致性 | 人设走偏/行为不符 | `novel-chapter-writer` | 重新调用写作技能，传入人物设定 |
| 节点4：结构符合性（含禁止词汇检查和AI味检查） | 四部分结构缺失/失衡/禁止词汇/AI味 | `novel-chapter-writer` | 重新调用写作技能，传入结构修正、禁止词汇替换或去AI化指令 |
| 节点5：内容质量 | 对话不自然/情感空洞 | `novel-chapter-writer` | 重新调用写作技能，传入质量修正指令 |
| 节点6：文笔规范 | 段落过长/信息密度低 | `novel-chapter-writer` | 重新调用写作技能，传入文笔修正指令 |

---

## 修复调用流程

```
审查发现问题
    │
    ▼
判断问题严重程度
    │
    ├── 阻塞问题（严重冲突/字数不足）
    │     │
    │     ▼
    │   调用 novel-chapter-writer 修复
    │     ├── 传入：本章章纲 + 约束清单 + 问题描述
    │     ├── 传入：修复指令（如"修复人物状态冲突"）
    │     └── 输出：修复后的正文
    │     │
    │     ▼
    │   重新执行审查（从节点0开始）
    │
    └── 🟡 警告问题（质量/文笔）
          │
          ▼
        记录问题到审查报告
        ├── 修复建议：调用 novel-chapter-writer 处理
        └── 继续后续审查节点
```

## 修复调用示例

### 示例1：字数不足

```
问题：正文非空白字符1850，缺口250字符
修复技能：novel-chapter-writer
修复指令：
  - 读取本章约束清单：08-约束清单/章纲约束/第X卷/第XXX章-约束清单.md
  - 在"剧情发展"和"情绪高潮"部分各扩写125字符
  - 保持对话占比≥60%
  - 扩写后重新验证字数≥2100
```

### 示例2：人物状态冲突

```
问题：主角本章开头伤势已愈，但前章结尾重伤未愈
修复技能：novel-chapter-writer
修复指令：
  - 读取前章约束清单：08-约束清单/正文约束/第X卷/第XXX-1章-约束清单.md
  - 提取前章结尾人物状态
  - 修改本章开头，使人物状态与前章一致
  - 重新验证优先审查节点0
```

### 示例3：AI味过重

```
问题：开头堆砌专业名词，对话书面化，结尾强加心理描写
修复技能：novel-chapter-writer
修复指令：
  - 执行去AI化六步法
  - 第一步：删除开头专业名词堆砌
  - 第四步：对话改为口语化
  - 第五步：结尾用行为替代心理描写
  - 重新验证节点4（结构符合性，含禁止词汇检查和AI味检查）
```

---

## 修复后重新审查

**修复完成后，必须重新执行完整审查流程**：

1. 调用修复技能完成修复
2. 从节点0（优先审查）重新开始
3. 逐项勾选确认清单
4. 全部通过后输出审查报告
