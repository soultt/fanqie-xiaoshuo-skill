## 一、字数标准

### 1.1 每章字数
- **正文目标**：≥2100非空白字符
- **字数达标率**：≥98%
- **字数过多阈值**：>3000字符建议精简

### 1.2 四部分结构字数分配

| 部分 | 标准值 | 范围 |
|------|--------|------|
| 开头钩子 | 约250字符 | 200-300字符 |
| 剧情发展 | 约650字符 | 600-700字符 |
| 情绪高潮 | 约600字符 | 500-700字符 |
| 章节卡点 | 约400字符 | 350-450字符 |

### 1.3 字数统计规则
```python
non_space_chars = len([c for c in content if not c.isspace()])
# 包含：汉字、标点符号、英文字母、数字、特殊符号等所有非空白字符
# 不包含：空格、换行符、制表符等空白字符
```

**统计范围**：仅统计正文内容区域，不包含头部注释（## 文件信息等）和尾部注释（## 写作备注等）。

### 1.4 扩写优先级指南

| 非空白字符数 | 缺字程度 | 处理策略 | 扩写重点 |
| ------------ | -------- | -------- | -------- |
| 1800-2099字符 | 轻微不足 | 轻微扩写 | 增加细节描写、对话氛围 |
| 1500-1799字符 | 中度不足 | 中度扩写 | 补充场景、强化情绪、增加对话 |
| 1200-1499字符 | 重度不足 | 重度扩写 | 增加剧情支线、扩展对话、强化描写 |
| <1200字符 | 严重不足 | 需要重写 | 检查是否遗漏关键情节 |

## 二、对话与段落规范

| 标准项 | 标准值 |
|--------|--------|
| 对话占比 | ≥60%（正文对话字符/正文总非空白字符） |
| 每段对话上限 | 不超过150非空白字符 |
| 段落长度 | 每段≤3行（适合手机阅读） |
| 对话轮次限制 | 对话不超过5轮不推进剧情 |
| 纯描写限制 | 避免连续3段以上纯心理描写或背景交代 |

## 三、禁止词汇完整列表

> **以下词汇禁止出现在正文内容中**（仅允许在文件元数据、约束清单、审查报告中出现）

### 3.1 卷/部结构词

**模式匹配：第X卷、卷X、第X部**（X为任意数字）

**模式匹配：卷末XX、卷首XX**（XX为任意词，示例：卷末收尾、卷末之战、卷末完结、卷首要事）

章节前、章节后、卷前、卷后

第一部曲、第一部、第二部、篇、章回

### 3.2 章节导航词

下一章、上一章、前一章、后一章

本章、下章、上章、前章、章节回顾

### 3.3 高潮/转折导航词

卷末高潮、本卷高潮、全书高潮

高潮来临、即将高潮、马上高潮

### 3.4 规划性词汇

这里应该、作者安排、剧情需要

伏笔回收、埋下伏笔、回扣上文

**模式匹配：伏笔N回收、伏笔N、回收N**（N为任意数字/中文数字）

**模式匹配：爽点N、卡点N、高潮N、铺垫N、转折N、情节N、冲突N、事件N**（N为任意数字/中文数字）

### 3.5 时序导航词

时间线、故事线、情节线

### 3.6 正确表达示例

| 禁止写法 | 正确写法 |

## 五、AI味特征识别

### 5.1 AI味特征清单

| 特征类别 | 具体表现 | 检测风险 |
|---------|---------|---------|
| 人物关系混乱 | 前后矛盾、性格突变、关系错乱 | 高 |
| 修饰过度 | 堆砌形容词、不推进情节 | 高 |
| 乱加戏 | 无关情节、人设走偏 | 高 |
| 时间感缺失 | 缺乏时间推移、场景跳跃突兀 | 高 |
| 结尾强加心理 | 莫名其妙的心理描写、情绪转折生硬 | 高 |
| 开头堆数字 | 精密数字、专业名词堆砌 | 高 |
| 对话不自然 | 过于书面化、缺乏口语特征 | 中 |
| 情节套路化 | 固定模板、缺乏创新 | 中 |
| 情感表达空洞 | 形容词堆砌、无具体行为支撑 | 中 |

### 5.2 去AI化核心原则

| 原则 | 说明 |
|------|------|
| 增加具体细节 | 用具体动作、场景替代抽象描述 |
| 强化人物个性 | 给角色添加独特口癖、习惯动作 |
| 打破完美节奏 | 适当加入意外、停顿、打断 |
| 注入情感波动 | 情绪变化要有层次，不要一步到位 |
| 添加时间标记 | 明确时间流逝、场景转换 |
| 口语化处理 | 对话要口语化，避免书面语 |

### 5.3 AI味检查表

| AI味特征 | 检查内容 | 结果 |
|---------|---------|------|
| 人物关系混乱 | 人物性格是否前后一致？关系是否清晰？ | □ 一致 □ 混乱 |
| 修饰过度 | 是否存在3个以上连续形容词堆砌？ | □ 无 □ 有 |
| 乱加戏 | 是否有偏离章纲的无关情节？ | □ 无 □ 有 |
| 时间感缺失 | 时间推移是否有明确标记？ | □ 有标记 □ 缺失 |
| 结尾强加心理 | 结尾是否有莫名其妙的心理描写？ | □ 无 □ 有 |
| 开头堆数字 | 开头是否有精密数字/专业名词堆砌？ | □ 无 □ 有 |
| 对话不自然 | 对话是否口语化？有无书面语？ | □ 口语化 □ 书面语 |
| 情感表达空洞 | 情感是否用行为体现？有无形容词堆砌？ | □ 行为体现 □ 空洞 |

## 七、审查层级标准

| 层级 | 名称 | 优先级 | 说明 |
|------|------|--------|------|
| 优先审查 | 前后章节冲突+字数符合性 | P0-最高 | 必须在所有其他审查之前执行 |
| 一级审查 | 章纲符合性 | P1-高 | 含约束清单一致性作为子项 |
| 二级审查 | 章节连贯性 | P2-中 | 对话与节奏 |
| 三级审查 | 人设一致性 | P3-低 | 人物行为符合设定 |
| 四级审查 | 结构符合性 | P4-参考 | 含去AI化、大纲导航字眼检查 |
| 五级审查 | 内容质量 | P5-参考 | 描写生动性、信息密度 |
| 六级审查 | 文笔规范 | P6-参考 | 错别字、语病、标点 |
