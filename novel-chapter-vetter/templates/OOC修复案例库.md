# OOC修复案例库

> **用途**：提供常见OOC类型的具体修复示例
> **参考时机**：发现OOC后对照案例选择修复方案

---

## 案例1：性格OOC - 冷静角色突然冲动

> OOC量化评估的审查维度详见 [审查方法详解](./审查方法详解.md) 中的OOC审查章节

**症状**：
- 人设：主角性格冷静理智，不轻易动怒
- OOC表现：因一句嘲讽就大打出手，无任何铺垫

**严重程度**：4分（严重OOC）

**修复方案**：

方案A（推荐）：增加合理触发
```
原文：
"你算什么东西？"那人嘲讽道。
主角大怒，直接出手将其打飞。

修复后：
"你算什么东西？"那人嘲讽道，"就像你那个废物父亲一样。"
主角瞳孔骤缩，握剑的手青筋暴起。
那是他心中永远的痛——父亲为保护他而死，却被人如此侮辱。
"你找死。"
剑光一闪，那人已经飞了出去。
```

方案B：调整行为
```
主角眼神一冷，但随即恢复平静。
"口舌之争无益。"他淡淡道，"实力才是硬道理。"
说罢，他转身离去，留下那人愣在原地。
```

## 案例2：能力OOC - 等级跳跃

**症状**：
- 前章：主角处于境界A初期
- 本章：主角展现境界B实力，无任何突破过程

**严重程度**：5分（灾难级OOC）

**修复方案**：

必须补充突破过程：
```
前章结尾增加：
"必须突破了。"
主角咬牙，强行运转功法，冲击那道瓶颈。
...
（突破过程描写）

本章开头：
三天后，主角缓缓睁眼，眼中精光一闪。
境界B，成！
```

## 案例3：关系OOC - 关系发展过快

**症状**：
- 第10章：主角与女主刚认识
- 第15章：两人已山盟海誓

**严重程度**：3分（中度OOC）

**修复方案**：

方案A：增加感情铺垫
- 在第11-14章增加共同经历的事件
- 增加互相了解的过程
- 增加情感升温的细节

方案B：调整关系阶段
- 将"山盟海誓"改为"互有好感"
- 延后表白/承诺到更合适的章节

## 案例4：动机OOC - 反派行为无动机

**症状**：
- 反派突然帮助主角，但无任何利益驱动或性格转变过程

**严重程度**：4分（严重OOC）

**修复方案**：

补充动机：
```
原文：
反派突然出手，帮主角挡下了致命一击。

修复后：
反派突然出手，帮主角挡下了致命一击。
"别误会，"他冷冷道，"我只是需要他活着。那批货的下落只有他知道。"
主角心中一凛——原来如此，他早就有所图谋。
```

## 案例5：情绪OOC - 情绪反应过度

**症状**：
- 主角因小事暴怒或过度悲伤，与性格不符

**严重程度**：2分（轻微OOC）

**修复方案**：

调整情绪反应强度：
```
原文：
听到这个消息，主角悲痛欲绝，嚎啕大哭。

修复后：
听到这个消息，主角身形一晃，脸色瞬间苍白。
他张了张嘴，却发不出声音。
良久，他缓缓闭上眼，一滴泪从眼角滑落。
"我知道了。"
声音沙哑，却平静得可怕。
```

## 案例6：成长OOC - 成长轨迹断裂

**症状**：
- 前章主角还在学习隐忍
- 本章主角突然老谋深算，无成长过程

**严重程度**：3分（中度OOC）

**修复方案**：

补充成长过程：
- 增加挫折/教训事件
- 增加反思/顿悟场景
- 增加向他人学习的过程

## 快速修复决策树

```
发现OOC
    │
    ├── 性格OOC？
    │     ├── 是 → 增加合理触发 或 调整行为
    │     └── 否 →
    │
    ├── 能力OOC？
    │     ├── 是 → 补充获取/突破过程
    │     └── 否 →
    │
    ├── 关系OOC？
    │     ├── 是 → 增加铺垫 或 调整关系阶段
    │     └── 否 →
    │
    ├── 动机OOC？
    │     ├── 是 → 补充动机说明
    │     └── 否 →
    │
    └── 其他OOC
          └── 根据严重程度选择：重写/修复/观察
```
