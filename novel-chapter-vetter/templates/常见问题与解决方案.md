# 常见问题与解决方案

> **说明**：本文件包含 novel-chapter-vetter 技能审查过程中常见问题的诊断与解决方案。
> 主文件引用位置：`SKILL.md`

---

## 问题1：正文严重超前章纲

**症状**：

- 提前揭示了后续章节的关键信息
- 提前展现了后续才该有的能力
- 提前解决了后续才该解决的问题

**解决方案**：

1. 对照章纲（05-章纲/第X卷/第XXX章-xxx.md）和后续章纲
2. 删除超前内容
3. 改为埋下伏笔，不揭示真相
4. 或调整后续章纲（05-章纲/第X卷/第XXX+N章-xxx.md），提前安排揭示
5. 检查是否影响整体大纲（01-总纲/总纲.md）

---

## 问题2：正文严重超出章纲

**症状**：

- 写了章纲没有规划的情节
- 新增了章纲没有的人物
- 扩展了章纲没有的细节

**解决方案**：

1. 对照章纲（05-章纲/第X卷/第XXX章-xxx.md）
2. 评估新增内容是否必要
3. 若必要：补充到章纲，更新规划
4. 若不必要：删除或移至其他章节
5. 控制内容边界，避免发散

---

## 问题3：遗漏章纲要点

**症状**：

- 漏写了章纲要求的关键情节
- 漏写了章纲要求的对话
- 漏写了章纲要求的伏笔

**解决方案**：

1. 对照章纲（05-章纲/第X卷/第XXX章-xxx.md），找出所有遗漏点
2. 补充遗漏内容
3. 或评估章纲，删除不必要的要点
4. 建立章纲要点检查清单

---

## 问题4：字数分配失衡

**症状**：

- 某部分过长，某部分过短
- 总字数不符合要求
- 结构比例失调

**解决方案**：

1. 对照章纲字数分配（05-章纲/第X卷/第XXX章-xxx.md）
2. 压缩过长部分（删除冗余对话/描写）
3. 扩充过短部分（增加细节/心理/对话）
4. 调整结构，确保四部分完整
5. 控制总字数在2100-3000非空白字符

---

## 问题5：字数不足（正文非空白字符 < 2100字符）

**症状**：

- 正文非空白字符数低于2100字符标准（仅统计正文内容，不含头部/尾部注释）
- 内容过于精简，缺乏细节
- 情节发展过快，缺少铺垫
- 对话过于简短，缺少神态/动作描写

**解决方案**：

1. **统计字数缺口（仅正文非空白字符）**
   - 先提取正文内容（排除 ## 文件信息、## 写作备注 等注释部分）
   - 统计非空白字符：`len([c for c in body if not c.isspace()])`
   - 计算缺口：2100 - 实际正文非空白字符数 = \_\_\_\_字符
   - 分析各部分缺字情况
2. **确定扩写优先级**
   - 优先扩写发展部分（情节主体）
   - 优先扩写高潮部分（情绪渲染）
   - 其次扩写开头（环境铺垫）
   - 最后扩写卡点（悬念强化）
3. **选择扩写技巧**
   - **对话扩写**：增加神态、动作、心理反应
   - **场景扩写**：增加环境细节、五感描写
   - **情绪扩写**：增加内心独白、身体反应、环境烘托
   - **动作扩写**：分解动作、增加细节、增加效果
4. **按部分扩写（目标非空白字符数）**
   ```
   开头部分（目标250字符）：
   - 增加环境氛围描写
   - 增加人物状态描写
   - 增加时间/地点铺垫

   发展部分（目标650字符）：
   - 扩展对话，增加细节
   - 增加场景转换过渡
   - 增加人物心理活动

   高潮部分（目标600字符）：
   - 强化情绪渲染
   - 增加动作细节
   - 增加环境烘托

   卡点部分（目标400字符）：
   - 增加悬念氛围
   - 强化钩子效果
   - 增加人物反应
   ```
5. **扩写后检查**
   - 确认非空白字符数在2100-3000字符范围内
   - 检查各部分分配是否合理
   - 确保扩写内容不偏离章纲
   - 保持对话占比≥60%

## 问题5.5：字数过多（正文非空白字符 > 3000字符）

**症状**：

- 正文非空白字符数超过3000字符标准
- 内容冗余、节奏拖沓
- 修饰堆砌、对话冗长
- 心理描写过多、场景描写过度

**解决方案**：

1. **统计超出字数**
   - 统计非空白字符：`len([c for c in body if not c.isspace()])`
   - 计算超出：实际非空白字符数 - 3000 = \_\_\_\_字符
2. **确定精简优先级**
   - 优先精简冗余修饰和形容词堆砌
   - 优先精简与核心事件无关的次要描写
   - 其次压缩过度心理活动
   - 最后精简次要对话轮次
3. **按部分精简**
   - 开头：删除冗余场景铺垫，直接切入核心事件
   - 发展：合并重复对话，删除与核心事件无关的支线
   - 高潮：精简过度心理描写，用动作替代形容词堆砌
   - 卡点：删除过度铺垫，保持悬念精炼有力
4. **精简后检查**
   - 确认非空白字符数在2100-3000字符范围内
   - 确保精简后核心事件完整
   - 保持对话占比≥60%

## 问题6：约束清单与章纲矛盾

**现象**：约束清单中的约束条件与章纲内容存在冲突

**原因**：约束清单生成时未正确读取上游章纲或大纲变更后未同步更新约束清单

**解决方案**：
1. 读取上游章纲文件，确认最新内容
2. 对比约束清单与章纲，标记矛盾项
3. 以上游（章纲/大纲）为准，更新约束清单
4. 重新验证一致性

## 使用说明

**问题诊断流程**：
1. 根据审查报告中的问题类型，对照本文档找到对应问题
2. 按照解决方案步骤逐一执行
3. 执行完成后重新审查验证

**常见问题优先级**：
- 严重问题：超前章纲、超出章纲、遗漏章纲要点
- 中等问题：字数分配失衡
- 基础门槛：字数不足 / 字数过多
