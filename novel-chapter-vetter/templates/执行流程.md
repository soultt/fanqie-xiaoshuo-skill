## 阻塞式审查执行机制（强制）

**每个审查节点必须完成才能进入下一个节点，不可跳过任何步骤。**

### 执行规则（强制）

- **规则1**：必须按顺序执行，不可跳过任何审查节点
- **规则2**：每个节点必须输出检查结果（通过/问题/失败）
- **规则3**：优先审查发现严重冲突 --> 强制阻塞，必须修复后重查
- **规则4**：字数<2100非空白字符 --> 强制阻塞，必须扩写后重查
- **规则5**：每级审查完成后必须勾选确认，才能进入下一级
- **规则6**：最终报告必须包含所有7个审查节点（P0-P6）及报告生成的结果

### 审查节点完成确认清单

**每完成一个节点，必须勾选确认**：
- [ ] **节点0**：优先审查（前后章节冲突7项 + 字数符合性）已完成
- [ ] **节点1**：一级审查（章纲符合性 + 约束清单一致性）已完成
- [ ] **节点2**：二级审查（章节连贯性）已完成
- [ ] **节点3**：三级审查（人设一致性）已完成
- [ ] **节点4**：四级审查（结构符合性，含去AI化+大纲导航字眼）已完成
- [ ] **节点5**：五级审查（内容质量）已完成
- [ ] **节点6**：六级审查（文笔规范）已完成
- [ ] **节点7**：生成审查报告已完成

**未全部勾选 --> 审查报告不完整，不得输出**

### 阻塞触发条件

| 触发条件               | 阻塞级别 | 处理方式                         |
| ---------------------- | -------- | -------------------------------- |
| 优先审查发现严重冲突（P0） | 强制阻塞 | 立即停止，修复后从节点0重查 |
| 字数<2100非空白字符     | 强制阻塞 | 立即停止，扩写后从节点0重查 |
| 对话占比<60%           | 强制阻塞 | 立即停止，扩写对话后重查 |
| 章纲或正文约束清单不一致 | 强制阻塞 | 立即停止，修正后重查 |
| 核心事件与章纲不符     | 强制阻塞 | 立即停止，修正后重查 |
| 标题继承错误或存在重名/高度相似冲突 | 强制阻塞 | 立即停止，返回卷纲层修复后重查 |
| 其他审查发现严重问题     | 强制阻塞 | 立即停止，修复后重查 |
| 任何节点未执行         | 强制阻塞 | 补全后才能输出报告 |
| 发现问题未修复         | 强制阻塞 | 修复后才能继续 |

> **完整阻塞触发条件**：详见 [审查验证规范 - 阻塞触发条件](./审查验证规范.md#66-阻塞触发条件强制)

## 标准审查流程

### 开始审查前必须确认阻塞式机制已启用（强制）

- [ ] 我已阅读并理解阻塞式审查执行规则
- [ ] 我将按顺序执行所有审查节点，不跳过任何节点
- [ ] 每个节点完成后我将勾选确认清单
- [ ] 发现阻塞问题时我将立即停止，不输出不完整报告
- [ ] 最终报告将包含所有节点的审查结果

**未全部勾选确认 --> 不得开始审查**

### 步骤一：确认审查范围

- 确定审查对象：章节号、章纲文件、正文文件
- 确认审查依据是否齐全（章纲、章纲约束清单、正文约束清单、人物设定、前章正文）

**步骤完成确认**：[ ] 步骤一（确认审查范围）已完成

### 步骤二：读取审查依据

- 章纲：`05-章纲/NN-第X卷-卷名/第XXX章-章节标题.md`（对照依据）
- 正文：`06-正文/NN-第X卷-卷名/第XXX章-章节标题.md`（待审查）
- 人物设定：`03-人物设定/`（参考）
- 前章正文：`06-正文/NN-第X卷-卷名/第XXX-1章-xxx.md`（了解上文）
- 后续章纲：`05-章纲/NN-第X卷-卷名/第XXX+1章-xxx.md`（了解后续规划）
- **章纲约束清单：`08-约束清单/章纲约束/NN-第X卷-卷名/第XXX章-约束清单.md`**
- **正文约束清单：`08-约束清单/正文约束/NN-第X卷-卷名/第XXX章-约束清单.md`**（如为审查前章）

**步骤完成确认**：[ ] 步骤二（读取审查依据）已完成

### 步骤三：优先审查（前后章节冲突 + 字数符合性，P0-最高）

- 0.1 人物状态冲突检查
- 0.2 时间线冲突检查
- 0.3 地点空间冲突检查
- 0.4 物品道具冲突检查
- 0.5 人物关系冲突检查
- 0.6 前情逻辑冲突检查
- 0.7 能力设定冲突检查
- 0.8 字数符合性检查

**节点完成确认**：
- [ ] 节点0：优先审查已完成
- [ ] 字数达标（>=2100非空白字符）或已制定扩写方案
- [ ] 无严重冲突问题

**发现阻塞问题 --> 停止执行，调用 novel-chapter-writer 修复后重新审查**

### 步骤四：一级审查（章纲符合性 + 双约束清单一致性）

按检查清单逐项对比，记录所有偏差，评估严重程度。

- 1.1 内容边界检查
- 1.2 剧情一致性检查
- 1.3 人物行为检查
- 1.4 四部分结构检查
- 1.5 卡点符合性检查
- 1.6 爽点符合性检查
- 1.7 双约束清单一致性检查（章纲约束清单 + 正文约束清单 + 约束冲突处理）

**节点完成确认**：[ ] 节点1：一级审查（章纲符合性 + 双约束清单一致性）已完成

### 步骤五：二级审查（章节连贯性）

- 2.1 对话占比检查
- 2.2 段落规范检查
- 2.3 节奏检查

**节点完成确认**：[ ] 节点2：二级审查（章节连贯性）已完成

### 步骤六：三级审查（人设一致性）

- 3.1 人物行为一致性检查
- 3.2 人物对话风格检查
- 3.3 人物情绪反应检查

**节点完成确认**：[ ] 节点3：三级审查（人设一致性）已完成

### 步骤七：四级审查（结构符合性，含去AI化+大纲导航字眼）

- 4.1 标题继承与冲突检查
- 4.2 四部分结构完整性检查
- 4.3 去AI化检查（AI特征检查）
- 4.4 大纲导航类字眼检查

**节点完成确认**：[ ] 节点4：四级审查（结构符合性，含去AI化+大纲导航字眼）已完成

### 步骤八：五级审查（内容质量）

- 5.1 场景描写质量检查
- 5.2 信息密度检查
- 5.3 氛围营造检查

**节点完成确认**：[ ] 节点5：五级审查（内容质量）已完成

### 步骤九：六级审查（文笔规范）

- 6.1 错别字与语病检查
- 6.2 标点符号规范检查

**节点完成确认**：[ ] 节点6：六级审查（文笔规范）已完成

### 步骤十：生成审查报告

- 偏差汇总（按严重程度排序）
- 修改建议（具体可执行）
- 优先级排序（必须改 > 建议改 > 可选改）
- 保存报告：`07-审查报告/正文审查/第XXX章-审查报告.md`

> 人物状态追踪表参见 [人物状态追踪表](./人物状态追踪表.md)，建议每章正文完成后更新

> **最终确认（必须全部勾选才能输出报告）**
> - [ ] 无严重冲突问题（或已修复）
> - [ ] 字数达标（>=2100非空白字符）或已制定扩写方案
> - [ ] 偏差汇总已生成
> - [ ] 修改建议已制定
> - [ ] 优先级已排序
> - [ ] 报告已保存到指定位置

### 步骤十一：审查后正文约束清单同步

> **关键步骤**：如正文修改导致状态变化，必须同步更新正文约束清单。

- 如果正文修改了人物状态 --> 更新正文约束清单中的人物状态
- 如果正文修改了物品/装备 --> 更新正文约束清单中的物品记录
- 如果正文新增了遗留问题 --> 在正文约束清单中添加"下章注意"项
- 如果正文修改了场景/地点 --> 更新正文约束清单中的场景记录

## 偏离类型与处理

### 偏离严重程度分级

**严重偏离（必须修改）**：
- 超前章纲（提前暗示后续内容）
- 改变核心剧情走向
- 人物严重OOC
- 遗漏关键卡点/爽点
- 违反约束清单中的禁止事项

**中等偏离（建议修改）**：
- 超出章纲范围（新增不必要内容）
- 爽点类型不符
- 字数分配严重失衡
- 伏笔处理不当
- 违反约束清单中的建议事项

**轻微偏离（可选修改）**：
- 段落长度略长
- 对话占比略低
- 新增次要人物
- 细节描写有异

### 偏离处理决策树

```
发现偏离
    |
    +--> 是否影响后续章节？
    |       |
    |       +--> 是 --> 必须修改
    |       |       |
    |       |       +--> 修改正文回归章纲
    |       |   或调整后续章纲
    |       |
    |       +--> 否 --> 是否提升质量？
    |               |
    |               +--> 是 --> 保留，更新章纲
    |               |       将偏离内容补充到章纲
    |               |       更新 05-章纲/NN-第X卷-卷名/第XXX章-标题.md
    |               |
    |               +--> 否 --> 是否必要？
    |                       |
    |                       +--> 是 --> 保留
    |                       +--> 否 --> 删除
```
