## 一、优先审查方法（前后章节冲突）

### 0.1 人物状态冲突审查方法

```
对照文件：
- 前章正文：06-正文/第X卷/第XXX-1章-xxx.md
- 本章正文：06-正文/第X卷/第XXX章-xxx.md

审查步骤：
1. 提取前章结尾的人物状态：
   - 伤势：左臂骨折
   - 体力：几近枯竭
   - 情绪：愤怒但无奈
   - 装备：剑已断

2. 提取本章开头的人物状态：
   - 伤势：完好无损 ✗
   - 体力：充沛 ✗
   - 情绪：平静 ✓（有解释：想通了）
   - 装备：手持新剑 ✗

3. 对比分析：
   - 伤势冲突：前章骨折，本章完好 → 严重冲突
   - 体力冲突：前章枯竭，本章充沛 → 中等冲突
   - 装备冲突：前章断剑，本章新剑 → 中等冲突

4. 生成修复建议：
   - 方案A：本章开头补充"经过三天休养，伤势痊愈"
   - 方案B：本章保持伤势，影响战斗表现
   - 方案C：修改前章，减轻伤势程度
```

### 0.2 时间线冲突审查方法

```
对照文件：
- 前章正文：06-正文/第X卷/第XXX-1章-xxx.md
- 本章正文：06-正文/第X卷/第XXX章-xxx.md

审查步骤：
1. 提取前章结尾时间：
   - 具体时间：深夜子时
   - 相对时间：距离比赛还有一天
   - 事件进度：刚结束修炼

2. 提取本章开头时间：
   - 具体时间：傍晚酉时 ✗
   - 相对时间：比赛即将开始 ✓
   - 事件进度：前往赛场 ✓

3. 对比分析：
   - 时间倒流：深夜→傍晚 → 严重冲突
   - 建议：改为"次日清晨"或"天刚亮"

4. 时间线一致性检查表：
   | 章节 | 时间点 | 时长 | 事件 |
   |------|--------|------|------|
   | 第X-1章 | 深夜子时 | - | 修炼结束 |
   | 第X章 | ？ | ？ | ？ |
   | 第X+1章 | ？ | ？ | ？ |
```

### 0.3 地点空间冲突审查方法

```
对照文件：
- 前章正文：06-正文/第X卷/第XXX-1章-xxx.md
- 本章正文：06-正文/第X卷/第XXX章-xxx.md
- 世界观：04-世界观/地理设定.md（距离参考）

审查步骤：
1. 提取前章结尾地点：
   - 具体位置：城市A，地点A
   - 周围环境：窗外是繁华街道

2. 提取本章开头地点：
   - 具体位置：势力A，地点B ✗
   - 周围环境：群山环绕 ✗

3. 对比分析：
   - 地点跳跃：客栈→演武场 → 严重冲突
   - 距离问题：城市A到势力A需要三天路程

4. 修复建议：
   - 方案A：本章开头补充"三天后，抵达势力A"
   - 方案B：增加一章"前往势力A"的途中情节
   - 方案C：修改前章，提前出发
```

审查步骤：
1. 提取前章信息状态：
   - 已知信息：敌人是张三
   - 未知信息：张三的幕后主使

2. 提取本章信息状态：

   - 信息获取：李四是幕后主使 → 无获取过程
   - 目标转变：调查张三→对付李四 → 无转变过程

4. 修复建议：
   - 补充"通过审问张三得知李四"
   - 或补充"发现张三与李四的秘密通信"

### 0.7 能力设定冲突审查方法

```
对照文件：

- 本章正文：06-正文/第X卷/第XXX章-xxx.md
- 人物设定：03-人物设定/主角.md

审查步骤：
1. 提取前章能力状态：
   - 境界：当前境界
   - 能力：技能A（每天X次）
   - 已使用：2次

2. 提取本章能力状态：
   - 境界：当前境界 ✓
   - 使用能力：火球术4次 ✗
   - 新能力：冰锥术 ✗

3. 分析异常：
   - 使用次数：超过每天3次限制 → 冲突
   - 新能力：突然出现冰锥术 → 冲突

4. 修复建议：
   - 火球术：改为使用其他手段，或说明"透支使用"
   - 冰锥术：补充获取过程，或删除
```

## 二、章纲符合性审查方法

### 1. 内容边界审查方法

**A. 超出章纲（Over）**

```
对照文件：
- 章纲：05-章纲/第X卷/第XXX章-xxx.md
- 正文：06-正文/第X卷/第XXX章-xxx.md

章纲要求：主角与张三对话，获取信息
正文表现：主角与张三对话 + 与李四对话 + 与王五打斗
审查结果：✗ 超出章纲，李四对话和王五打斗不在规划内

处理方式：
- 评估：新增内容是否必要？
- 若必要：修改章纲，补充内容
- 若不必要：删除或移至其他章节
```

**B. 遗漏章纲（Miss）**

```
对照文件：
- 章纲：05-章纲/第X卷/第XXX章-xxx.md
- 正文：06-正文/第X卷/第XXX章-xxx.md

章纲要求：主角与张三对话（获取信息A）+ 发现线索B + 内心挣扎C
正文表现：主角与张三对话（获取信息A）+ 发现线索B
审查结果：✗ 遗漏章纲要点，缺少内心挣扎C

处理方式：
- 补充内心挣扎内容
- 或修改章纲删除该要点
```

**C. 超前章纲（Ahead）**

```
对照文件：
- 章纲：05-章纲/第X卷/第XXX章-xxx.md
- 正文：06-正文/第X卷/第XXX章-xxx.md
- 后续章纲：05-章纲/第X卷/第XXX+N章-xxx.md

章纲要求：主角发现线索（但不知道线索含义）
正文表现：主角发现线索 + 推理出线索含义 + 知道幕后黑手
审查结果：✗ 超前章纲，线索含义应在第X章（05-章纲/第X卷/第XXX+N章-xxx.md）揭示

处理方式：
- 删除超前内容
- 改为埋下伏笔，不揭示真相
- 或调整后续章纲，提前揭示
```

### 2. 情节一致性审查方法

```
对照文件：
- 章纲：05-章纲/第X卷/第XXX章-xxx.md 中的"情节分解"
- 正文：06-正文/第X卷/第XXX章-xxx.md 中的"正文内容"

| 章纲情节 | 正文表现 | 一致性 | 问题说明 |
|---------|---------|--------|---------|
| 主角被羞辱 | 主角被羞辱 | ✓ | 无 |
| 主角隐忍 | 主角当场反击 | ✗ | 人设不符 |
| 系统提示出现 | 系统未出现 | ✗ | 遗漏关键情节 |
| 反派震惊 | 反派平静接受 | ✗ | 情绪不符 |
```

### 3. 人物行为审查方法

```
对照文件：
- 章纲：05-章纲/第X卷/第XXX章-xxx.md 中的"出场人物"和"关键对话"
- 正文：06-正文/第X卷/第XXX章-xxx.md
- 人设：03-人物设定/主角.md

章纲设定：
- 主角：冷静隐忍，内心愤怒但不表现
- 反派：嚣张跋扈，看不起主角
- 配角A：劝解主角，担心冲突

正文表现：
- 主角：冷静隐忍 ✓
- 反派：嚣张跋扈 ✓
- 配角A：煽风点火 ✗（与章纲不符）
- 新增配角B：帮主角说话 ✗（章纲无此人物）

审查结果：
- 配角A行为偏离，需调整
- 配角B为新增人物，需评估必要性
```

## 三、章节连贯性审查方法

```

- 本章正文：06-正文/第X卷/第XXX章-xxx.md
- 后章章纲：05-章纲/第X卷/第XXX+1章-xxx.md（了解后续规划）

A. 开头承接审查
前章卡点：主角发现关键物品A，却不知其用途
本章开头：主角已经知道关键物品A是开启秘境的钥匙 ✗
审查结果：✗ 未承接卡点，直接跳过了探索过程

B. 人物状态审查
前章结尾：主角身受重伤，昏迷不醒
本章开头：主角生龙活虎，正在修炼 ✗
审查结果：✗ 人物状态不连贯，缺少恢复过程

C. 场景转换审查
前章结尾：主角在密室中
本章开头：主角在广场上 ✗
审查结果：✗ 场景跳跃，缺少过渡

D. 时间线审查
前章结尾：三天后出发
本章开头：已经到达目的地 ✗
审查结果：✗ 时间跳跃过大，缺少途中情节

E. 卡点呼应审查
本章卡点：发现敌人埋伏
后章开头：主角在客栈休息 ✗
审查结果：✗ 卡点未呼应，后章应承接"遭遇埋伏"

## 四、人设一致性审查方法

```
对照文件：
- 人物设定：03-人物设定/主角.md、配角.md、反派.md
- 前章正文：06-正文/第X卷/第XXX-N章-xxx.md（查看人物前史）
- 本章正文：06-正文/第X卷/第XXX章-xxx.md

A. 主角人设一致性
人物设定（03-人物设定/主角.md）：
- 性格：冷静理智，不轻易动怒
- 核心价值观：以大局为重
- 成长阶段：第50章，正处于"学会隐忍"阶段

本章表现：
- 主角因一句嘲讽就大打出手 ✗

审查结果：✗ 人设OOC（Out Of Character）
- 问题：行为与"冷静理智"人设冲突
- 建议：改为冷静反击，或增加"触及底线"的合理触发

B. 人物成长一致性
前章表现（第49章）：
- 主角面对羞辱选择隐忍

本章表现（第50章）：
- 主角面对羞辱直接爆发 ✓（符合成长轨迹）

审查结果：✓ 成长合理，从隐忍到反击是质变节点

C. 配角设定一致性
人物设定（03-人物设定/配角.md）：
- 配角A：忠诚耿直，不善言辞

本章表现：
- 配角A巧舌如簧，帮主角游说众人 ✗

审查结果：✗ 配角OOC
- 问题：与"不善言辞"设定冲突
- 建议：改为配角A用行动支持，或换其他角色游说

D. 反派动机一致性
人物设定（03-人物设定/反派.md）：
- 反派B：贪婪自私，为利益不择手段

本章表现：
- 反派B为了"正义"与主角合作 ✗

审查结果：✗ 反派OOC
- 问题：行为与动机冲突
- 建议：改为反派B为利益假意合作，暗中算计

E. 人物关系合理性
前章关系（第45章）：
- 主角与女主：刚认识，互有好感

本章关系：
- 主角与女主：生死相许，山盟海誓 ✗

审查结果：✗ 关系发展过快
- 问题：5章内从初识到深爱不现实
- 建议：增加感情铺垫，或调整关系阶段

F. 能力使用合理性
人物设定（03-人物设定/主角.md）：
- 当前能力：当前境界，掌握属性A法术

本章表现：
- 主角使用冰系法术 ✗
- 主角展现高境界实力 ✗

审查结果：✗ 能力设定冲突
- 问题1：属性不符（火系→冰系）
- 问题2：等级不符（低境界→高境界）
- 建议：改为火系法术，或提前铺垫获得冰系能力
```

## OOC量化评估标准

### 评分维度（1-5分）

| 分数 | 严重程度 | 判定标准 | 处理方案 |
|------|---------|---------|---------|
| 5分 | 灾难级OOC | 人设完全崩坏，性格/动机/能力完全矛盾，读者无法识别角色 | 必须重写，重新规划人物轨迹 |
| 4分 | 严重OOC | 核心人设违背（如冷静角色突然冲动且无触发），能力严重越级 | 必须修复，调整行为或增加合理铺垫 |
| 3分 | 中度OOC | 行为偏离人设但有解释空间，情绪反应过度，关系发展过快 | 建议修复，补充心理描写或调整行为 |
| 2分 | 轻微OOC | 行为略偏人设但可接受，台词风格略有偏差，小细节不符 | 可选修复，记录观察后续章节 |
| 1分 | 疑似OOC | 有OOC嫌疑但证据不足，或属于合理的人物成长 | 无需修复，继续观察 |

### 评分方法

1. **独立评分**：每个OOC问题按上述标准独立评分
2. **加权计算**：主角OOC权重×2，配角OOC权重×1，反派OOC权重×1.5
3. **总分判定**：
   - ≥15分：本章人设严重崩坏，必须返工
   - 10-14分：人设问题较多，建议大幅修改
   - 5-9分：存在人设问题，需要针对性修复
   - <5分：人设基本稳定，可选优化

## 五、结构符合性审查方法

### 1. 四部分结构审查方法

```
对照文件：
- 章纲：05-章纲/第X卷/第XXX章-xxx.md 中的"情节分解（2100-3000非空白字符分配）"
- 正文：06-正文/第X卷/第XXX章-xxx.md

章纲结构：
├─ 开头钩子（250非空白字符）：主角发现异常
├─ 剧情发展（650非空白字符）：调查异常原因
├─ 情绪高潮（600非空白字符）：发现惊人真相
└─ 章节卡点（400非空白字符）：新的危机出现

正文结构：
├─ 开头（300非空白字符）：主角发现异常 ✓（略超但可接受）
├─ 发展（800非空白字符）：调查异常 + 与配角对话 ✗（过长，且对话偏离）
├─ 高潮（400非空白字符）：发现真相（但不够震撼）⚠（功能未完全达到）
└─ 卡点（500非空白字符）：新危机 ✓

审查结果：
- 发展部分过长，需压缩
- 高潮部分力度不足，需加强
```

### 2. 卡点符合性审查方法

```
对照文件：
- 章纲：05-章纲/第X卷/第XXX章-xxx.md 中的"章节卡点"
- 正文：06-正文/第X卷/第XXX章-xxx.md

章纲卡点：
类型：信息型悬念
内容：家主提及婚约，引出新的冲突
预期效果：读者好奇婚约对象是谁

正文卡点：
类型：信息型+情感型 ✓（升级，更好）
内容：家主提及婚约，婚约对象竟是主角认识的神秘女子
效果：读者好奇婚约对象是谁 + 为什么是她 ✓（超出预期）

审查结果：✓ 卡点符合且升级，保持
```

```
对照文件：
- 章纲：05-章纲/第X卷/第XXX章-xxx.md 中的"爽点设计"

章纲爽点：
- 类型：打脸型

## 六、内容质量审查方法

### 1. 对话质量审查方法

```
对照文件：
- 章纲：05-章纲/第X卷/第XXX章-xxx.md 中的"关键对话"
- 正文：06-正文/第X卷/第XXX章-xxx.md

章纲关键对话：
1. 反派："你凭什么？"（嘲讽）
2. 主角："凭这个。"（展现实力）
3. 众人：震惊反应

正文对话：
1. 反派："你凭什么？" ✓
2. 主角："凭这个。" ✓
3. 反派："就凭你？"（新增，延长冲突）⚠
4. 主角：（沉默，直接展现实力）✓
5. 众人：震惊反应 ✓
6. 配角A：（劝解，新增对话）✗（偏离章纲）

审查结果：
- 第3句延长冲突，可保留
- 第6句偏离，建议删除或修改
```

### 2. 伏笔处理审查方法

```
对照文件：
- 章纲：05-章纲/第X卷/第XXX章-xxx.md 中的"伏笔埋设"
- 正文：06-正文/第X卷/第XXX章-xxx.md
- 前章章纲：05-章纲/第X卷/第XXX-N章-xxx.md

章纲伏笔规划：
- 伏笔A：埋设关键物品A线索（第5章回收）
- 伏笔B：提及神秘人物（第10章回收）

正文伏笔处理：
- 伏笔A：关键物品A线索已埋设 ✓
- 伏笔B：神秘人物已提及 ✓
- 新增伏笔C：主角的特殊能力 ⚠（章纲未规划）
- 提前揭示：神秘人物竟是主角师父 ✗（应在第10章揭示）

审查结果：
- 伏笔C需评估，若重要则补充到章纲
- 提前揭示需删除，改为暗示而非揭示
```

### 3. 信息准确性审查方法

```
对照文件：
- 章纲：05-章纲/第X卷/第XXX章-xxx.md
- 正文：06-正文/第X卷/第XXX章-xxx.md

章纲信息：
- 时间：三天后
- 地点：城市A广场
- 人物实力：主角当前境界，反派高境界
- 物品：神秘丹药（效果未知）

正文信息：
- 时间：三天后 ✓
- 地点：城市A广场 ✓
- 人物实力：主角当前境界，反派高境界 ✗（与章纲不符）
- 物品：神秘丹药（能提升修为）✗（章纲应为未知）

审查结果：
- 反派实力错误，需修改为高境界
- 丹药效果提前揭示，需改为未知
```

## 七、文笔规范审查方法

### 1. 字数审查方法

```
步骤1：提取正文内容
├── 读取文件：06-正文/第X卷/第XXX章-xxx.md
├── 定位正文开始：## 正文内容 标题之后
├── 定位正文结束：## 写作备注 标题之前（或文件末尾）
└── 提取纯正文内容

步骤2：统计正文字数（非空白字符）
├── 统计非空白字符：len([c for c in body if not c.isspace()])
├── 统计非空白字符数：____字符
├── 统计非空白字符数量：____非空白字符（参考）
└── 判断是否达标

步骤3：字数达标情况处理（2100 ≤ 非空白字符 ≤ 3000字符）
├── 状态：✓ 字数达标，无需调整
├── 检查各部分分配是否合理
└── 检查是否存在某部分过长/过短

步骤4：字数不足情况处理（非空白字符 < 2100字符）
├── 状态：✗ 字数不足，需要扩写
├── 计算缺口：2100 - 实际非空白字符数 = ____字符
├── 分析缺字原因
└── 制定扩写方案

步骤5：字数过多情况处理（非空白字符 > 3000字符）
├── 状态：✗ 字数过多，需要精简
├── 计算超出：实际非空白字符数 - 3000 = ____字符
├── 分析超出原因
└── 制定精简方案
```

### 2. 段落规范审查方法

```
审查文件：06-正文/第X卷/第XXX章-xxx.md

正文段落统计：
- 总段落数：45段
- 超长段落（>3行）：8段 ✗
- 对话段落：25段 ✓
- 描写段落：12段

超长段落列表：
1. 第3段：环境描写，5行 ✗
2. 第15段：心理描写，6行 ✗
3. 第28段：动作描写，4行 ⚠
...

审查结果：
- 8段超长段落需拆分
- 建议每段不超过3行，适合手机阅读
```

### 3. 对话占比审查方法

```
审查文件：06-正文/第X卷/第XXX章-xxx.md

正文非空白字符数：2100-3000字符
对话非空白字符数：1250字符
占比：50% ✗（低于60%标准）

对话质量分析：
- 有效对话（推动剧情）：900字符
- 无效对话（闲聊/重复）：350字符

审查结果：
- 对话占比不足，需增加250字符对话
- 无效对话350字符，建议删除或改为剧情推进
- 建议增加主角与反派的冲突对话
```

## 八、扩写技巧建议

### 1. 对话扩写

- 增加说话时的神态描写
- 增加听话者的心理反应
- 增加对话间的动作细节
- 增加环境氛围对对话的影响

### 2. 场景扩写

- 增加环境细节（视觉、听觉、嗅觉）
- 增加人物对环境的感知
- 增加场景转换的过渡
- 增加时间流逝的暗示

### 3. 情绪扩写

- 增加内心独白
- 增加身体反应（心跳、呼吸、颤抖）
- 增加环境烘托（天气、光线、声音）
- 增加回忆/联想

### 4. 动作扩写

- 分解动作步骤
- 增加动作细节（力度、角度、速度）
- 增加动作效果（声音、视觉、他人反应）
- 增加动作间的心理活动
