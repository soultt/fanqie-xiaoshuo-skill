## 审查验证机制

> **核心要求**：审查结论必须基于当前文件内容，不得只凭口头判断或历史记忆下结论。
> **完整规范**：详见 [审查验证规范](./templates/审查验证规范.md)

### 关键规则

| 规则 | 说明 |
|------|------|
| 规则1 | 每个检查项都必须有对应的文件依据 |
| 规则2 | 审查输出必须体现验证依据 |
| 规则3 | 禁止仅口头声明"已检查"或"通过" |
| 规则4 | 禁止以任何理由跳过检查项 |
| 规则5 | 禁止抽查部分内容而非全量验证 |
| 规则6 | 每次审查都应重新核对当前文件内容 |
| 规则7 | 禁止使用"之前读取""我记得"等依赖记忆的表述 |
| 规则8 | 记忆与文件冲突时，以文件为准 |

### 审查执行确认清单（强制）

**审查开始前必须确认**：

- [ ] 我将给出对应的文件依据
- [ ] 我不会仅口头声明"已检查"或"通过"

**未全部勾选确认 → 不得开始审查**

## 审查维度体系

> **详细检查方法**：参见 [审查方法详解](./templates/审查方法详解.md)
> **审查标准值**：参见 [审查标准速查](./templates/审查标准速查.md)

| 层级 | 名称 | 优先级 | 说明 |
|------|------|--------|------|
| 优先审查 | 前后章节冲突+字数符合性 | P0-最高 | 必须在所有其他审查之前执行 |
| 一级审查 | 章纲符合性 | P1-高 | 含约束清单一致性作为子项 |
| 二级审查 | 章节连贯性 | P2-中 | 对话与节奏 |
| 三级审查 | 人设一致性 | P3-低 | 人物行为符合设定 |
| 四级审查 | 结构符合性 | P4-参考 | 含去AI化、大纲导航字眼检查 |
| 五级审查 | 内容质量 | P5-参考 | 描写生动性、信息密度 |
| 六级审查 | 文笔规范 | P6-参考 | 错别字、语病、标点 |

### 优先审查（P0-最高）：前后章节冲突+字数符合性

检查人物状态、时间线、地点、物品、知识的连续性，以及字数是否达标（2100-3000非空白字符）。
**一旦发现严重冲突、字数不足或字数过多，立即阻塞，修复后重查。**

#### 0.1-0.7 七项冲突检查

| 检查项 | 关注点 |
|--------|--------|
| 人物状态冲突 | 修为/实力、情绪、穿着/装备 |
| 时间线冲突 | 时间衔接、跨度、白天/黑夜一致性 |
| 地点空间冲突 | 地点衔接、转换过渡、空间关系 |
| 物品道具冲突 | 持有物品一致性、新物品来源、消耗记录 |
| 人物关系冲突 | 关系一致性、称呼、态度 |
| 前情逻辑冲突 | 信息获取合理性、决策依据、因果关系 |
| 能力设定冲突 | 能力一致性、使用限制、成长过程 |

#### 0.8 字数符合性

- 每章非空白字符数：2100-3000（硬性要求，<2100必须扩写，>3000必须精简）
- 仅统计正文内容（不含头部/尾部注释）
- 统计方法：`len([c for c in body if not c.isspace()])`

### 一级审查（P1-高）：章纲符合性

- 内容边界检查（超出/遗漏/超前章纲）
- 剧情一致性、人物行为、四部分结构
- 卡点符合性、爽点符合性
- 双约束清单一致性（章纲约束 + 正文约束）

### 二级审查（P2-中）：章节连贯性

- 对话占比 >= 60%
- 段落长度 <= 3行
- 节奏合理

### 三级审查（P3-低）：人设一致性

- 人物行为、对话风格、情绪反应符合设定

### 四级审查（P4-参考）：结构符合性

- 标题继承与冲突检查
- 四部分结构完整性
- 去AI化检查（8项AI特征）
- 大纲导航类字眼检查（完整禁止词汇列表见 [审查标准速查](./templates/审查标准速查.md)）

### 五级审查（P5-参考）：内容质量

- 场景描写生动性、信息密度、氛围营造

### 六级审查（P6-参考）：文笔规范

- 错别字、语病、标点符号、语句通顺性

### 快速概览

1. **确认审查范围** → 2. **读取审查依据** → 3-9. **逐级审查（P0-P6）** → 10. **生成报告** → 11. **同步约束清单**

**阻塞触发条件**：优先审查发现严重冲突、字数<2100、字数>3000、对话占比<60%、约束清单不一致、核心事件不符、标题冲突等。

**修复映射**：审查只负责发现问题，修复必须调用 `novel-chapter-writer` 完成。

## 审查注意事项

1. **约束清单是审查依据**：约束清单与章纲具有同等重要性，必须对照约束清单逐项检查。
2. **修改正文后必须同步更新正文约束清单**：任何导致人物状态、物品、场景变化的修改，都必须反映在约束清单中。
3. **章纲优先原则**：当约束清单与章纲矛盾时，以章纲为准，同时标注约束清单需更新。
4. **前章正文优先**：审查连贯性时，以前章正文实际内容为准，而非章纲规划。
5. **审查不完整不得输出**：所有7个审查节点（P0-P6）+ 报告生成步骤必须全部完成并勾选确认后，才能输出审查报告。
