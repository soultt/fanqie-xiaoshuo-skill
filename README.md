# 番茄小说 AI 辅助创作技能库 (Fanqie Xiaoshuo AI Skills)

这是一个专门针对网文小说（特别是番茄小说风格）创作的 AI 技能与工作流集合。包含了从大纲设计、角色设定、章节写作、章纲创建到内容审查、签约评估等全流程的自动化与辅助工具。

## 包含的技能模块 (Skills)

1. **fanqie-contract-evaluator (签约评估)**
   - 包含签约评估模板，用于评估小说的签约潜力和商业价值。

2. **flow-automation (工作流自动化)**
   - 包含工作流模式、接口规范和异常处理，用于串联小说创作的各个环节。

3. **novel-chapter-outline-creator (章纲创建器)**
   - 提供卷纲提取、章纲标准、执行流程等模板，帮助快速构建高质量的章节大纲。

4. **novel-chapter-vetter (章节审查器)**
   - 包含审查报告模板、OOC修复案例库、人物状态追踪表等，确保正文内容不脱离设定。

5. **novel-chapter-writer (章节写作器)**
   - 包含写作标准、写作示例库、去AI化技法等，辅助生成自然、流畅且符合网文节奏的正文。

6. **novel-creation-workflow (小说创作工作流)**
   - 提供从章纲、正文到审查的日更实战方案及综合模板，串联整个小说创作生命周期。

7. **novel-master-outline-vetter (总纲审查器)**
   - 提供大纲审查标准、分段审查规范等，用于对小说整体大纲进行逻辑与设定审查。

8. **novel-outline-designer (大纲设计器)**
   - 包含总纲模板、卷纲模板、章节卡片模板等，协助作者构建宏大的小说世界与主线剧情。

9. **novel-outline-vetter (章纲审查器)**
   - 针对章纲提供独立的审查标准、验证规范与审查报告模板。

10. **novel-setting-designer (设定设计器)**
    - 提供世界观、能力体系、角色设定等模板集，构建扎实的小说基础设定。

11. **novel-writer-master (小说创作大师/中枢)**
    - 统筹整个小说创作流程，包含创作流程控制规范、双重约束机制以及统一标准。

## 使用方法

每个目录下都包含一个 `SKILL.md` 文件作为该技能的主入口，以及 `templates/` 目录用于存放具体的执行模板和规范。您可以将这些文件作为 Prompt 或技能导入到支持该格式的 AI 代理工具中，打造个人的自动化小说创作助手。
