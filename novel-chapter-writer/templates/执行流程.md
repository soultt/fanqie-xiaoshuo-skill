## 强制约束检查（阻塞式）

**阶段说明（强制）**：本检查为强制流程，任一检查项未通过则停止执行。

开始正文写作前，必须完成以下检查：

```
┌──────────────────────────────────────────────────────────┐
│  强制约束自检清单（novel-chapter-writer）                │
├──────────────────────────────────────────────────────────┤
│ 检查项1：本章章纲文件存在？                                │
│   文件：05-章纲/NN-第X卷-卷名/第XXX章-章节标题.md         │
│   状态：☑ 已存在并读取  ☒ 不存在（停止执行）              │
├──────────────────────────────────────────────────────────┤
│ 检查项2：章纲约束清单存在？                                │
│   文件：08-约束清单/章纲约束/NN-第X卷-卷名/第XXX章-约束清单.md │
│   状态：☑ 已存在并读取  ☒ 不存在（停止执行）              │
│   说明：章纲约束清单由novel-chapter-outline-creator生成    │

│              请检查前章是否正确生成正文约束清单"           │
│   说明：此检查项确保章节连贯性，是正文写作的强制前置条件    │
├──────────────────────────────────────────────────────────┤
│ 检查项3：人物设定文件存在？                                │
│   文件：03-人物设定/主角.md（至少主角文件必须存在）        │

│ 检查项5：输出目录可写？                                    │
│   目录：06-正文/NN-第X卷-卷名/                            │
│   状态：☑ 可写  ☒ 不可写（停止执行）                      │
├──────────────────────────────────────────────────────────┤
│ 检查项6：章纲约束清单内容验证                              │

│   非第1章：                                               │

│   要求：正文对话字符数 / 正文总非空白字符数 ≥ 60%           │
│   计算方法：扫描正文中引号包裹的对话行，统计对话字符数       │
│   状态：☑ ≥60%（通过）  ☒ <60%（强制阻塞，必须增加对话）   │
│   说明：对话占比是番茄平台核心指标，<60% 不得保存文件       │

```

**检查失败处理**：
- 任一必需检查项（1, 2, 2.5, 3, 5, 6, 6.2, 6.5, 8）失败 → **立即停止执行**，报告缺失文件或标题冲突或对话不足
- 检查项4、7（前章正文相关）失败 → 生成警告，询问是否继续（第1章除外）
- **检查项2.5（前章正文约束清单）失败 → 强制停止，不得继续写作**
- **检查项8（对话占比<60%）失败 → 强制停止，必须增加对话后重新验证**

## 约束信息加载与写作约束生成

> 约束清单读取的基础流程参见上方「约束清单读取流程」，本节在此基础上增加写作约束整理逻辑。

检查全部通过后，**从章纲约束清单与前章正文约束清单加载约束信息**：

### 步骤1：读取章纲约束清单
```markdown
文件路径：08-约束清单/章纲约束/NN-第X卷-卷名/第XXX章-约束清单.md

必须包含的内容：
- 卷纲规定内容（核心事件/爽点/伏笔/卡点）
- 章纲规划内容（四部分结构摘要）
- 人物状态（前章结尾状态）
- 禁止事项
```

### 步骤2：验证章纲约束清单完整性
| 验证项 | 状态 |
|--------|------|
| 卷纲规定内容完整 | ☑ |
| 章纲四部分结构完整 | ☑ |
| 人物状态已记录 | ☑ |
| 禁止事项已列出 | ☑ |

**任一缺失 → 停止执行，报错："章纲约束清单内容不完整"**

### 步骤3：生成本章写作约束

> **模板引用**：详见 [正文约束清单模板](./正文约束清单模板.md)
>
> 包含：
> - 正文写作约束完整格式（来源文件、卷纲规定内容、章纲规定内容、人物状态约束、禁止事项）
> - 正文字眼禁止词表（卷部结构词、章节导航词、高潮/转折导航词、规划性质词、伏笔相关词、时序导航词）
> - 大纲导航类字眼检查清单
> - 正确表达示例
> - 约束信息读取确认标记

### 步骤4：标记约束信息已读取
在本章写作约束末尾添加读取确认（格式详见正文约束清单模板）。

## 正文约束清单生成（供下章使用）

> **模板引用**：详见 [正文模板（正文约束清单部分）](./正文模板.md#二正文约束清单模板)

**生成要求（强制）**：正文输出后，必须生成正文约束清单供下章读取。

### 正文约束清单路径
```
08-约束清单/正文约束/NN-第X卷-卷名/第XXX章-约束清单.md
```

### 生成步骤

1. **正文验证通过后**，提取本章实际内容约束
2. **记录人物状态**：从本章结尾提取主角状态
3. **记录实际字数**：四部分各自的实际字数
4. **规划下章约束**：根据卡点设计下章初始状态
5. **保存到指定路径**：`08-约束清单/正文约束/NN-第X卷-卷名/第XXX章-约束清单.md`

### 依赖说明
**下游依赖（强制）**：此文件是下一章创作的强制输入。
- 下章 novel-chapter-outline-creator 必须读取此文件获取人物状态
- 下章 novel-chapter-writer 必须读取此文件获取连贯性约束
- 确保批量生成时跨章节的连贯性

## 阻塞式执行机制（强制）

**每个步骤必须完成才能进入下一个步骤，不可跳过任何步骤。**

### 执行规则（强制）

- **规则1**：必须按顺序执行，不可跳过任何步骤

- **规则4**：每个步骤完成后必须勾选确认，才能进入下一步
- **规则5**：最终输出必须包含所有步骤的完成确认

- [ ] **节点3**：步骤三（读取章纲约束清单）已完成
- [ ] **节点3.5**：步骤三.5（读取前章正文约束清单）已完成（关键节点，非第1章强制）
- [ ] **节点4**：步骤四（快速浏览）已完成
- [ ] **节点5**：步骤五（分阶段写作）已完成

  - 第1章：跳过此节点

> **阻塞说明（强制）**：所有触发条件均为强制阻塞，不得以任何理由跳过。

| 触发条件 | 阻塞级别 | 处理方式 |

| **正文约束清单验证未通过** | **强制阻塞** | **立即停止，修复后重新验证，不得输出正文** |
| **输出验证未通过** | **强制阻塞** | **立即停止，不得输出成品** |
| 任何步骤未执行 | 强制阻塞 | 补全后才能输出完成声明 |

## 标准写作流程

### 阶段零：启用阻塞式执行机制（强制）

> **执行开始确认（强制）**：
> - [ ] 我已阅读并理解阻塞式执行规则
> - [ ] 我将按顺序执行所有步骤，不跳过任何步骤
> - [ ] 每个步骤完成后我将勾选确认清单
> - [ ] 发现阻塞问题时我将立即停止，不输出不完整成品
>
> **未全部勾选确认 → 不得开始执行**

**节点完成确认**：[ ] 节点0：阶段零确认已完成

---

### 步骤一：确认保存位置
- 根据章节号确定所属卷
- 文件名：`第XXX章-章节标题.md`
- 路径：`06-正文/NN-第X卷-卷名/`

### 步骤二：读取章纲内容（最关键步骤）

**步骤说明（强制）**：这是最关键的步骤，必须首先完成。

**操作方法**：
1. 打开对应章纲文件（如 `05-章纲/01-第一卷-卷名/第005章-初次修炼.md`）
2. 提取以下核心内容：

### 步骤六.5：对话占比验证（强制阻塞，必须执行）

**对话占比要求（强制）**：对话占比 ≥ 60% 是硬性要求，不达标必须强制阻塞。

**对话统计方法**：
```python
# 统计正文中对话行（以中文引号/日文引号开头的行）的字符数
dialogue_chars = 0
for line in body.split('\n'):
    stripped = line.strip()
    if stripped.startswith('"') or stripped.startswith('\u201c') or stripped.startswith('\u300c'):
        dialogue_chars += len([c for c in stripped if not c.isspace()])
ratio = round(dialogue_chars / non_space * 100, 1) if non_space > 0 else 0
```

**判定标准**：
- 对话占比 ≥ 60% → 通过，继续步骤七
- 对话占比 < 60% → **强制阻塞**，必须增加对话后重新验证

**对话占比不足时的修复策略**：

| 场景类型 | 修复方法 |
|---------|---------|
| 叙述过多 | 将大段叙述转化为人物对话推进 |
| 打斗/动作场景 | 增加旁观者反应对话、对战双方挑衅/嘲讽 |
| 商业分析场景 | 将江凡独白改为与林若雪/王胖子的对话讨论 |
| 心理活动场景 | 将内心独白转化为与他人的交谈 |
| 场景过渡 | 增加人物间的简短对话替代纯描写 |

**修复后重新验证**：增加对话后必须重新统计，确认对话占比 ≥ 60%。
