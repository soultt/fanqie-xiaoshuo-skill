# 正文约束清单模板

> **模板引用**：本模板由 `novel-chapter-writer/SKILL.md` 引用。
> **相关模板**：详见 [章纲约束清单模板](../../novel-chapter-outline-creator/templates/约束清单模板.md)。

## 正文写作约束清单格式

基于章纲约束清单内容，生成 `正文写作约束清单`：

```markdown
## 正文写作约束清单（第XXX章）
生成时间：YYYY-MM-DD HH:MM:SS
生成技能：novel-chapter-writer
约束来源：08-约束清单/章纲约束/NN-第X卷-卷名/第XXX章-约束清单.md

### 来源文件
- [x] 章纲约束清单：08-约束清单/章纲约束/NN-第X卷-卷名/第XXX章-约束清单.md
- [x] 本章章纲：05-章纲/NN-第X卷-卷名/第XXX章-章节标题.md
- [x] 人物设定：03-人物设定/主角.md
- [x] 前章正文：06-正文/NN-第X卷-卷名/第XXX-1章-xxx.md（或"本章为第1章"）

### 卷纲规定内容（必须严格遵循）
| 项目 | 内容 | 遵循状态 |
|------|------|----------|
| 核心事件 | {从约束清单复制} | ☑ |
| 爽点设计 | {从约束清单复制} | ☑ |
| 伏笔埋设 | {从约束清单复制} | ☑ |
| 卡点设计 | {从约束清单复制} | ☑ |

### 章纲规定内容（必须严格遵循）
#### 四部分结构
- 开头钩子：{从约束清单复制，约250字符}
- 剧情发展：{从约束清单复制，约650字符}
- 情绪高潮：{从约束清单复制，约600字符}
- 章节卡点：{从约束清单复制，约400字符}

#### 核心要素
- 核心事件：{从约束清单复制}
- 爽点设计：{从约束清单复制}
- 伏笔埋设：{从约束清单复制}
- 卡点设计：{从约束清单复制}

### 人物状态约束
#### 前章结尾状态（来自约束清单）
- 主角伤势/体力：{从约束清单复制}
- 主角情绪状态：{从约束清单复制}
- 持有物品：{从约束清单复制}
- 当前地点：{从约束清单复制}

#### 本章结尾状态（写作时填写）
- 主角伤势/体力：{待填写}
- 主角情绪状态：{待填写}
- 持有物品：{待填写}
- 当前地点：{待填写}

### 禁止事项

#### 章纲遵循禁止事项
- [x] 不得脱离章纲四部分结构
- [x] 不得修改章纲规定的核心事件
- [x] 不得违反章纲规定的爽点设计
- [x] 不得违反章纲规定的伏笔埋设
- [x] 不得修改章纲规定的卡点设计
- [x] 不得超出章纲范围添加额外内容

#### 正文叙事表现禁止事项（强约束）
- **禁止大段心理活动和场景解说，所有剧情推进必须通过人物对话来完成。**

#### 正文字眼禁止事项（强制）
> **引用说明（强制）**：禁止词汇完整列表引用 `novel-writer-master/统一标准.md` 1.5.1节。
>
> 以下为快速参考，完整列表请查阅统一标准：

> **执行要求（强制）**：以下词表禁止出现在正文内容中，仅允许在元数据、约束清单、审查报告中出现。

| 类别 | 示例词汇 |
|------|---------|
| **卷/部结构词** | 第一卷、第二卷、第三卷、卷一、卷二、卷末、卷首、卷尾、下一卷、本卷、上卷、下卷、前卷、后卷、章节前、章节后、卷前、卷后、第一部、第二部、第一部曲、篇、章回 |
| **章节导航词** | 下一章、上一章、前一章、后一章、本章、下章、上章、前章、章节回顾 |
| **高潮/转折导航词** | 卷末高潮、本卷高潮、全书高潮、高潮来临、即将高潮、马上高潮、转折点来临、即将转折 |
| **规划性词汇** | 根据大纲、按照计划、按照设定、这里应该、作者安排、剧情需要、伏笔回收、埋下伏笔、回扣上文 |
| **时序导航词** | 时间线、故事线、情节线、这一幕、这一段、这一幕戏 |

#### 大纲导航类字眼检查清单（输出验证必须检查）

| 检查项 | 文中出现 | 状态 |
|--------|---------|------|
| 卷/部结构词 | ☐ 未出现 | ☑ |
| 章节导航词 | ☐ 未出现 | ☑ |
| 高潮/转折导航词 | ☐ 未出现 | ☑ |
| 规划性词汇 | ☐ 未出现 | ☑ |
| 时序导航词 | ☐ 未出现 | ☑ |

**任一出现 → 标记为问题，必须修改后输出**

#### 正确表达示例

| 禁止写法 | 正确写法 |
|---------|---------|
| "根据大纲设定，{主角名}开始修炼" | "{主角名}深吸一口气，开始了修炼" |
| "本卷高潮即将来临" | "空气中弥漫着紧张的气氛..." |
| "下一章将有大事件发生" | "他感觉到有什么即将发生..." |
| "这是为下一卷埋下的伏笔" | "他若有所思地望向远方..." |
| "根据计划，主角将突破" | "能量在他体内翻涌，突破的契机来了" |
```

## 约束清单读取确认标记

在章纲约束清单末尾添加：
```markdown
## 下步技能读取确认
- [x] novel-chapter-writer 已读取（读取时间：YYYY-MM-DD HH:MM:SS）
```
