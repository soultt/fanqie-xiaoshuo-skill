## 一、开头钩子示例（200-300非空白字符）

**写作要点**：
- 直接切入，不要铺垫
- 承接上文或力量悬念
- 3秒内抓住读者

**章纲**：门开了，走进来的竟是已经死去的老爹

**正文扩展**：
```
"咔嚓——"

沉重的木门缓缓打开。
所有人的目光都集中在门口，空气仿佛凝固了。
一个身影出现在门口，月光从他背后斜照进来，在地上投下长长的影子。
当看清那张脸的瞬间，我的瞳孔骤然收缩——

"老……老爹？！"

我的声音在颤抖。
不可能。
老爹明明在三年前的那场大战中战死了。
我亲眼看着他的身体被敌人的长矛贯穿，亲眼看着他的生命气息消散。
可此刻，他就站在门口，脸上带着我熟悉的温和笑容。

"乖儿，好久不见。"

他的声音和记忆中一模一样。
但我注意到，他的脸色苍白得不像活人，眼中闪过一抹诡异的红光。
这到底是怎么回事？
```

## 二、剧情发展示例（600-700非空白字符）

**写作要点**：
- 对话占比60%以上
- 短句短段，每段不超过3行
- 每100非空白字符一个小钩子

### 1. 基础对话格式

```
"你确定要这么做？"张三问道，语气沉重。
"我确定。"我攥紧拳头，"这是唯一的办法。"

"可是风险太大了。"

"我知道。"

我转过身，看着窗外的夜色。
"但如果我不这么做，会有更多人死。"
```

### 2. 对话+动作+心理

```
"跪下。"

长老将合同拍在桌上，眼中带着讥讽。
（动作）

我攥紧拳头，指甲刺入掌心。
（动作+心理）

——还有三秒，只要再忍三秒……
（心理）

"怎么？不愿意？"

他冷笑一声，"到了这步，你老婆还在医院等着手术费呢。"

（对话+嘲讽）

我的心猛地一缩。
（心理）

该死！
（心理）
```

### 3. 群像对话

```
"我不同意。"张三第一个站出来。
"我也反对。"李四附和道。
长老皱了皱眉："或者……可以试一试？"

"试什么试？"张三瞪了他一眼，"这是拿大家的命去冒险！"

一直没说话的我开口了：
"但如果成功，我们都能活下来。"

所有人都看向我。
"你有把握？"张三问。
"五成。"

"才五成？"

"如果不试，我们连一成的机会都没有。"
```

## 三、情绪高潮示例（约600非空白字符）

**写作要点**：
- 情绪层次递进
- 动作+心理+对话结合
- 达到卡点后分页

**高潮写作示例（打脸型）**：

**章纲**：主角展示实力，反派震惊，众人惊呼

**正文扩展**：
```
"就凭你？"

{反派名}防备地看着我，"一个废物，也配跟我谈条件？"

我没有说话。
只是缓缓抬起手。
体内的灵力开始疯狂运转，一股强大的气息从我身上爆发出来。

"这……这是……"

{反派名}的笑容僵在脸上。
"不可能！不对，比{境界A}更强！"

有人惊呼出声。
"{境界B}！他是{境界B}！"

全场哗然。
{反派名}的脸色瞬间变得惨白。
他自己也不过{境界A}后阶，在{境界B}面前，根本不值一提。

"不可能！"

他失声叫道，"三个月前你还只是{初始境界}，怎么可能……"

"没有什么不可能。"

我淡淡地说道，一步踏出。
强大的气浪席卷全场，{反派名}直接被压得跪在地上。

"现在，你还觉得我是废物吗？"

我俯视着他，声音冰冷。
{反派名}浑身发抖，眼中满是恐惧和难以置信。
他怎么也想不到，那个被他踩在脚下三年的废物，竟然在短短三个月内突破到了{境界B}。
这种修炼速度，简直闻所未闻。

"少……少爷饶命……"

他终于低下了高昂的头颅。
周围的人都看呆了。
那个平日里高高在上的{反派名}，此刻竟然像条狗一样跪在地上求饶。

而让他们更震惊的，是我这个一直被他们看不起的"废物"，竟然隐藏着如此恐怖的实力。

"这就是少爷吗……"

有人喃喃自语，眼中满是敬畏。
"太可怕了，这种天赋，这种实力……"

"我们之前居然还嘲讽他，真是有眼无珠……"

各种议论声此起彼伏，但我充耳不闻。
只是冷冷地看着跪在地上的{反派名}。

"记住，以后见到我，要绕道走。"

"是……是……"

{反派名}连连点头，额头上的冷汗不断滴落。
```

## 四、章节卡点示例（300-400非空白字符）

**写作要点**：
- 悬念升级
- 情绪达到卡点后戛然而止
- 让读者必须看下一章

**卡点写作示例（信息型）**：

**章纲**：家中提出婚约，引出新的冲突

**正文扩展**：
```
就在众人还沉浸在震惊中时，一个低沉的声音响起。

"够了。"

族长从主位上站起来，目光深邃地看着我。
"既然少爷回来了，那有一件事，也该提上日程了。"

我心头一紧。
"什么事？"

"你的婚事。"

我愣住了。
什么婚事？
我怎么不知道？

"十年前，你与{城主家}大小姐{女性角色}定下婚约。"

族长缓缓说道："如今你回来了，这门亲事，也该办了。"

{女性角色}？

我的脑海中浮现出一个名字。
{城主家}大小姐，{城市名}第一美女，修炼天才，年仅十八就突破到了{高境界}。
这种天之骄女，会愿意嫁给我这个"废物"？

"族长，这……"

"怎么？你不愿意？"

族长打断我，眼中闪过一抹凌厉的光芒。
"不是不愿意，只是……"

"那就这么定了。"

族长一锤定音，"三日后，杨家会派人前来商议婚事。"

我还想说什么，但族长已经转身离去。
留下我一个人站在原地，心中五味杂陈。

婚事？
{女性角色}？
这到底是怎么回事？
为什么我从来没有听说过这件事？
而且，为什么偏偏是现在提起？

就在我百思不得其解的时候，一个小厮慌慌张张跑来。

"少爷，不好了！"

"什么事？"

"杨家大小姐……她来了！"

"什么？"

我大吃一惊。
不是说三日后才来商议吗？
怎么现在就来了？
而且，为什么偏偏选在这个时候？

心中涌起一股不好的预感，我快步向大门走去。
当我来到门口时，看到了一个白衣胜雪的身影。
她背对着我，站在台阶下，长发随风飘动。
仿佛是感应到了我的到来，她缓缓转过身来。
四目相对的瞬间，我整个人都愣住了。

因为那张脸……

我认得。
不仅认得，而且刻骨铭心不能再刻骨铭心。

"怎么是你？"

我失声叫道。

她微微一笑，那笑容中带着几分我看不懂的意味。
"好久不见，我的未婚夫。"
```
