# 正文检查清单

> **模板引用**：本模板由 `novel-chapter-writer/SKILL.md` 引用。

---

## 一、章纲符合性检查（最重要，必须首先检查）

### 核心事件符合性
- [ ] 正文的核心事件是否与章纲完全一致？
- [ ] 是否有擅自更改核心事件内容？
- [ ] 正文是否围绕核心事件展开？

### 四部分结构符合性
- [ ] 开头钩子是否按章纲规定内容展开？
- [ ] 剧情发展是否按章纲规定内容展开？
- [ ] 情绪高潮是否按章纲规定内容展开？
- [ ] 章节卡点是否按章纲规定内容展开？

### 爽点设计符合性
- [ ] 正文的爽点是否与章纲一致？
- [ ] 爽点位置是否与章纲规定一致？
- [ ] 是否有偏离章纲规定的爽点？

### 伏笔埋设符合性
- [ ] 正文的伏笔是否与章纲完全一致？
- [ ] 是否有偏离章纲规定的伏笔？
- [ ] 是否有擅自新增伏笔？

### 卡点设计符合性
- [ ] 正文的卡点是否与章纲完全一致？
- [ ] 卡点是否能正确衔接下一章？
- [ ] 是否有擅自更改卡点内容？

**如以上任何一项不符合，必须重新修改正文！**

## 二、字数验证检查（必须首先执行）

**字数统计规则**：
- 统计正文内容区域（`## 正文内容` 到 `## 写作备注` 之间）的非空白字符
- 统计方法：`len([c for c in body if not c.isspace()])`
- 包含：汉字、标点、数字、字母、符号等所有非空白字符
- 不包含：空格、换行符、制表符等空白字符
- 不包含：头部文件信息、尾部写作备注等注释部分

**字数达标检查**：
- [ ] **正文非空白字符数 ≥ 2100字符**（硬性要求，不满足必须扩写）
  - 当前字数：____字符
  - 缺口：____字符（若不足）
- [ ] **正文非空白字符数 ≤ 2500字符**（硬性要求，超过必须精简）
  - 当前字数：____字符
  - 超出：____字符（若超过）

**各部分字数分配检查**：
- [ ] 开头钩子：250±50字符；（当前：____字符）
- [ ] 剧情发展：650±50字符；（当前：____字符）
- [ ] 情绪高潮：600±50字符；（当前：____字符）
- [ ] 章节卡点：400±50字符；（当前：____字符）

**字数不足时的扩写检查**：
- [ ] 是否已确认缺字部分？
- [ ] 是否已按扩写优先级进行扩写？
- [ ] 扩写后是否重新验证字数达标？

**字数过多时的精简检查**：
- [ ] 是否已确认超出部分？
- [ ] 是否已按精简优先级进行精简？
- [ ] 精简后是否重新验证字数达标？

## 三、基础检查
- [ ] 正文文件名标题 = 页内标题 = 章纲标题？
- [ ] 已生成"正文标题检查表"，且无重名/高度相似标题？
- [ ] 四部分结构完整？
- [ ] **对话占比≥60%？（强制阻塞，不达标不得保存）**
  - 计算方法：`dialogue_chars / non_space_chars ≥ 0.6`
  - 统计范围：正文中以 `"` `"` `「` 开头的行
  - 当前对话占比：____%
  - 不达标 → **强制阻塞，必须增加对话后重新验证**
- [ ] 每段不超过3行？
- [ ] 文件已保存到 `06-正文/NN-第X卷-卷名/第XXX章-标题.md`？

## 四、节奏检查
- [ ] 开头3秒抓住读者？
- [ ] 每500字（约250非空白字符）出现一次小转折？
- [ ] 情绪高潮达到卡点？
- [ ] 卡点有效驱动下章？

## 五、文笔检查
- [ ] 短句短段为主？
- [ ] 对话自然流畅？
- [ ] 动作描写具体？
- [ ] 心理活动真实？

## 六、人物检查
- [ ] 主角行为符合人设？
- [ ] 配角有鲜明特点？
- [ ] 对话符合人物性格？
- [ ] 人物关系有发展？
