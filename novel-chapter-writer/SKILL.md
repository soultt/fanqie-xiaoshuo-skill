## 核心原则（强制）：严格遵循章纲

**正文创作必须严格遵循章纲，不得脱离章纲自行推演！**

每章正文都必须：
1. **首先读取章纲中对应章节的内容**（核心事件、四部分结构、爽点设计、伏笔埋设、卡点设计）
2. **严格按照章纲的四部分结构展开**，不得擅自更改结构
3. **章节标题与文件名必须继承章纲标题**，不得在正文层改名或另起标题
4. **核心事件必须与章纲一致**，不得增加或改变核心剧情
5. **爽点设计必须与章纲一致**，不得偏离或改变爽点位置
6. **伏笔埋设必须与章纲一致**，不得偏离或新增章纲未规划的伏笔
7. **卡点设计必须与章纲一致**，确保与后续章节衔接

**禁止行为（强制）**：
- ❌ 脱离章纲核心事件自行编造剧情
- ❌ 修改章纲规定的四部分结构
- ❌ 在正文层修改章节标题或文件名标题
- ❌ 以"第一次/第二次/再次/又一次"等伪差异标题绕过重名问题
- ❌ 违反章纲规定的爽点设计
- ❌ 违反章纲规定的伏笔埋设
- ❌ 修改章纲规定的卡点设计
- ❌ 超出章纲范围添加额外内容

## 正文写作核心原则

### 从章纲到正文的扩展比例

```
章纲：250-350非空白字符 → 扩展 6-10倍 → 正文：2100-2500非空白字符
```

### 字数统计规则

**统计范围**：
- 仅统计正文内容区域（`## 正文内容` 到 `## 写作备注` 之间）
- 包含汉字、标点符号、英文字母、数字、特殊符号等所有非空白字符
- 不包含空格、换行符、制表符等空白字符
- 不包含头部注释和尾部注释

**统计方法**：
```python
non_space_chars = len([c for c in body if not c.isspace()])
```

**字数指标**：
- 每章非空白字符数：2100-2500（硬性要求，<2100必须扩写，>2500必须精简）
- 开头钩子约250 / 剧情发展约650 / 情绪高潮约600 / 章节卡点约400

**扩展方式**：
- 对话扩展（章纲1句 → 正文5-10句，占比≥60%）
- 动作扩展（章纲一动作 → 正文详细描写）
- 心理扩展（章纲提示 → 正文内心独白）
- 场景扩展（章纲如过 → 正文五感描写）

## 日更4200非空白字符实施流程

### 时间分配方案

**分两次写作**（每次约1小时）：
- 上午：回顾章纲 → 写作第1章（40分钟）→ 简单修改 → 保存
- 晚上：回顾章纲 → 写作第2章（40分钟）→ 修改润色 → 保存

**番茄工作法**：写作25分钟 → 休息5分钟，每天4个番茄钟 = 4200字符。

### 写作速度参考

| 水平 | 速度 | 40分钟产出 |
|------|------|-----------|
| 新手 | 25-35字符/分钟 | 1000-1400字符 |
| 练习 | 50-60字符/分钟 | 2000-2400字符 |
| 老手 | 75-100字符/分钟 | 3000-4000字符 |

## 执行注意事项

1. **严格遵循章纲（强制）**：正文创作必须严格遵循章纲，不得脱离章纲自行演绎
2. **章纲优先原则**：如发现正文与章纲不一致，必须以章纲为准进行修改
3. **扩展而非改变**：正文的任务是将章纲的内容扩展为详细的故事，而不是改变章纲的内容
4. **字数要求（强制）**：正文非空白字符数必须在 2100-2500 字符之间；<2100必须扩写，>2500必须精简，修改后重新验证
5. **情节连贯**：写作前必须查看前一章正文，确保情节连贯
6. **对话自然**：对话要符合人物性格，读起来要自然流畅
7. **卡点有效**：卡点必须有足够的吸引力，驱动读者继续阅读
8. **正文约束清单强制输出**：正文文件保存后必须立即生成正文约束清单，这是下一章写作的强制输入
