## 优先审查：前后章节冲突（最高优先级）

### 0.1 卷间衔接冲突审查

**检查项**：
- [ ] 相邻卷之间是否有衔接？
- [ ] 卷末状态是否与下卷卷初状态一致？
- [ ] 主角成长是否连续？
- [ ] 势力发展是否合理？

**冲突类型与判定**：

| 冲突类型 | 严重程度 | 示例 | 修复方案 |
|---------|---------|------|---------|
| 实力跳跃 | 严重 | 第一卷末境界A，第二卷初境界B | 补充突破过程章节 |
| 地点跳跃 | 严重 | 第一卷末在A城，第二卷初在B城无解释 | 补充移动过程 |
| 时间断裂 | 中等 | 第一卷末"三天后出发"，第二卷初已到达 | 补充途中情节 |
| 势力突变 | 严重 | 第一卷末无势力，第二卷初突然有势力 | 补充势力建立过程 |

**审查方法**：
1. 提取第一卷末状态（实力、位置、势力、时间）
2. 提取第二卷初状态
3. 对比分析，发现跳跃/突变
4. 修复：补充过渡情节

### 0.2 人物成长轨迹冲突审查

**检查项**：
- [ ] 主角成长轨迹是否连续？
- [ ] 配角成长是否合理？
- [ ] 人物关系发展是否连贯？
- [ ] 人物能力成长是否有依据？

**冲突类型与判定**：

| 冲突类型 | 严重程度 | 示例 | 修复方案 |
|---------|---------|------|---------|
| 成长跳跃 | 严重 | 总纲"第100章境界A"，卷纲"第80章境界B" | 统一成长节点 |
| 能力矛盾 | 严重 | 第一卷"火系"，第二卷"冰系"无解释 | 补充能力获取 |
| 关系突变 | 严重 | 第一卷末敌人，第二卷初朋友 | 补充关系转变 |
| 性格突变 | 中等 | 第一卷"冷静"，第二卷"冲动" | 补充性格转变原因 |

**审查方法**：
1. 建立成长轨迹对照表（章节 vs 总纲规划 vs 卷纲设定）
2. 分析冲突点
3. 修复：统一成长节点

### 0.3 时间线规划冲突审查

**检查项**：
- [ ] 各卷时间线是否衔接？
- [ ] 时间跨度是否合理？
- [ ] 事件时间顺序是否正确？
- [ ] 时间节点是否一致？

**冲突类型与判定**：

| 冲突类型 | 严重程度 | 示例 | 修复方案 |
|---------|---------|------|---------|
| 时间重叠 | 严重 | 第一卷"历时三个月"，第二卷"历时半年"但衔接 | 调整时间跨度 |
| 时间倒流 | 严重 | 第一卷末"年底"，第二卷初"年初" | 调整时间描述 |
| 事件时序 | 严重 | 第一卷"明年比赛"，第二卷"比赛已结束" | 调整事件顺序 |
| 时间节点 | 中等 | 总纲"第100章年底"，卷纲"第100章年中" | 统一时间节点 |

**审查方法**：
1. 建立时间线对照表（卷数/章节范围/时间跨度/起止时间）
2. 检查衔接是否正确
3. 检查总时长是否合理

### 0.4 势力发展冲突审查

**检查项**：
- [ ] 势力变化是否有规划？
- [ ] 势力发展是否连续？
- [ ] 势力关系变化是否合理？
- [ ] 势力实力变化是否有依据？

**冲突类型与判定**：

| 冲突类型 | 严重程度 | 示例 | 修复方案 |
|---------|---------|------|---------|
| 势力凭空出现 | 严重 | 第一卷无宗门，第二卷突然有宗门 | 补充势力建立 |
| 势力消失 | 严重 | 第一卷有家族，第二卷无解释消失 | 补充势力覆灭 |
| 实力突变 | 中等 | 第一卷弱势力，第二卷突然顶级势力 | 补充发展过程 |
| 关系突变 | 严重 | 第一卷敌对势力，第二卷盟友无解释 | 补充关系转变 |

**审查方法**：
1. 建立势力发展追踪表（势力/各卷状态/变化原因）
2. 分析冲突（凭空出现/消失/突变）
3. 修复：补充势力变化过程

### 0.5 主线推进冲突审查

**检查项**：
- [ ] 主线推进是否连续？
- [ ] 主线任务分配是否合理？
- [ ] 主线节点是否一致？
- [ ] 主线目标是否清晰？

**冲突类型与判定**：

| 冲突类型 | 严重程度 | 示例 | 修复方案 |
|---------|---------|------|---------|
| 主线断裂 | 严重 | 第一卷主线任务，第二卷完全无关 | 调整主线衔接 |
| 任务重叠 | 中等 | 第一卷和第二卷任务相同 | 调整任务分配 |
| 节点矛盾 | 严重 | 总纲"第200章复仇"，卷纲"第150章复仇" | 统一节点 |
| 目标模糊 | 中等 | 各卷主线目标不清晰 | 明确主线目标 |

**审查方法**：
1. 建立主线推进表（卷数/主线任务/推进程度/累计进度）
2. 检查连续性（各卷是否衔接）
3. 检查节点一致性

### 0.6 爽点分布冲突审查

**检查项**：
- [ ] 各卷爽点分布是否合理？
- [ ] 爽点间隔是否一致？
- [ ] 大爽点位置是否合理？
- [ ] 爽点类型是否多样？

**冲突类型与判定**：

| 冲突类型 | 严重程度 | 示例 | 修复方案 |
|---------|---------|------|---------|
| 爽点过密 | 中等 | 第一卷每章都有爽点 | 调整爽点间隔 |
| 爽点过疏 | 中等 | 第二卷连续30章无爽点 | 增加小爽点 |
| 大爽点缺失 | 严重 | 卷末无大爽点 | 增加卷末高潮 |
| 爽点重叠 | 中等 | 相邻章节爽点类型相同 | 调整爽点类型 |

**审查方法**：
1. 建立爽点分布表（卷数/小中大爽点数）
2. 检查间隔（小3-5章/中20-30章/大50-100章（每卷1-2个））
3. 检查位置（大爽点在卷末）

### 0.7 伏笔规划冲突审查

**检查项**：
- [ ] 各卷伏笔是否有规划？
- [ ] 伏笔回收是否在计划内？
- [ ] 伏笔数量是否合理？
- [ ] 伏笔与主线是否相关？

**冲突类型与判定**：

| 冲突类型 | 严重程度 | 示例 | 修复方案 |
|---------|---------|------|---------|
| 伏笔过多 | 中等 | 第一卷埋设20个伏笔 | 减少伏笔数量 |
| 伏笔无回收 | 严重 | 伏笔埋设后无回收计划 | 添加回收计划 |
| 回收超期 | 中等 | 第10章伏笔第200章才回收 | 调整回收时间 |
| 伏笔无关 | 中等 | 伏笔与主线无关 | 删除或关联主线 |

**审查方法**：
1. 建立伏笔追踪表（伏笔内容/埋设章节/回收章节/间隔）
2. 分析问题（间隔过长/无回收计划）
3. 修复：提前回收或中期强化记忆

## 一级审查：总纲质量审查

### 1. 核心钩子审查

**检查项**：
- [ ] 是否有一句话核心概念？
- [ ] 核心钩子是否在前300字内出现？
- [ ] 钩子类型是否明确？
- [ ] 钩子是否有足够吸引力？

**钩子类型评估**：
| 钩子类型 | 特点 | 吸引力评分标准 |
|---------|------|---------------|
| 生存危机 | 主角面临死亡威胁 | 高（需有独特设定） |
| 身份反差 | 废物变天才、穷人变富豪 | 高（需有合理逻辑） |
| 悬念谜团 | 神秘事件、未知力量 | 高（需有后续揭示计划） |
| 情感冲击 | 背叛、复仇、守护 | 中高（需有情感铺垫） |

**审查方法**：
```
核心钩子示例：
"核心悬念描述"
评估：✓ 悬念型+生存型，双重钩子

"主角身份觉醒了金手指类型"
评估：⚠ 套路化，建议增加独特元素

"他发现自己能看到别人的死亡倒计时"
评估：✓ 悬念型，有吸引力
```

### 2. 主角设定审查

**检查项**：
- [ ] 主角是否有明确的身份起点和终点？
- [ ] 主角是否有清晰的核心目标？
- [ ] 金手指是否有明确的来源和限制？
- [ ] 主角是否有性格缺陷或弱点？
- [ ] 主角成长轨迹是否合理？

**金手指设计评估**：
```
优秀金手指设计：
- 来源明确：系统/重生/血脉/传承
- 限制清晰：使用代价/冷却时间/成长条件
- 成长路线：初期弱→中期强→后期巅峰

问题金手指设计：
- 来源不明：突然就有能力
- 无限制：想用就用，无代价
- 无成长：一开始就无敌
```

**成长轨迹审查**：
| 阶段 | 实力成长 | 心智成长 | 身份变化 | 关系变化 |
|------|---------|---------|---------|---------|
| 起点 | 明确初始实力 | 明确初始心智 | 明确初始身份 | 明确初始关系 |
| 中期 | 有突破节点 | 有转变节点 | 有提升节点 | 有变化节点 |
| 终点 | 明确最终实力 | 明确最终心智 | 明确最终身份 | 明确最终关系 |

### 8. 人物出场审查

**检查项**：
- [ ] 主角在本卷的成长是否明确？
- [ ] 重要配角出场是否有规划？
- [ ] 新反派是否有完整设定？
- [ ] 人物关系发展是否合理？

**人物出场规划**：
```
主角成长规划：
- 实力：从XX境界提升到XX境界
- 心智：从XX性格转变为XX性格
- 身份：从XX身份提升到XX身份
- 关系：与XX建立XX关系

配角出场规划：
| 姓名 | 作用 | 出场章节 | 与主角关系发展 |
|------|------|----------|----------------|
| 配角A | 协助主角 | 第X章 | 从陌生到信任 |
| 配角B | 制造冲突 | 第X章 | 从敌对到和解 |

反派设定：
| 姓名 | 身份 | 目的 | 出场章节 | 结局章节 |
|------|------|------|----------|----------|
| 反派A | XX | XX | 第X章 | 第X章 |
```

**反派独立性审查（强制）**：

> 反派的威胁必须针对主角"作为人"的弱点，而非主角"作为能力者"的体系。

**检验公式**：
```
问："如果去掉主角的金手指，这个反派是否依然构成威胁？"
→ 是 ✅ 反派设计合格
→ 否 ❌ 反派只是金手指的配套NPC，必须重新设计
```

**反派独立性检查项**：
- [ ] 反派的威胁是否针对主角"作为人"的弱点（情感/社会/价值观）？
- [ ] 去掉金手指后，反派是否依然是威胁？
- [ ] 反派是否有独立于金手指体系的动机和存在理由？
- [ ] 反派是否使用了与金手指不同体系的力量或手段？
- [ ] 打败反派的方式是否不限于"升级金手指"（如智慧、情感、人际关系）？
- [ ] 反派是否让读者在价值观层面产生动摇或共鸣？

**常见反派独立性缺陷**：
| 缺陷类型 | 表现 | 修复方向 |
|----------|------|----------|
| 体系绑定 | 反派使用金手指的同体系黑暗版 | 让反派使用完全不同的力量或手段 |
| 存在依赖 | 没有金手指就没有反派 | 给反派独立于金手指的动机 |
| 解决方式单一 | 打败反派=升级金手指碾压 | 增加情感抉择、智力博弈等解决路径 |
| 动机薄弱 | 反派只为"变强"或"毁灭" | 给反派与主角价值观对立的深层动机 |

### 9. 爽点节奏审查

**检查项**：
- [ ] 本卷是否有爽点规划？

### 12. 章节标题质量审查（新增，强制）

> **维度说明（强制）**：这是本次新增的审查维度，用于确保章节标题质量，防止叙事功能词/通用词标题。

**检查项**：
- [ ] 是否存在叙事功能词标题？（卷末高潮、卷末铺垫、开篇、过渡、转折等）
- [ ] 是否存在通用词标题？（商行升级、四阶、天赋交易、修炼、突破等）
- [ ] 是否存在全卷重名标题？
- [ ] 是否存在主干重复、人物动作重复、弱区分词伪差异标题？
- [ ] 是否存在连续重复标题？
- [ ] 章节标题是否具体描述本章事件？

**禁止标题类型**：
| 禁止类型 | 错误示例 | 问题说明 |
|---------|---------|---------|
| 叙事功能词 | 卷末高潮、卷末铺垫、开篇、过渡、转折 | 不是具体事件，读者无法产生兴趣 |
| 情绪描述词 | 压抑、爆发、爽点、高潮 | 太抽象，没有信息量 |
| 结构描述词 | 承上启下、衔接、收尾 | 纯功能性描述，无内容 |
| 重复标题 | 连续多章使用相同标题 | 读者无法区分章节 |
| 全卷重名 | 非连续章节使用相同标题 | 读者回查时无法区分章节 |
| 伪差异标题 | 首次交易、再次交易、第三次交易 | 只有弱区分词变化，主干仍重复 |
| 空泛标题 | 新的开始、新的挑战、新的敌人 | 没有具体信息 |
| 通用词标题 | 商行升级、四阶、天赋交易、修炼、突破 | 多章使用同一通用词，无法区分具体内容 |

**正确标题类型**：
| 正确类型 | 正确示例 | 优点 |
|---------|---------|------|
| 具体事件 | 赵家破产、商行升级天赋交易、古武臣服 | 读者一眼知道本章内容 |
| 人物动作 | 林辰出手、苏晚跪求、李叔归顺 | 有画面感，引发好奇 |
| 悬念钩子 | 神秘买家现身、天道之门微启、暗中的敌人 | 制造期待感 |
| 关键物品 | 半块玉佩、商行来信、气运之眼 | 以物引事 |
| 场景转换 | 进京、酒吧开业、古武世界 | 标志格局变化 |

**审查方法**：
```
步骤1：提取所有章节标题
    从 02-卷纲/NN-第X卷-卷名.md 的章节卡片表格中提取所有章节标题

步骤2：检测叙事功能词
    扫描标题中是否包含以下禁用词：
    "卷末高潮""卷末铺垫""开篇""过渡""转折"
    "压抑""爆发""爽点""高潮""承上启下""衔接""收尾"
    "新的开始""新的挑战""新的敌人"
    导航类禁用词（引用统一标准1.5.1节）：
    "下一章""上一章""前一章""后一章""本章""下章""上章""前章"
    "章节回顾""第一卷""第二卷""卷一""卷二""卷末""卷首""卷尾"
    "下一卷""本卷""上卷""下卷""前卷""后卷""第一部""第二部"
    "第一部曲""篇""章回""卷末高潮""本卷高潮""全书高潮""高潮来临"
    "即将高潮""马上高潮""转折点来临""即将转折"
    "根据大纲""按照计划""按照设定""这里应该""作者安排""剧情需要"
    "伏笔回收""埋下伏笔""回扣上文""时间线""故事线""情节线"
    "这一幕""这一段""这一幕戏"

步骤3：检测全卷重名与高度相似标题
    统计所有标题出现次数
    相同标题在任意两章出现 → 标记为问题
    仅替换"再""又""继续""新的"等弱区分词 → 标记为伪差异问题
    同一人物+同一动作组合重复出现 → 标记为问题
    问题类型固定枚举：通过 / 完全重复 / 主干重复 / 人物动作重复 / 伪差异 / 禁用词
    处理结论固定枚举：保留 / 重写标题 / 回退卷纲层修复 / 回退章纲层修复 / 阻塞待修
    生成"标题冲突审查表"：| 序号 | 标题 | 来源位置 | 冲突对象 | 问题类型 | 处理结论 |

步骤4：检测通用词重复
    统计每个通用词出现的次数：
    "商行升级""四阶""天赋交易""修炼""突破"等
    同一通用词出现≥2次 → 标记为问题

步骤5：检测连续重复标题
    检查相邻章节是否使用相同标题
    连续≥2章相同标题 → 标记为问题
    发现连续重复或全卷重名 → 阻塞，不得放行为"轻微问题"
```

**文件对照**：
- 对照文件：`02-卷纲/NN-第X卷-卷名.md`（卷纲文件，含章节卡片表格）
- 参考标准：`novel-writer-master/统一标准.md` 第八节（章节标题命名规范）
