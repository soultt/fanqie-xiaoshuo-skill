# 大卷纲分段审查规范

> **模板引用**：本文件由 `SKILL.md` 引用，包含大卷纲分段审查机制的完整定义。

---

## 核心规则

> **当卷纲章节数超过30章时，必须使用分段审查机制，避免因token限制导致审查不完整。**

---

## 触发条件

| 卷纲章节数 | 审查模式 | 说明 |
|-----------|---------|------|
| ≤30章 | 全量审查 | 一次性审查全部章节 |
| 31-60章 | 分2段审查 | 每段约30章 |
| 61-100章 | 分3段审查 | 每段约30-35章 |
| >100章 | 分4+段审查 | 每段不超过30章 |

---

## 分段规则

```
分段计算公式：
段数 = ceil(总章节数 / 30)

分段示例：
- 50章卷纲：分2段（第1-30章 / 第31-50章）
- 80章卷纲：分3段（第1-27章 / 第28-54章 / 第55-80章）
- 125章卷纲：分5段（每段25章）
```

---

## 分段审查流程

```
┌─────────────────────────────────────────────────────────┐
│  大卷纲分段审查流程                                      │
├─────────────────────────────────────────────────────────┤
│ 步骤1：识别卷纲章节数                                     │
│     判断是否需要分段（>30章）                             │
│                                                          │
│ 步骤2：计算分段方案                                       │
│     段数 = ceil(总章节数 / 30)                           │
│     确定每段的章节范围                                    │
│                                                          │
│ 步骤3：逐段执行审查                                       │
│     for 每段 in 分段列表:                                │
│         - 提取本段章节卡片                                │
│         - 执行章节卡片详细度审查                          │
│         - 生成本段审查报告                                │
│         - 保存本段报告                                    │
│                                                          │
│ 步骤4：合并审查报告                                       │
│     - 汇总各段问题数量                                   │
│     - 合并P0/P1/P2问题清单                               │
│     - 生成整体审查结论                                   │
│                                                          │
│ 步骤5：输出完整审查报告                                   │
│     保存到：07-审查报告/大纲审查/第X卷-分段审查报告.md    │
└─────────────────────────────────────────────────────────┘
```

```markdown
- **分段数量**：X段
- **审查模式**：分段审查

|------|----------|----------|-----------|--------|--------|--------|
| 第1段 | 第N-M章 | XX章 | XX章 | X个 | X个 | X个 |
| 第2段 | 第N-M章 | XX章 | XX章 | X个 | X个 | X个 |
| ... | ... | ... | ... | ... | ... | ... |
| **总计** | - | XX章 | XX章 | X个 | X个 | X个 |

## 各段详细问题清单

### 第1段（第N-M章）
#### P0级问题
| 章节 | 问题 | 修改建议 |
|------|------|----------|

#### P1级问题
| 章节 | 问题 | 修改建议 |
|------|------|----------|

### 第2段（第N-M章）
...

## 整体审查结论
- **总体达标率**：XX%
- **主要问题类型**：[缩略描述/字数不足/结构缺失]
- **修改优先级**：先修复P0问题，再处理P1问题
- **预计修复时间**：约XX分钟
```

---

## 分段审查注意事项

1. **每段审查独立保存**：避免token限制导致报告丢失
2. **段间衔接检查**：检查相邻段之间的衔接是否自然
3. **合并时去重**：同一问题在相邻段可能重复报告
4. **优先级排序**：合并后按P0→P1→P2排序问题清单
5. **进度反馈**：每完成一段向用户报告进度
