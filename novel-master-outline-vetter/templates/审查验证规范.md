# 审查强制工具验证规范

> **模板引用**：本文件由审查技能引用，定义审查过程中必须执行的强制工具验证机制。

---

## 核心原则

> **最高优先级说明（强制）**：审查必须使用工具验证，禁止仅口头声明。

**问题背景**：
- ❌ 审查时只是口头声明"已检查"，没有实际执行工具调用
- ❌ 跳过某些检查项，导致问题遗漏
- ❌ 抽查部分内容，而非全量验证

**解决方案**：
- ✅ 每个检查项必须使用工具验证
- ✅ 必须输出工具调用结果作为证据
- ✅ 禁止仅口头声明"通过"或"无问题"

## 四、禁止行为清单

### 4.0 禁止依赖记忆（最高优先级）

> **风险说明（强制）**：这是导致审查结果错误的根本原因。

```
核心问题：记忆压缩导致内容不符

问题描述：
- AI在长对话中会将之前读取的文件内容压缩存储在记忆中
- 压缩后的记忆可能丢失细节、改变顺序、甚至出现错误
- 如果审查时依赖记忆而非重新读取文件，会导致审查结果与实际文件不符

错误示例：
❌ "根据之前读取的总纲，核心钩子是xxx"（依赖记忆）
❌ "我记得卷纲中第5章的事件是xxx"（依赖记忆）
❌ "之前检查过这个文件，内容是xxx"（依赖记忆）

正确示例：
✅ 每次审查时重新执行 Read 工具读取文件
✅ 不依赖之前对话中的任何记忆内容
✅ 以本次 Read 工具返回的结果为准
```

**强制规定**：

| 规定 | 说明 | 违反后果 |
|------|------|----------|
| **禁止依赖记忆** | 不得使用"之前读取"、"我记得"等表述 | 审查结果无效，必须重审 |
| **强制重新读取** | 每个检查项必须执行 Read 工具 | 未执行 Read → 检查项无效 |
| **以文件为准** | 记忆与文件冲突时，以文件为准 | 必须输出 Read 结果作为证据 |
| **禁止记忆引用** | 不得引用之前对话中的文件内容 | 必须重新读取当前文件 |

**记忆压缩风险场景**：

| 场景 | 风险 | 解决方案 |
|------|------|----------|
| 长对话后审查 | 记忆被压缩，丢失细节 | 每次审查重新 Read |
| 多文件审查 | 记忆混淆不同文件内容 | 每个文件单独 Read |
| 修改后审查 | 记忆中是旧版本内容 | 重新 Read 获取最新版本 |
| 跨会话审查 | 记忆完全不包含文件内容 | 必须重新 Read 所有文件 |

### 4.1 绝对禁止

```
❌ 禁止行为：

1. 仅口头声明"已检查"而不执行工具调用
   错误示例："已检查人物状态冲突，无问题"（无工具调用）
   正确示例：执行 Read 工具读取前章和本章，输出对比结果

2. 跳过某些检查项
   错误示例："时间线冲突检查跳过"（无理由跳过）
   正确示例：执行 Read 工具验证时间线，输出验证结果

3. 抽查部分内容而非全量验证
   错误示例："抽查了第5章和第10章"（只检查部分章节）
   正确示例：对所有章节执行全量验证

4. 以"篇幅限制"为由省略验证
   错误示例："由于篇幅限制，省略部分验证"
   正确示例：必须执行所有验证，可分批输出

5. 不输出工具调用结果作为证据
   错误示例："验证通过"（无证据）
   正确示例：输出工具调用结果，如"Read 结果显示：第5章结尾伤势=骨折，第6章开头伤势=完好，存在冲突"

6. 依赖记忆而非重新读取文件（最高优先级）
   错误示例："根据之前读取的总纲..."或"我记得卷纲中..."
   正确示例：每次审查重新执行 Read 工具，以本次读取结果为准
```

### 4.2 审查报告必须包含的内容

```
✅ 审查报告必须包含：

1. 每个检查项的工具调用记录
   格式：[检查项] 执行 Read xxx.md，结果：xxx

2. 每个检查项的验证结果
   格式：[检查项] 验证结果：通过/不通过，原因：xxx

3. 发现问题的详细描述
   格式：[问题] 第X章与第Y章存在冲突：xxx

4. 修复建议
   格式：[建议] 修改第X章xxx内容为xxx
```

## 六、流程控制机制（防止流程跳出）

> **流程说明（强制）**：本章节用于解决流程跳出问题，确保审查流程完整执行。

### 6.1 流程跳出风险点

| 风险点 | 说明 | 解决方案 |
|--------|------|----------|
| 确认后跳过 | 确认清单后没有强制阻塞机制 | 添加节点完成确认机制 |
| 口头声明 | 只说"已检查"而不执行工具调用 | 强制要求输出工具调用结果 |
| 警告不阻塞 | 发现问题只是警告，继续执行 | 将警告升级为阻塞 |
| 流程中断 | 中途停止不输出报告 | 强制要求完成所有节点 |
| **依赖记忆** | **使用记忆而非重新读取文件** | **强制每次执行 Read 工具** |
