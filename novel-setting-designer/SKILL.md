## 模块一：核心冲突与反派生长设计

### 反派与金手指解绑规则（最高优先级）

> **核心原则**：反派必须与故事的**核心冲突、主题、情感线**深度绑定，但必须与**力量体系/金手指**解绑。
>
> 反派不能脱离故事——反派是故事的引擎，不是金手指的配套。
> 反派必须脱离金手指——反派的存在理由不能是"给金手指提供对手盘"。

**规则一：反派源于故事核心冲突，不是预先设定的**

```
正确理解：
故事推进中，核心冲突逐渐浮现 → 反派从冲突中自然生长出来 → 金手指是应对工具

错误理解：
先确定一个固定反派（如地产商） → 再编故事来配合这个反派
```

**故事核心冲突的5个来源**（反派必须与至少一个绑定）：

| 冲突来源 | 核心张力 | 反派可能形态（示例） |
|----------|----------|-------------------|
| **情感线** | 主角在乎的人/事被威胁 | 养父、初恋、挚友、仇人之子、被辜负的恩师... |
| **社会线** | 主角的生存空间被挤压 | 地产商、官僚、媒体、资本、行业协会... |
| **价值观线** | 主角的信念被挑战 | 理想主义者、实用主义者、程序正义者... |
| **命运线** | 主角的过去/身世被揭开 | 知情者、共谋者、掩盖者、复仇者... |
| **主题线** | 故事探讨的核心议题 | 正义vs秩序、自由vs安全、真相vs和谐... |

**执行方式**：在设计设定之前，必须先回答：
1. 这个故事的**核心冲突**是什么？
2. 这个冲突源于哪条线？（情感/社会/价值观/命运/主题）
3. **随着冲突发展，会浮现什么样的对手？**
4. 反派的动机是否与**故事主题**相关？
5. 去掉金手指后，这个冲突/对手是否依然是**故事的核心威胁**？（必须回答"是"）

**规则二：命名隔离（禁止与金手指共享关键词）**

反派相关的一切命名，禁止与金手指/力量体系共享任何关键词。

| 禁止行为 | 典型表现 | 危害 |
|----------|----------|------|
| 反派组织名包含金手指关键词 | 金手指关键词出现在反派组织名中 | 暴露绑定关系 |
| 反派能力名与金手指同源 | 反派的能力是金手指的"黑暗版" | 体系绑定 |
| 主角组织名与金手指相关 | 主角团队名围绕金手指命名 | 世界围绕金手指运转 |
| 反派目标与金手指功能相关 | 反派想做的事是金手指功能的反面 | 功能绑定 |

**检验方法**：列出金手指的所有核心关键词，再列出反派相关的所有命名，检查是否有任何重叠。

**规则三：冲突维度必须多元**

正反冲突必须在以下至少3个维度上展开：

| 维度 | 说明 | 示例 |
|------|------|------|
| 情感维度 | 反派威胁主角在乎的人 | 反派绑架了主角的妹妹 |
| 社会维度 | 反派利用世俗力量压迫主角 | 反派利用媒体抹黑主角 |
| 价值观维度 | 反派的逻辑让主角动摇 | 反派说"你帮的那些人，真的想被帮吗？" |
| 智力维度 | 反派比主角更聪明 | 反派设局让主角自投罗网 |
| 法律维度 | 反派利用规则合法作恶 | 反派的操作全部合法 |

## 模块二：人物设定设计

### 动态人设坐标系

每个角色在"道德底线值"与"欲望燃烧度"两个维度上要有明确坐标，并预设位移节点。

**主角成长线**（根据题材自定义）：
```
格式：第X-Y章：[实力变化] + [心智变化]
示例（修仙）：第1-100章：炼气→筑基（实力）+ 懵懂→觉醒（心智）
示例（都市）：第1-100章：普通人→小有名气（社会地位）+ 自卑→自信（心智）
示例（悬疑）：第1-100章：一无所知→掌握关键线索（信息）+ 被动→主动（心智）
```

**配角定位**（根据故事需要自定义角色数量和关系）：
| 角色 | 道德底线 | 欲望燃烧度 | 与主角关系 |
|------|----------|------------|------------|
| （根据故事设定） | | | |

### 反派与金手指解绑设计原则

> **核心原则**：反派的威胁必须针对主角"作为人"的弱点，而非主角"作为能力者"的体系。

**常见错误模式（必须避免）**：

| 错误模式 | 表现 | 危害 |
|----------|------|------|
| 反派是金手指的黑暗版 | 金手指=读心，反派=植念 | 反派工具化 |
| 反派使用同体系力量 | 金手指=火系，反派=暗火系 | 冲突单一 |
| 反派的存在依赖金手指 | 没有金手指就没有反派 | 世界观围绕金手指运转 |
| 打败反派=升级金手指 | 冲突解决方式只有能力碾压 | 缺少情感和智力维度 |

**反派与金手指解绑检验维度**：

| 检验维度 | 核心问题 |
|----------|----------|
| 威胁来源 | 反派的威胁是否来自世俗权力/社会资源/人际关系/智力，而非超能力？ |
| 能力关系 | 反派是否与金手指处于完全不同的力量体系，或根本没有超能力？ |
| 情感关系 | 反派与主角的关系是否基于情感/血缘/师承/利益，而非能力对抗？ |
| 价值观对立 | 反派的逻辑是否让主角在价值观层面动摇，而非仅仅在能力层面被打压？ |
| 信息不对称 | 反派是否不知道金手指的存在，或金手指对反派完全无效？ |

**反派与金手指解绑检验公式**（设计反派时必须通过）：
```
问："如果去掉主角的金手指，这个反派是否依然构成威胁？"
→ 是 ✅ 反派与金手指已解绑
→ 否 ❌ 反派只是金手指的配套NPC，必须重新设计
```

**反派设计自检清单**：
- [ ] 反派的威胁是否针对主角"作为人"的弱点？
- [ ] 去掉金手指后，反派是否依然是威胁？
- [ ] 反派是否有独立于金手指体系的动机？
- [ ] 打败反派的方式是否不限于"升级金手指"？
- [ ] 反派是否让读者在情感/价值观层面产生动摇？

## 模块三：世界观设定设计

### 世界观设定要素

1. **力量体系设定**：等级划分、晋升规则、能力类型、限制与代价、社会影响
2. **势力分布设定**：主要势力（名称/性质/规模/核心利益/与主角关系）、势力关系、势力动态
3. **地理设定**：世界地理格局、重要地点、势力据点
4. **时间线设定**：重大历史事件、关键时间节点
5. **物品装备设定**：重要道具、神器法宝、特殊资源
