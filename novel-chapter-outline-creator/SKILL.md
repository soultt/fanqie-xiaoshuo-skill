## 核心原则（强制）：严格遵循卷纲

**章纲创作必须严格遵循卷纲，不得脱离卷纲自行推演！**

每章章纲都必须：

1. **首先读取卷纲中对应章节的内容**（核心事件、爽点设计、伏笔埋设、卡点设计）
2. **严格按照卷纲的核心事件展开**，不得擅自更改主要情节
3. **爽点设计必须与卷纲一致**，不得增减或改变爽点类型
4. **伏笔埋设必须与卷纲一致**，不得遗漏或新增卷纲未规划的伏笔
5. **卡点设计必须与卷纲一致**，确保与后续章节衔接

**禁止行为（强制）**：

- ❌ 脱离卷纲核心事件自行编造情节
- ❌ 更改卷纲规定的爽点类型和强度
- ❌ 遗漏卷纲规定的伏笔埋设
- ❌ 更改卷纲规定的卡点设计

│   ├── 主角.md
│   ├── 配角.md
│   └── 反派.md
│
├── 04-世界观/                         ← 输入：设定一致性
│   ├── 力量体系.md
│   ├── 势力分布.md
│   ├── 地理设定.md
│   ├── 时间线.md

├── 05-章纲/                           ← 输出目录
│   └── NN-第X卷-卷名/
│       └── 第XXX章-章节标题.md        ← 输出：本章章纲（每章一个文件，禁止多章合并）
│
├── 06-正文/                           ← 下游输出参考
│   └── NN-第X卷-卷名/
│       └── 第XXX章-章节标题.md
│
├── 07-审查报告/                       ← 可选输出

> **卷定位规则**：NN 通过读取 `01-总纲/总纲.md` 中的分卷规划表确定。详见 [章纲标准速查](./templates/章纲标准速查.md) 第七节。

### 章纲文件结构规范（强制执行）

> **禁止事项（强制）**：禁止将多个章节合并到一个章纲文件中。

| 要求         | 说明                                              |
| ---------- | ----------------------------------------------- |
| **每章一个文件** | 第001章必须对应 `第001章-xxx.md`，不允许 `第001-010章-xxx.md` |
| **文件名格式**  | `第XXX章-章节标题.md`（XXX为三位数字，左补零）                   |
| **章节号唯一**  | 每个章节号对应且仅对应一个章纲文件                               |

**示例（正确）**：

```
✓ 第001章-普通的一天.md
✓ 第002章-零点的礼物.md
✓ 第003章-初次战斗.md
```

### 章纲约束清单机制（关键）

**每章章纲必须同时生成章纲约束清单**，供下游技能（novel-chapter-writer）读取：

```
08-约束清单/章纲约束/NN-第X卷-卷名/
├── 第001章-约束清单.md     ← 第1章约束清单
├── 第002章-约束清单.md     ← 第2章约束清单
├── 第003章-约束清单.md     ← 第3章约束清单
└── ...
```

**章纲约束清单作用**：

1. **持久化约束信息**：不依赖上下文，写入文件确保跨章节传递
2. **强制读取机制**：novel-chapter-writer 必须读取此文件，不存在则停止
3. **状态同步**：包含前章结尾人物状态，确保连贯性

## 章纲自检要点

创建完成后，对照以下要点进行自审：

### 卷纲符合性（最重要，强制优先）
- [ ] 核心事件与卷纲完全一致
- [ ] 爽点类型和强度与卷纲一致
- [ ] 伏笔与卷纲一致
- [ ] 卡点与卷纲一致

### 结构完整性
- [ ] 包含完整的四部分结构
- [ ] 各部分字数分配合理
- [ ] 总字数达1900非空白字符基准（允许合理波动，不低于1800）

### 内容质量
- [ ] 开头钩子有吸引力
- [ ] 剧情发展推进主线
- [ ] 高潮有情绪爆发力
- [ ] 卡点能驱动下一章

### 人物一致性
- [ ] 主角行为符合人设
- [ ] 配角出场有必要
- [ ] 人物对话符合性格

> **修改章纲后必须同步更新章纲约束清单**：详见 [执行流程](./templates/执行流程.md) 中"章纲修改后同步流程"章节。

## 使用示例

### 示例：创建第15章章纲

**用户输入**："创建第15章章纲，第一卷"

**执行流程**：

1. **读取输入文件**：
   - `01-总纲/总纲.md`
   - `02-卷纲/NN-第一卷-觉醒篇.md`（卷纲文件，含章节卡片表格）
   - `03-人物设定/主角.md`
   - `05-章纲/NN-第一卷/第014章-xxx.md`（前一章）
2. **提取卷纲章节内容**：从章节卡片表格中提取第15章内容（标题、核心事件、爽点、伏笔、卡点）
3. **分析章节定位**：确定第15章的任务和在卷中位置
4. **设计四部分结构**：严格基于卷纲展开
5. **规划爽点与伏笔**：与卷纲保持一致
6. **输出章纲文件**：`05-章纲/NN-第一卷/第015章-章节标题.md`
7. **生成章纲约束清单**：`08-约束清单/章纲约束/NN-第一卷/第015章-约束清单.md`
8. **卷纲符合性自审**：确认所有内容与卷纲一致

## 执行注意事项

1. **严格遵循卷纲（强制）**：章纲创作必须严格遵循卷纲，不得脱离卷纲自行推演
2. **字数统计**：正文写作目标为2100非空白字符，章纲分配基准为1900非空白字符
3. **情节连贯**：创建前必须查看前一章章纲，确保情节连贯
4. **任务明确**：每章必须有1-2个明确的任务
5. **卡点有效**：卡点必须有足够的吸引力，避免强行制造悬念
6. **人设一致**：人物行为必须符合人设
7. **爽点适度**：爽点强度要与章节位置匹配
8. **伏笔合理**：伏笔要有回收计划
9. **卷纲优先**：如发现章纲与卷纲不一致，必须以卷纲为准
