# 卷纲章节内容提取模板

**关键说明（强制）**：这是最关键的步骤，必须首先完成。

## 核心原则：章节标题必须从卷纲提取

> **执行要求（强制）**：禁止自行拟定标题。

```
错误示例：
❌ 卷纲标题"首次交易"，章纲标题"初试能力"（自行拟定）
❌ 卷纲标题"赵家破产"，章纲标题"赵浩倒台"（自行拟定）

正确示例：
✅ 卷纲标题"首次交易"，章纲标题"首次交易"（一致）
✅ 卷纲标题"赵家破产"，章纲标题"赵家破产"（一致）
```

## 操作方法

> **批量创建要求（强制）**：批量创建时，每章必须使用工具重新打开卷纲文件，禁止依赖上下文记忆。

1. **使用工具重新打开**对应卷纲文件（如 `02-卷纲/NN-第一卷-觉醒篇.md`），了解本卷核心任务、爽点规划、伏笔规划
2. 从章节卡片表格中找到对应章节行
3. **逐字复制**以下五项核心内容（含章节标题），不得凭记忆修改

## 提取模板

```markdown
## 卷纲章节内容提取（第XXX章）

### 来源
- **卷纲文件**：NN-第X卷-卷名.md（含章节卡片表格）
- **章节位置**：第X阶段/第XXX章

### 提取内容

#### 0. 章节标题（必须严格遵循，禁止自行拟定）
- **卷纲规定**：从章节卡片表格中复制标题内容
- **禁止修改（强制）**：章节标题必须与卷纲完全一致，不得自行拟定

#### 1. 核心事件（必须严格遵循）
- **卷纲规定**：从章节卡片表格中复制核心事件内容
- **章纲展开方向**：基于核心事件进行细节展开，不得改变核心事件本身

#### 2. 爽点设计（必须严格遵循）
- **卷纲规定**：从章节卡片表格中复制爽点设计内容
- **爽点类型**：无/小爽点/中爽点/大爽点
- **章纲展开方向**：基于爽点设计进行细节展开

#### 3. 伏笔埋设（必须严格遵循）
- **卷纲规定**：从章节卡片表格中复制伏笔埋设内容
- **伏笔类型**：有/无
- **章纲展开方向**：基于伏笔埋设进行细节展开，不得遗漏

#### 4. 卡点设计（必须严格遵循）
- **卷纲规定**：从章节卡片表格中复制卡点设计内容
- **章纲展开方向**：基于卡点设计进行细节展开，确保与下章衔接
```

## 提取示例（第5章）

```markdown
## 卷纲章节内容提取（第5章）

### 来源
- **卷纲文件**：NN-第一卷-觉醒篇.md（含章节卡片表格）
- **章节位置**：第一阶段：觉醒篇/第5章

### 提取内容

#### 0. 章节标题（必须严格遵循，禁止自行拟定）
- **卷纲规定**：首次交易
- **禁止修改（强制）**：章节标题必须为"首次交易"，不得改为"初试能力"等

#### 1. 核心事件（必须严格遵循）
- **卷纲规定**：林辰首次使用商行交易能力，将赵浩的霉运交易给自己，获得10万现金
- **章纲展开方向**：展开交易过程、能力使用细节、获得现金的描写

#### 2. 爽点设计（必须严格遵循）
- **卷纲规定**：小爽点——首次成功交易，获得10万现金
- **爽点类型**：小爽点
- **章纲展开方向**：强调"废物"到"有钱人"的转变，设计内心独白

#### 3. 伏笔埋设（必须严格遵循）
- **卷纲规定**：无
- **伏笔类型**：无
- **章纲展开方向**：无需埋设伏笔

#### 4. 卡点设计（必须严格遵循）
- **卷纲规定**：10万到账，林辰看着余额冷笑："谁是废物？"
- **章纲展开方向**：设计交易完成后的场景，引出下章打脸情节
```
