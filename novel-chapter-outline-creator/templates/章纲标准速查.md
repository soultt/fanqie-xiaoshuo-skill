> **来源**：`novel-writer-master/统一标准.md` v2.8（2026-05-25）

## 一、字数标准

### 1.1 章纲字数要求
- **章纲基准**：≥1900非空白字符（分配基准）
- **允许范围**：1800-2100非空白字符
- **正文目标**：≥2100非空白字符（由章纲扩展而来）
- **字数过多阈值**：>2200字符建议精简

### 1.2 四部分结构字数分配（章纲基准）

| 部分 | 标准值 | 范围 |
|------|--------|------|
| 开头钩子 | 约250字符 | 200-300字符 |
| 剧情发展 | 约650字符 | 600-700字符 |
| 情绪高潮 | 约600字符 | 500-700字符 |
| 章节卡点 | 约400字符 | 350-450字符 |

### 1.3 字数统计规则
```python
non_space_chars = len([c for c in content if not c.isspace()])
# 包含：汉字、标点符号、英文字母、数字、特殊符号等所有非空白字符
# 不包含：空格、换行符、制表符等空白字符
```

## 二、对话规范

### 2.1 对话占比要求
- **正文对话占比**：≥60%（对话字符占正文总非空白字符的比例）
- **章纲规划要求**：每章必须规划足够的对话场景

### 2.2 单段对话长度限制
- **单段对话上限**：≤150非空白字符
- **超长对话处理**：拆分对话+动作打断，避免大段独白

## 三、爽点间隔标准

| 爽点强度 | 推荐间隔（章节数） | 说明 |
|---------|------------------|------|
| 小爽点 | 3-5章 | 日常情节保持节奏 |
| 中爽点 | 20-30章 | 阶段性高潮 |
| 大爽点 | 50-100章 | 卷末全书高潮 |

## 四、禁止词汇

### 4.1 完整禁止词汇列表（强制）

**章纲正文均适用**，以下词汇禁止出现在正文中：

| 类别 | 示例词汇 | 正确表达建议 |
|------|---------|-------------|
| **卷/部结构词** | 第一卷、卷首、卷末、本卷、上卷、下卷 | 第一章、这一章、上一章、下一章 |
| **章节导航词** | 本章、下一章、上一章、上节、下节 | 这里、这里、接下来、先前 |
| **高潮/转折导航词** | 卷末高潮、全书高潮、高潮来临、高潮到来 | 激烈冲突、关键时刻 |
| **规划性词汇** | 根据大纲、按照计划、伏笔回收、按计划 | （直接写情节，无需说明） |
| **时序导航词** | 时间线、故事线、这一幕、这一场 | 这时、此刻、当下 |

### 4.2 大纲导航类字眼检查清单

| 检查项 | 要求 |
|--------|------|
| 卷/部结构词 | □ 正文中不得出现 |
| 章节导航词 | □ 正文中不得出现 |
| 高潮/转折导航词 | □ 正文中不得出现 |
| 规划性词汇 | □ 正文中不得出现 |
| 时序导航词 | □ 正文中不得出现 |

**违反上述任一事项 → 标记为问题，需修改**

## 五、章纲文件规范

### 5.1 文件命名规则
- **格式要求**：`第XXX章-章节标题.md`
- **章节编号**：三位数字，左补零（第1章 → `第001章`）
- **禁止行为**：禁止多章合并（如 `第001-010章-xxx.md`）

### 5.2 文件结构要求
- 必须包含YAML头部（`--- ... ---`）
- 必须包含一级标题 `# 第XXX章：《章节标题》`
- 必须包含 `卷纲对照` 部分
- 必须包含完整的四部分结构
- 必须包含 `爽点设计` 部分
- 必须包含 `卡点设计` 部分

## 六、章节标题唯一性标准

### 6.1 标题冲突定义

| 冲突类型 | 定义 | 处理方式 |
|---------|------|---------|
| **完全重复** | 标题文字完全相同 | 返回卷纲层修复 |
| **主干重复** | 核心动词/名词相同，仅修饰词不同 | 返回卷纲层修复 |
| **人物动作重复** | 都是"XX打脸YY"结构，换人名 | 返回卷纲层修复 |
| **伪差异** | 文字不同但语义高度相近 | 返回卷纲层修复 |

### 6.2 冲突检查表格式

```markdown
## 章纲标题唯一性检查表

| 序号 | 标题 | 来源位置 | 冲突对象 | 问题类型 | 处理结论 |
|------|------|----------|---------|----------|----------|
| 1 | 首次交易 | 第005章 | - | 通过 | 保留 |
| 2 | 赵家破产 | 第012章 | - | 通过 | 保留 |
```

### 6.3 处理结论枚举值

| 值 | 含义 |
|---|------|
| 通过 | 无冲突，保留 |
| 保留 | 无冲突，保留 |
| 重写标题 | 轻微差异，在章纲层重写 |
| 回退卷纲层修复 | 严重冲突，必须回到卷纲层修改 |
| 回退章纲层修复 | 章纲层面可修复，在章纲层修改 |
| 阻塞待修 | 冲突未解决，阻塞等待修复 |

### 6.4 强制处理规则
- **发现完全重复/主干重复 → 强制阻塞**，必须返回卷纲层修改
- 禁止在章纲层私自改名绕过冲突检查
- 每批创建后必须检查表，不能跳过

## 七、卷定位规则

当路径中出现 `NN-第X卷-卷名` 时：
- `NN` 通过读取 `01-总纲/总纲.md` 中的分卷规划表确定
- 分卷规划表中列出每卷对应的序号
- 按表格映射替换路径中的 `NN`

**示例**：
- 表格中：`01 → 第一卷-觉醒篇`
- 实际路径：`05-章纲/01-第一卷-觉醒篇/第001章-xxx.md`

## 八、约束传递机制

### 8.1 约束清单作用
1. **持久化约束信息**：不依赖上下文，写入文件确保跨章节传递
2. **强制读取机制**：下游技能必须读取此文件，不存在则停止
3. **状态同步**：包含前章结尾人物状态，确保连贯性

### 8.2 文件保存位置
```
08-约束清单/章纲约束/NN-第X卷-卷名/第XXX章-约束清单.md
```

## 九、输出验证标准

### 9.1 验证通过条件
- 全部验证项通过 → 可以输出
- 存在警告 → 可以输出，但建议优化
- 存在失败 → 必须修复后才能输出

### 9.2 强制失败项（必须修复）
- 文件格式错误
- 必填内容缺失
- 章节标题来源不一致
- 章节标题冲突
- 卷纲符合性验证失败
- 章纲约束清单不存在
- 章纲约束清单内容不完整
- 一致性验证失败
