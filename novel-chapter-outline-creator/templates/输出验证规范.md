## 验证失败处理

| 验证项 | 失败处理 |
|--------|----------|
| 文件格式 | 修复文件格式后重新验证 |
| 必填内容 | 补充缺失内容后重新验证 |
| 字数分配 | 警告：建议扩充；严重不足必须修复 |
| **章节标题来源** | **必须修复**：使用卷纲标题替换，禁止自行拟定 |
| **章节标题冲突** | **强制阻塞**：必须回到卷纲层修复，禁止在章纲层改名绕过 |
| 卷纲符合性 | **必须修复**：不得输出不符合卷纲的章纲 |
| 标准一致性 | 修正为标准值后重新验证 |
| **章纲约束清单** | **强制阻塞**：必须重新生成章纲约束清单，不得输出章纲，不得进入下一章 |

## 验证通过标准

- **全部通过**：可以输出文件
- **存在警告**：可以输出，但建议优化
- **存在失败**：必须修复后才能输出
