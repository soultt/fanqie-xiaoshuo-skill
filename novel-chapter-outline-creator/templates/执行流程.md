# 章纲创建执行流程

> **说明**：本文件从 SKILL.md 拆分而来，包含完整的强制约束检查、阻塞式执行机制、创建步骤和输出验证。
> 主文件引用位置：`../SKILL.md` → "执行流程"章节

## 阻塞式执行机制（强制）

**每个阶段必须完成才能进入下一个阶段，不可跳过任何阶段。**

### 执行规则（强制）

- **规则1**：必须按顺序执行，不可跳过任何阶段
- **规则2**：每个阶段必须输出完成确认
- **规则3**：阶段零检查未通过 → 强制阻塞，必须修复后重查
- **规则4**：每个阶段完成后必须勾选确认，才能进入下一阶段
- **规则5**：最终输出必须包含所有阶段的完成确认

### 节点完成确认清单

**每完成一个阶段，必须勾选确认**：

- [ ] **节点0**：阶段零（强制约束检查）已完成
- [ ] **节点1**：阶段一（信息收集）已完成
- [ ] **节点2**：阶段二（章节定位）已完成
- [ ] **节点3**：阶段三（结构设计）已完成
- [ ] **节点4**：阶段四（内容设计）已完成
- [ ] **节点5**：阶段五（爽点与伏笔设计）已完成
- [ ] **节点6**：阶段六（人物与对话规划）已完成
- [ ] **节点7**：阶段七（章纲约束清单生成与同步）已完成
- [ ] **节点8**：输出验证（章纲文件+章纲约束清单存在）已完成

**未全部勾选 → 章纲创建未完成，不得输出完成声明**

### 阻塞触发条件

> **阻塞说明（强制）**：所有触发条件均为强制阻塞，不得以任何理由跳过。

| 触发条件              | 阻塞级别        | 处理方式                    |
| ----------------- | ----------- | ----------------------- |
| 总纲/卷纲/人物设定文件不存在   | 强制阻塞     | 立即停止，报告缺失文件             |
| 章节标题重复            | 强制阻塞     | 立即停止，修改标题               |
| 章纲约束清单生成失败        | 强制阻塞     | 立即停止，重新生成               |
| **章纲约束清单内容不完整** | **强制阻塞** | **立即停止，补充内容后重新验证**      |
| **章纲约束清单验证未通过** | **强制阻塞** | **立即停止，修复后重新验证，不得输出章纲** |
| **章纲与卷纲原文不一致** | **强制阻塞** | **立即停止，修正章纲后重新验证**      |
| **未重新核对卷纲文件**  | **强制阻塞** | **立即停止，重新核对卷纲文件后再继续**   |
| 阶段七被跳过            | 强制阻塞     | 禁止跳过，必须执行               |
| 任何阶段未执行           | 强制阻塞     | 补全后才能输出完成声明             |

## 批量创建流程控制（强制）

**批量创建要求（强制）**：批量创建多章章纲时，必须严格遵循以下流程。

### 循环控制机制

```
┌─────────────────────────────────────────────────────────┐
│  🔄 批量创建循环控制（强制）                              │
├─────────────────────────────────────────────────────────┤
│                                                          │
│ FOR 章节号 = 起始章 TO 结束章:                           │
│                                                          │
│   步骤0：重新核对卷纲文件（每章必须执行，不可跳过）     │
│      → 重新查看卷纲文件全文                               │
│      → 从章节卡片表格中定位本章行                         │
│      → 提取本章的标题、核心事件、爽点、伏笔、卡点         │
│      → ❌ 核对失败或本章行不存在 → 立即停止               │
│      → ✅ 成功提取 → 继续步骤1                            │
│                                                          │
│   步骤1：创建本章章纲（阶段0-6）                          │
│      → ❌ 失败 → 立即停止，报告错误                      │
│      → ✅ 成功 → 继续步骤2                               │
│                                                          │
│   步骤2：生成章纲约束清单（阶段7）                        │
│      → ❌ 失败 → 立即停止，重新生成                      │
│      → ✅ 成功 → 继续步骤3                               │
│                                                          │
│   步骤3：验证输出（阶段8）                                │
│      → ❌ 章纲约束清单不存在 → 立即停止，重新生成         │
│      → ❌ 章纲约束清单不完整 → 立即停止，补充内容         │
│      → ❌ 章纲与卷纲原文不一致 → 立即停止，修正章纲       │
│      → ✅ 验证通过 → 继续步骤4                           │
│                                                          │
│   步骤4：输出章节完成确认                                 │
│      → ✅ 第XXX章创建完成（章纲+章纲约束清单已验证）      │
│      → ✅ 才能进入下一章                                 │
│                                                          │
│ END FOR                                                  │
│                                                          │
│ ❌ 禁止：                                                 │
│   - 跳过步骤0（不重新核对卷纲）                           │
│   - 依赖"上下文记忆"代替重新核对卷纲文件                  │
│   - 先创建多章章纲，再统一生成章纲约束清单                │
│   - 章纲约束清单未验证通过时进入下一章                   │
│   - 以"效率"为由跳过单章验证                             │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 批量创建禁止行为

| 禁止行为                 | 说明                     |
| -------------------- | ---------------------- |
| 跳过步骤0（不重新核对卷纲）      | 每章必须重新核对卷纲文件，禁止依赖上下文记忆 |
| 依赖"上下文记忆"代替重新核对卷纲 | 上下文记忆不可靠，必须以当前文件内容为准   |
| 先创建多章章纲，再统一生成章纲约束清单 | 必须每章完成后立即生成章纲约束清单    |
| 章纲约束清单未验证通过时进入下一章   | 必须验证通过才能进入下一章          |
| 以"效率"为由跳过单章验证        | 每章必须完成所有8个节点           |
| 不输出章节完成确认            | 每章完成后必须输出确认            |

### 章节完成确认输出格式（批量创建时强制）

每章创建完成后，必须输出以下确认：

```
✅ 第XXX章创建完成
   - 章纲文件：05-章纲/NN-第X卷-卷名/第XXX章-章节标题.md ✓
   - 章纲约束清单：08-约束清单/章纲约束/NN-第X卷-卷名/第XXX章-约束清单.md ✓
   - 验证状态：通过
   - 可以进入下一章：是
```

**如果任一项为 ❌，必须立即停止，修复后才能继续。**

## 阶段一：信息收集

**目的**：收集所有创建章纲所需的信息

### 1.1 读取总纲

**目的**：了解整体规划，确认本章在整体中的地位

**关键信息提取**：

- 整体故事走向
- 重大事件节点
- 本章在整体规划中的位置

### 1.2 读取卷纲（最关键步骤）

**目的**：获取本章的规划内容

**操作方法**：详见 [卷纲提取模板](./卷纲提取模板.md)

**关键信息提取**：

- 本章核心事件
- 爽点设计
- 伏笔埋设
- 卡点设计

### 1.3 读取人物设定

**目的**：确保人物行为符合人设

**关键信息提取**：

- 主角当前状态（实力、心理、目标）
- 主角性格特点与核心价值观
- 本章出场配角的人设
- 本章出场反派的动机

### 1.4 获取前章人物状态（如非第1章）

**目的**：确保本章人物状态与前章一致，避免OOC

**获取优先级**（按优先级从高到低）：

1. **前章正文约束清单**（如前章正文已写完）：`08-约束清单/正文约束/NN-第X卷-卷名/第XXX-1章-约束清单.md` → 使用**实际结尾状态**
2. **前章章纲**（如前章正文未写完，批量创建章纲时）：`05-章纲/NN-第X卷-卷名/第XXX-1章-xxx.md` → 使用**规划状态**
3. **人物设定**（第1章或前章文件不存在时）：`03-人物设定/主角.md` → 使用**初始状态**

> **优先级说明**：优先使用正文实际结尾状态。仅在正文尚未写完时，才退而使用章纲规划状态。

**关键信息提取**：

- 主角伤势/体力状态
- 主角情绪状态
- 持有物品
- 当前地点

### 1.5 查看相邻章节的章纲（如存在）

**目的**：确保情节连贯，避免冲突

**查看文件**：

- 前一章章纲：`05-章纲/NN-第X卷-卷名/第XXX-1章-xxx.md`（参考情节发展）
- 后一章规划（如有）：参考卷纲中的后续安排

**节点完成确认**：\[ ] 节点1：阶段一（信息收集）已完成

## 章纲修改后同步流程

**同步更新要求（强制）**：修改章纲后必须同步更新章纲约束清单。

> **阻塞说明（强制）**：章纲修改后，章纲约束清单必须同步更新，否则下游技能（novel-chapter-writer、novel-outline-vetter）将读取到过期数据。

```
修改章纲后同步流程：
1. 确认章纲已修改完成
2. 重新从修改后的章纲中提取约束信息
3. 按章纲约束清单模板重新生成内容
4. 覆盖保存到：08-约束清单/章纲约束/NN-第X卷-卷名/第XXX章-约束清单.md
5. 验证章纲约束清单与修改后章纲一致
6. 此步骤不可跳过。
```

**示例（错误）**：

```
❌ 修改章纲后直接保存，不更新章纲约束清单
❌ 认为章纲约束清单不重要，跳过同步步骤
```

**示例（正确）**：

```
✓ 修改章纲 → 检查不符合项 → 修改章纲 → 重新生成章纲约束清单 → 验证一致性
```
