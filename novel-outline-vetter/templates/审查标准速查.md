# 章纲审查标准速查

> 本文件内联 `统一标准.md` 中与章纲审查相关的关键标准，避免跨目录引用。

---

## 一、字数标准

### 每章字数
- **正文目标**：≥2100非空白字符
- **字数达标率**：≥98%

### 四部分结构字数分配

| 部分 | 标准值（章纲） | 范围 |
|------|---------------|------|
| 开头钩子 | 250字符 | 200-300字符 |
| 剧情发展 | 650字符 | 600-700字符 |
| 情绪高潮 | 600字符 | 500-700字符 |
| 章节卡点 | 400字符 | 350-450字符 |
| **总计** | **1900字符** | **1700-2100字符** |

---

## 二、爽点间隔标准

| 爽点类型 | 间隔标准 | 说明 |
|---------|---------|------|
| 小爽点 | 3-5章 | 常规爽点，保持读者兴趣 |
| 中爽点 | 20-30章 | 阶段性爽点，推动剧情发展 |
| 大爽点 | 50-100章（每卷1-2个） | 卷级高潮，重大转折 |

---

## 三、对话与段落规范

| 标准项 | 标准值 |
|--------|--------|
| 对话占比 | ≥60%（正文对话字符/正文总非空白字符） |
| 每段对话上限 | 不超过150非空白字符 |
| 段落长度 | 每段≤3行（适合手机阅读） |
| 对话轮次限制 | 对话不超过5轮不推进剧情 |
| 纯描写限制 | 避免连续3段以上纯心理描写或背景交代 |

---

## 四、伏笔管理标准

| 周期 | 处理方式 |
|------|---------|
| 10-30章 | 最佳回收周期 |
| 30-50章 | 需中期强化（回顾/提及） |
| >50章 | 有被遗忘风险，应尽量避免 |

- **每卷新伏笔数量**：3-5个

## 七、章节标题唯一性标准（强制执行）

### 核心规则

> **全书范围内，所有章节标题必须唯一，禁止重复。**

### 禁止使用的标题类型

| 禁止类型 | 错误示例 | 问题 |
|---------|---------|------|
| 叙事功能词 | 卷末高潮、卷末铺垫、卷末、卷首、开篇、过渡、转折 | 不是具体事件 |
| **卷末/卷首类** | **模式匹配：卷末XX、卷首XX** | 导航性词汇，破坏沉浸感 |
| 情绪描述词 | 压抑、爆发、爽点、高潮 | 太抽象 |
| 结构描述词 | 承上启下、衔接、收尾 | 纯功能性描述 |
| 通用词标题 | 商行升级、四阶、天赋交易、修炼、突破 | 无法区分具体内容 |
| 规划编号词 | 伏笔1回收、伏笔2、爽点1、卡点3 | 暴露创作痕迹 |

### 标题长度规范

- **标准长度**：2-6个字
- **最大长度**：不超过8个字（硬性上限）

### 标题唯一性规则

- 全书范围内禁止重名
- 禁止弱区分词制造伪差异
- 禁止同一人物+同一动作组合反复使用
- 同一主干标题最多出现2次（仅限"上/下"拆分）
- 发现冲突 → 回退卷纲层修复，禁止加序号/副标题放行

### 标题冲突检查表格式

`| 序号 | 标题 | 来源位置 | 冲突对象 | 问题类型 | 处理结论 |`

**问题类型固定枚举**：`通过 / 完全重复 / 主干重复 / 人物动作重复 / 伪差异 / 禁用词`

**处理结论固定枚举**：`保留 / 重写标题 / 回退卷纲层修复 / 回退章纲层修复 / 阻塞待修`

## 八、正文内容禁止词汇（1.5.1节）

| 类别 | 禁止词汇 | 说明 |
|------|---------|------|
| **卷/部结构词** | **模式匹配：第X卷、卷X、第X部**（X为任意数字） | 导航性词汇 |

| | **模式匹配：卷末XX、卷首XX**（XX为任意词） | 导航性词汇 |
| **章节导航词** | 下一章、上一章、前一章、后一章、本章、下章、上章、前章、章节回顾 | 导航性词汇 |

| | 转折点来临、即将转折 | 剧透性词汇 |

## 九、卷定位规则

### 卷定位规则（强制执行）

当需要根据章节号确定所属卷时：
```
步骤1：读取总纲，获取分卷规划表
步骤2：从分卷规划表中提取每卷的章节范围
步骤3：根据目标章节号匹配：卷起始章 ≤ 目标章节号 ≤ 卷结束章
步骤4：用匹配到的卷编号构建完整路径
```
