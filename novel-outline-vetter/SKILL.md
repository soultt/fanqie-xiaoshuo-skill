## 核心定位

基于大纲要求，对章纲进行全面审查，确保章节符合整体规划，发现并修正结构、伏笔、情绪等问题。

## 审查验证机制

> **核心要求**：审查结论必须基于当前文件内容，不得只凭口头判断或历史记忆下结论。

**执行要求**：
- ✅ 每个检查项都要基于实际文件内容核对
- ✅ 审查结论要给出对应的文件依据
- ✅ 禁止仅口头声明"通过"或"无问题"

> **完整规范**：详见 [审查验证规范](./templates/审查验证规范.md)

### 验证规则

| 规则 | 说明 |
|------|------|
| 规则1 | 每个检查项都必须有对应的文件依据 |
| 规则2 | 审查输出必须体现验证依据 |
| 规则3 | 禁止仅口头声明"已检查"或"通过" |
| 规则4 | 禁止以任何理由跳过检查项 |
| 规则5 | 禁止抽查部分内容而非全量验证 |
| 规则6 | 每次审查都应重新核对当前文件内容 |
| 规则7 | 禁止使用"之前读取""我记得"等依赖记忆的表述 |
| 规则8 | 记忆与文件冲突时，以文件为准 |

### 审查执行确认清单（强制）

**审查开始前必须确认**：
- [ ] 我已阅读并理解审查验证规范
- [ ] 我将重新核对当前文件内容，不依赖记忆
- [ ] 我不会使用"之前读取""我记得"等依赖记忆的表述
- [ ] 记忆与文件冲突时，我将以文件为准
- [ ] 我将完整执行所有检查项，不跳过任何检查
- [ ] 我将给出对应的文件依据
- [ ] 我不会仅口头声明"已检查"或"通过"
- [ ] 我不会以任何理由省略验证

**未全部勾选确认 → 不得开始审查**

## 审查维度体系

> **数值标准（字数/爽点/伏笔/禁用词）**：详见 [审查标准速查](./templates/审查标准速查.md)

### 优先审查：前后章节冲突（P0级，最高优先级）

检查7项冲突：人物状态、时间线、地点空间、物品道具、人物关系、剧情逻辑、能力设定

---

### 一级审查：大纲符合性（P1级）

检查5项：核心事件与卷纲一致、四部分结构完整、爽点与卷纲一致、伏笔与卷纲一致、卡点与卷纲一致

---

### 章纲约束清单一致性审查

> 确保章纲与章纲约束清单保持一致

**审查流程**：读取约束清单 → 验证存在 → 逐项对比（核心事件/爽点/伏笔/卡点/人物状态/禁止事项）→ 生成结果

**处理规则**：
- 章纲约束清单过期 → "需同步更新"
- 章纲违反约束 → "需修改章纲"

---

### 二级审查：结构完整性（P2级）

检查4项：字数分配合理、爽点间隔合理（小3-5/中20-30/大50-100章）、伏笔回收周期合理（10-30章最佳）、对话占比规划合理（≥60%）

---

### 三级审查：剧情质量（P3级）

检查3项：前后章衔接自然、人物行为符合人设、情绪递进合理

---

### 四级审查：文笔规范（P4级）

检查项：
1. 章节标题唯一性
2. 章节标题吸引力
3. 无AI特征描述
4. **章节标题重名/高度相似检查（强制）**
   - 必查：完全重名、主干重复、人物动作重复、弱区分词伪差异
   - 必产出：`章纲标题冲突审查表`（格式见 [审查标准速查](./templates/审查标准速查.md) 第七节）
   - 问题类型固定枚举：`通过 / 完全重复 / 主干重复 / 人物动作重复 / 伪差异 / 禁用词`
   - 处理结论固定枚举：`保留 / 重写标题 / 回退卷纲层修复 / 回退章纲层修复 / 阻塞待修`
   - ❌ 发现冲突 → 标记为阻塞问题，必须返回卷纲层修复
5. **章节标题导航类禁用词检查（强制）**
   - 完整禁用词列表见 [审查标准速查](./templates/审查标准速查.md) 第八节

## 执行流程

> **完整执行流程**：见 [执行流程](./templates/执行流程.md)

### 执行概述

1. **阶段零**：启用阻塞式审查机制 → 确认规则
2. **步骤1-2**：确认审查范围 + 读取审查依据
3. **步骤3**：优先审查（前后章节冲突7项）
4. **步骤4-5**：一级审查 + 章纲约束清单一致性审查
5. **步骤6-8**：二级审查 → 三级审查 → 四级审查
6. **步骤9-10**：生成审查报告 + 章纲约束清单同步

> **阻塞机制**：所有节点必须按序执行，不可跳过。任一阻塞条件触发 → 立即停止 → 修复后重审。

## 审查注意事项

1. **章纲约束清单是审查依据**：审查章纲时必须同时读取章纲约束清单
2. **修改章纲后必须同步章纲约束清单**：审查导致章纲修改时，章纲约束清单必须同步更新
3. **卷纲优先原则**：如发现章纲与卷纲不一致，必须以卷纲为准
4. **前章正文优先**：如发现章纲与前章正文结尾不一致，以前章正文为准
