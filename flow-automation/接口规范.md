# 技能间标准化接口规范

> **重要说明（强制）**：所有技能必须遵循本规范进行输出和输入，确保上下游技能正确衔接。

---

## 一、通用输出格式

### 1.1 文件头部元数据

所有技能输出文件必须在开头包含YAML格式的元数据：

```yaml
---
output_skill: "novel-chapter-outline-creator"    # 输出技能名称
output_time: "2025-01-15 10:30:00"              # 输出时间（ISO 8601格式）
downstream_skill: "novel-chapter-writer"        # 下游技能名称
chapter_number: 15                              # 章节号
chapter_title: "打脸嘲讽者"                      # 章节标题
version: "1.0"                                  # 输出格式版本
---
```

### 1.2 约束清单区块

所有创作类技能（outline-creator, chapter-writer）必须包含约束清单：

```markdown
## 约束清单

### 来源文件
- [上游文件1]: [路径] ✓
- [上游文件2]: [路径] ✓

### 约束内容
- [约束项1]: [值]
- [约束项2]: [值]

### 禁止事项
- ❌ [禁止行为1]
- ❌ [禁止行为2]
```

## 二、技能特定接口

### 2.1 novel-outline-designer 输出 → novel-chapter-outline-creator 输入

**输出文件**：`02-卷纲/NN-第X卷-卷名.md`

**必须包含的区块**：
```markdown
## 卷基本信息
- 卷号：第X卷
- 卷名：XXX
- 章节范围：第XX章-第XX章

## 章节详细规划

### 第XXX章：章节标题
- **核心事件**：[必须填写]
- **爽点设计**：[必须填写，格式：类型-内容]
- **伏笔埋设**：[必须填写，无则填"无"]
- **卡点设计**：[必须填写]

## 标题唯一性检查表
| 序号 | 标题 | 来源位置 | 冲突对象 | 问题类型 | 处理结论 |
```

**输入验证**：
- novel-chapter-outline-creator 必须能提取上述四项内容
- 必须存在"标题唯一性检查表"且字段顺序完整
- 问题类型只能使用：`通过 / 完全重复 / 主干重复 / 人物动作重复 / 伪差异 / 禁用词`
- 处理结论只能使用：`保留 / 重写标题 / 回退卷纲层修复 / 回退章纲层修复 / 阻塞待修`
- 发现标题冲突 → 返回 `E006`
- 缺少标题检查表 → 返回 `E008`
- 枚举值不合法 → 返回 `E009`
- 缺少任一项 → 报错停止

### 2.2 novel-chapter-outline-creator 输出 → novel-chapter-writer 输入

**输出文件**：`05-章纲/NN-第X卷-卷名/第XXX章-章节标题.md`

**必须包含的区块**：
```markdown
## 卷纲对照（必须首先填写）
- **核心事件**：[从卷纲复制]
- **爽点设计**：[从卷纲复制]
- **伏笔埋设**：[从卷纲复制]
- **卡点设计**：[从卷纲复制]

## 情节分解（2100非空白字符分配）
### 一、开头钩子（约250字符）
### 二、剧情发展（约650字符）
### 三、情绪高潮（约600字符）
### 四、章节卡点（约400字符）

## 爽点设计
| 序号 | 类型 | 位置 | 强度 | 内容概要 |

## 伏笔设计
| 序号 | 内容 | 位置 | 预计回收 | 回收方式 |

## 章纲标题唯一性检查表
| 序号 | 标题 | 来源位置 | 冲突对象 | 问题类型 | 处理结论 |
```

**输入验证**：
- novel-chapter-writer 必须验证上述区块存在
- 必须存在"章纲标题唯一性检查表"且字段顺序完整
- 问题类型只能使用：`通过 / 完全重复 / 主干重复 / 人物动作重复 / 伪差异 / 禁用词`
- 处理结论只能使用：`保留 / 重写标题 / 回退卷纲层修复 / 回退章纲层修复 / 阻塞待修`
- 发现标题冲突 → 返回 `E006`
- 缺少标题检查表 → 返回 `E008`
- 枚举值不合法 → 返回 `E009`
- 字数分配总和必须在1700-2100非空白字符范围内
- 爽点/卡点设计与卷纲一致

> 注意：以上为章纲分配基准范围。正文写作目标为≥2100非空白字符，详见统一标准1.3节。

- 必须存在"正文标题检查表"且字段顺序完整
- 问题类型只能使用：`通过 / 完全重复 / 主干重复 / 人物动作重复 / 伪差异 / 禁用词`
- 处理结论只能使用：`保留 / 重写标题 / 回退卷纲层修复 / 回退章纲层修复 / 阻塞待修`

## 五、版本兼容性

### 5.1 版本号规则

- 格式：`主版本.次版本`
- 主版本变更：接口不兼容，必须同步更新所有技能
- 次版本变更：接口兼容，可选更新

**当前技能版本**：
- 统一标准规范：`2.9`
- 接口规范：`2.9`
- 技能输出格式版本：`1.0`（文件头部元数据中的version字段）

### 5.2 兼容性处理

```yaml
# 下游技能读取上游输出时
if upstream_version.major != current_version.major:
    # 主版本不一致 → 报错
    raise CompatibilityError("接口版本不兼容")
elif upstream_version.minor < current_version.minor:
    # 次版本低于当前 → 警告，尝试兼容
    log_warning("上游版本较低，使用兼容模式")
```

## 六、错误处理规范

### 6.1 错误类型

| 错误码 | 错误类型 | 处理方式 |
|--------|----------|----------|
| E001 | 文件不存在 | 停止执行，报告缺失文件 |
| E002 | 格式错误 | 停止执行，报告格式问题 |
| E003 | 内容缺失 | 停止执行，报告缺失项 |
| E004 | 版本不兼容 | 停止执行，报告版本冲突 |
| E005 | 约束违反 | 停止执行，报告违反项 |
| E006 | 标题冲突 | 立即阻塞，返回上游标题修复 |
| E007 | 标题继承错误 | 立即阻塞，返回上游统一标题 |
| E008 | 标题检查表缺失 | 立即阻塞，补齐检查表后重试 |
| E009 | 标题枚举值非法 | 立即阻塞，按统一标准重写检查表 |

### 6.2 通用错误报告格式

```markdown
## 错误报告

- 错误码：E001
- 错误类型：文件不存在
- 发生技能：[技能名称]
- 发生时间：[时间]
- 错误详情：[详细描述]
- 建议处理：[处理建议]
```

> **修复路由引用**：标题相关错误码的自动化修复优先级与回退层级，详见 `templates/修复优先级表.md` 中“标题错误码修复路由”。

### 6.3 标题冲突阻塞返回格式

```markdown
## 标题冲突阻塞报告

- 错误码：E006
- 错误类型：标题冲突
- 阻塞级别：强制阻塞
- 发生技能：[技能名称]
- 发生时间：[时间]
- 当前标题：[章节标题]
- 处理要求：回退卷纲层或章纲层修复，禁止在当前层直接改名放行

### 标题冲突检查表
| 序号 | 标题 | 来源位置 | 冲突对象 | 问题类型 | 处理结论 |
|------|------|----------|----------|----------|----------|
| 1 | [当前标题] | [当前章节] | [冲突章节/文件] | 完全重复 / 主干重复 / 人物动作重复 / 伪差异 / 禁用词 | 回退卷纲层修复 / 回退章纲层修复 / 阻塞待修 |

### 处理动作
- 停止当前流程
- 返回上游修复标题
- 修复后重新生成并重新校验检查表
```
