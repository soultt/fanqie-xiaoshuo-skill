# 修复优先级规则表

本文档包含 flow-automation 技能的修复优先级规则。

---

## 章纲修复优先级规则

> P0级连贯性审查标准（7项）定义参见 `novel-writer-master/统一标准.md` 第六章，以下为快速参考。
> 标题冲突统一标准参见 `novel-writer-master/统一标准.md` 第八节；错误码定义参见 `flow-automation/接口规范.md` 第六章。

| 优先级 | 问题类型 | 修复策略 | 是否必须 |
|--------|---------|---------|---------|
| P0 | 人物状态冲突 | 补充过渡描写或调整设定 | 必须 |
| P0 | 时间线冲突 | 调整时间描述确保连贯 | 必须 |
| P0 | 地点空间冲突 | 补充移动过程 | 必须 |
| P0 | 物品道具冲突 | 补充来源/消耗记录 | 必须 |
| P0 | 人物关系冲突 | 补充关系转变过程 | 必须 |
| P0 | 剧情逻辑冲突 | 补充因果链条 | 必须 |
| P0 | 能力设定冲突 | 补充成长过程 | 必须 |
| P0 | 标题冲突（E006） | 停止当前流程，回退卷纲层重拟标题并重建标题唯一性检查表 | 必须 |
| P0 | 标题检查表缺失（E008） | 先补齐标题唯一性检查表，再继续下游流程 | 必须 |
| P0 | 标题枚举值非法（E009） | 按统一标准第八节重写检查表字段值后重试 | 必须 |
| P1 | 结构不完整 | 补充缺失部分 | 建议 |
| P1 | 字数分配不当 | 调整各部分字数 | 建议 |
| P1 | 节奏问题 | 调整情节密度 | 建议 |
| P1 | 卡点无效 | 重新设计悬念 | 建议 |
| P1 | 爽点设计问题 | 调整爽点类型/位置 | 建议 |
| P1 | 伏笔管理问题 | 补充伏笔/调整回收 | 建议 |
| P2 | 对话占比不足 | 增加对话内容 | 可选 |
| P2 | 段落过长 | 拆分段落 | 可选 |
| P2 | 信息密度问题 | 调整信息分布 | 可选 |

## 正文修复优先级规则

> 标题继承与标题冲突问题属于强制阻塞，禁止在正文层私自改名放行。

| 优先级 | 问题类型 | 修复策略 | 是否必须 |
|--------|---------|---------|---------|
| P0 | 人物状态冲突 | 补充过渡描写或调整状态描述 | 必须 |
| P0 | 时间线冲突 | 调整时间描述确保连贯 | 必须 |
| P0 | 地点空间冲突 | 补充移动过程 | 必须 |
| P0 | 物品道具冲突 | 补充来源/消耗记录 | 必须 |
| P0 | 人物关系冲突 | 补充关系转变过程 | 必须 |
| P0 | 剧情逻辑冲突 | 补充因果链条 | 必须 |
| P0 | 能力设定冲突 | 补充成长过程/遵守限制 | 必须 |
| P0 | 章纲严重偏离 | 调整正文回归章纲 | 必须 |
| P0 | 标题冲突（E006） | 停止当前流程，回退章纲层或卷纲层修复标题冲突后再写正文 | 必须 |
| P0 | 标题继承错误（E007） | 统一正文文件名标题、页内标题与章纲标题，禁止在正文层另起新名 | 必须 |
| P0 | 标题检查表缺失（E008） | 先补齐正文标题检查表，再进入正文审查 | 必须 |
| P0 | 标题枚举值非法（E009） | 按统一标准第八节重写正文标题检查表字段值 | 必须 |
| P1 | 超出章纲 | 评估必要性，删除或补充章纲 | 建议 |
| P1 | 遗漏章纲 | 补充遗漏内容 | 建议 |
| P1 | 结构不完整 | 补充缺失部分 | 建议 |
| P1 | 字数不足（<2100字符） | 扩展描写，增加细节 | 建议 |
| P1 | 字数过多（>3000字符） | 精简冗余内容 | 建议 |
| P1 | 对话占比不足（<60%） | 增加对话内容 | 建议 |
| P1 | 卡点无效 | 重新设计悬念 | 建议 |
| P1 | 伏笔问题 | 补充伏笔/调整回收 | 建议 |
| P2 | 段落过长 | 拆分段落 | 可选 |
| P2 | 描写不足 | 增加五感描写 | 可选 |
| P2 | 信息密度问题 | 调整信息分布 | 可选 |

## 标题错误码修复路由

| 错误码 | 问题场景 | 回退层级 | 首选修复动作 |
|--------|----------|----------|--------------|
| E006 | 标题冲突（完全重复/主干重复/人物动作重复/伪差异/禁用词） | 卷纲层优先，必要时章纲层 | 重拟标题并重建检查表，禁止加序号/加副标题放行 |
| E007 | 标题继承错误（文件名标题/页内标题/章纲标题不一致） | 章纲层优先，必要时卷纲层 | 恢复同一标题源，确保三处标题一致 |
| E008 | 标题检查表缺失 | 当前层 | 补齐检查表后重新校验再继续 |
| E009 | 标题枚举值非法 | 当前层 | 按统一标准第八节改写问题类型与处理结论 |

## 字数修复规则

| 字数情况 | 处理方式 |
|---------|---------|
| < 1500字符 | 严重不足，必须大幅扩展 |
| 1500-2000字符 | 不足，需要扩展描写 |
| 2000-2100字符 | 略微不足，可补充细节 |
| 2100-2500字符 | 达标，正常范围 |
| 2500-3000字符 | 达标，可接受范围 |
| > 3000字符 | 过长，建议精简 |
