# 工作流模式

本文包含 flow-automation 技能的七种自动化工作流模式。

> **卷定位规则**：当路径中出现 `NN-第X卷-卷名` 时，NN 通过读取总纲分卷规划表确定（详见 `统一标准.md` 第九节）。
> **标题错误码引用**：标题冲突标准见 `novel-writer-master/统一标准.md` 第八节；错误码定义见 `flow-automation/接口规范.md` 第六章；修复路由见 `templates/修复优先级表.md` 中“标题错误码修复路由”。

## 标题错误码跳转规则（所有模式通用）

```
发现标题问题
    │
    ├── E006 标题冲突
    │      → 立即阻塞
    │      → 回退卷纲层优先，必要时回退章纲层
    │      → 重拟标题并重建检查表
    │
    ├── E007 标题继承错误
    │      → 立即阻塞
    │      → 回退章纲层优先，统一文件名标题/页内标题/上游标题
    │
    ├── E008 标题检查表缺失
    │      → 当前层补齐检查表
    │      → 重新校验后才能继续
    │
    └── E009 标题枚举值非法
           → 当前层按统一标准第八节重写枚举值
           → 重新校验后才能继续
```

### 标题错误码案例示意

```text
第021章章纲创建
    ↓
读取卷纲标题：再次交易
    ↓
扫描已存在标题：第009章-首次交易
    ↓
判定结果：弱区分词伪差异
    ↓
返回 E006
    ↓
停止当前章创建
    ↓
回退卷纲层重拟标题
    ↓
重建标题唯一性检查表
    ↓
重新进入章纲创建流程
```

## 模式一：完整创作流程

Step 1: 大纲设计
- 调用 novel-outline-designer
- 创建 01-总纲/总纲.md
- 创建 02-卷纲/NN-第X卷-卷名.md（含章节卡片表格）
- 创建 03-人物设定/*.md
- 创建 04-世界观/*.md

Step 2: 大纲审查
- 调用 novel-master-outline-vetter
- 审查总纲质量
- 审查卷纲质量
- 审查逻辑一致性
- 输出 07-审查报告/大纲审查/

Step 3: 章纲创建（循环，按大维度来）
- 调用 novel-chapter-outline-creator
- 严格按大维度清单逐章创建章纲
- 每个章节必须对应大纲规划
- 禁止添加大纲未规划的内容
- 创建 05-章纲/NN-第X卷-卷名/第XXX章-xxx.md
- 同步生成 08-约束清单/章纲约束/NN-第X卷-卷名/第XXX章-约束清单.md
- 如触发 `E006/E008/E009` → 立即停止当前章，先修复标题问题再继续

Step 4: 章纲审查与修复（循环）
- 调用 novel-outline-vetter
- 审查章纲符合性
- 审查章纲与章纲约束清单一致性
- 输出 07-审查报告/章纲审查/
- 读取审查报告，分析问题优先级
- 如触发 `E006/E008/E009` → 按标题错误码修复路由回退并重审
- 修复问题
- 修改章纲后同步更新章纲约束清单

Step 5: 正文写作（循环）
- 调用 novel-chapter-writer
- 读取章纲、约束清单、人物设定、前章正文
- 严格按章纲内容创作正文
- 禁止添加章纲未规划的内容
- 创建 06-正文/NN-第X卷-卷名/第XXX章-xxx.md
- 同步生成 08-约束清单/正文约束/NN-第X卷-卷名/第XXX章-约束清单.md
- 如触发 `E006/E007/E008/E009` → 立即停止当前章，按错误码回退或补齐后再继续

Step 6: 正文审查与修复（循环）
- 调用 novel-chapter-vetter
- 审查正文质量
- 审查正文与正文约束清单一致性
- 输出 07-审查报告/正文审查/
- 如触发 `E006/E007/E008/E009` → 按标题错误码修复路由回退并重审
- 修复问题
- 修改正文后同步更新正文约束清单

Step 7: 循环推进
- 返回 Step 3，继续下一章
- 每完成一卷，进行卷级审查

## 模式二：单章创作流程

从章纲创建到正文写作的单章完整流程。

**单章标题异常示例**：
- 正文文件名标题 = `再次交易`
- 正文页内标题 = `黑市交换`
- 章纲标题 = `再次交易`
- 判定：标题继承错误 → 返回 `E007`
- 处理：停止正文流程，回退章纲层统一标题源后重试

## 模式三：批量章纲创建

批量创建多章章纲，每章生成约束清单。

### 强制规则（新增）

> **最高优先级说明（强制）**：以下规则必须严格执行，违反则立即停止执行。

1. **非第1章创建章纲时，必须先读取前章章纲约束清单**
2. **前章约束清单不存在时，必须停止，不得继续创建章纲**
3. **每章章纲完成后，必须等待约束清单生成完成**
4. **约束清单验证通过后，才能开始下一章**
5. **禁止在约束清单未生成时继续下一章**
6. **禁止在约束清单验证失败时输出章纲**

### 执行流程（强制顺序）

```
for each chapter:
    │
    ├── 1. 读取卷纲章节卡片表格
    │      → 文件：02-卷纲/NN-第X卷-卷名.md
    │      → 提取：章节标题/核心事件/爽点设计/伏笔埋设/卡点设计
    │
    ├── 2. 读取前章章纲约束清单（如非第1章，强制）
    │      → 文件：08-约束清单/章纲约束/NN-第X卷-卷名/第XXX-1章-约束清单.md
    │      → ❌ 不存在 → 立即停止，前章约束清单未生成
    │      → ✅ 存在 → 提取人物状态/伏笔状态/悬念
    │
    ├── 3. 创建章纲
    │      → 严格按卷纲内容创建
    │      → 字数分配：开头250/发展650/高潮600/卡点400
    │      → 发现标题冲突/检查表缺失/枚举值非法
    │         → 分别返回 E006 / E008 / E009 并立即停止
    │
    ├── 4. 保存章纲文件
    │      → 路径：05-章纲/NN-第X卷-卷名/第XXX章-xxx.md
    │
    ├── 5. 生成章纲约束清单（强制）
    │      → 路径：08-约束清单/章纲约束/NN-第X卷-卷名/第XXX章-约束清单.md
    │      → 内容：卷纲规定内容/人物状态/禁止事项
    │
    ├── 6. 验证章纲约束清单存在（强制）
    │      → ❌ 文件不存在 → 立即停止，重新生成
    │      → ✅ 文件存在 → 继续
    │
    ├── 7. 验证章纲约束清单内容完整（强制）
    │      → ❌ 内容不完整 → 立即停止，补充内容
    │      → ✅ 内容完整 → 继续
    │
    ├── 8. 输出验证通过确认（强制）
    │      → ✅ 章纲约束清单验证通过
    │      → ✅ 才能进入下一章
    │
    └── 9. 进入下一章循环
```

## 模式四：批量正文写作

批量写作多章正文，每章读取约束清单并生成正文约束清单。

### 强制规则（新增）

> **最高优先级说明（强制）**：以下规则必须严格执行，违反则立即停止执行。

1. **每章正文完成后，必须等待正文约束清单生成完成**
2. **正文约束清单验证通过后，才能开始下一章**
3. **禁止在正文约束清单未生成时继续下一章**
4. **禁止在正文约束清单验证失败时输出正文**

### 执行流程（强制顺序）

```
for each chapter:
    │
    ├── 1. 读取章纲约束清单
    │      → 文件：08-约束清单/章纲约束/NN-第X卷-卷名/第XXX章-约束清单.md
    │      → ❌ 不存在 → 停止，先创建章纲约束清单
    │
    ├── 2. 读取前章正文约束清单（如非第1章，强制）
    │      → 文件：08-约束清单/正文约束/NN-第X卷-卷名/第XXX-1章-约束清单.md
    │      → ❌ 不存在 → 立即停止，前章正文约束清单未生成
    │      → ✅ 存在 → 提取人物状态/伏笔状态/悬念
    │
    ├── 3. 创作正文
    │      → 严格按章纲内容创作
    │      → 字数≥2100非空白字符
    │      → 发现标题冲突/标题继承错误/检查表缺失/枚举值非法
    │         → 分别返回 E006 / E007 / E008 / E009 并立即停止
    │
    ├── 4. 保存正文文件
    │      → 路径：06-正文/NN-第X卷-卷名/第XXX章-xxx.md
    │
    ├── 5. 创建正文约束清单目录（强制，新增）
    │      → 路径：08-约束清单/正文约束/NN-第X卷-卷名/
    │      → ❌ 目录不存在 → 必须先创建目录
    │      → ✅ 目录存在或创建成功 → 继续
    │
    ├── 6. 生成正文约束清单（强制）
    │      → 路径：08-约束清单/正文约束/NN-第X卷-卷名/第XXX章-约束清单.md
    │      → 内容：人物状态/字数/下章约束
    │
    ├── 7. 输出验证（强制，在进入下一章前执行）
    │      → 验证正文文件存在
    │      → 验证字数达标
    │      → 验证正文约束清单存在
    │      → 验证正文约束清单内容完整
    │      → ❌ 任一失败 → 立即停止
    │
    ├── 8. 输出验证通过确认（强制）
    │      → ✅ 正文约束清单验证通过
    │      → ✅ 才能进入下一章
    │
    └── 9. 进入下一章循环
```

## 模式七：正文审查流程

- 发现标题继承错误 → 返回 `E007`
- 发现标题冲突、检查表缺失、枚举值非法 → 返回 `E006 / E008 / E009`
- 按标题错误码修复路由回退后重审
- 未修复前不得推进下一章

## 约束清单流转规则（所有模式通用）

```
创建章纲 → 生成章纲约束 → 审查章纲 → (修改则同步约束)
    ↓
写正文(读章纲约束) → 生成正文约束 → 审查正文 → (修改则同步约束)
    ↓
下章章纲(读正文约束) → ...
```

约束清单是跨章节连贯性的核心，所有模式都必须遵守此流转规则。
