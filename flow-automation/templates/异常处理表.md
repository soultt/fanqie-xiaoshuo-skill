# 异常处理表

本文档包含 flow-automation 技能的异常处理规则。

---

## 异常处理规则

| 异常类型 | 处理方式 |
|---------|---------|
| 章纲缺失 | 自动调用 novel-chapter-outline-creator 创建 |
| 正文缺失 | 自动调用 novel-chapter-writer 创建 |
| 章纲审查不通过 | 自动分析问题优先级，执行修复流程 |
| 正文审查不通过 | 自动分析问题优先级，执行修复流程 |
| 严重问题未修复 | 阻止进入下一阶段，强制修复 |
| 字数不足（<2100字符） | 自动扩展描写，增加细节 |
| 字数过多（>3000字符） | 自动精简冗余内容 |
| **正文超纲** | **删除超纲内容，强制回归章纲** |
| **正文遗漏章纲** | **补充遗漏的章纲要求** |
| **正文偏离章纲** | **调整正文方向，回归章纲规划** |
| **人物超纲（正文）** | **删除未规划人物或调整出场** |
| **事件超纲（正文）** | **删除未规划事件或调整** |
| **对话超纲** | **调整对话内容回归章纲** |
| **场景超纲** | **调整场景描写回归章纲** |
| **章纲约束文件缺失** | **阻止正文创作，提示先创建章纲** |
| 前后冲突 | 标记冲突位置，自动生成修复方案并执行 |
| 修复引入新问题 | 回滚修复，重新制定修复方案 |
| 修复验证失败 | 重新审查，迭代修复直至通过 |
| 章纲偏离严重 | 调整正文回归章纲或更新章纲 |
| 人设崩塌 | 强制修复，调整人物行为描写 |
| **章纲超纲** | **删除超纲内容，强制回归大纲** |
| **章纲遗漏大纲** | **补充遗漏的大纲要求** |
| **章纲偏离大纲** | **调整章纲方向，回归大纲规划** |
| **人物超纲（章纲）** | **删除未规划人物或调整出场** |
| **事件超纲（章纲）** | **删除未规划事件或调整** |
| **大纲约束文件缺失** | **阻止章纲创建，提示先创建大纲** |
| **标题冲突（E006）** | **立即阻塞，返回上游卷纲/章纲层修复标题，不得在当前层改名放行** |
| **标题继承错误（E007）** | **立即阻塞，统一文件名标题、页内标题与上游标题后重试** |
| **标题检查表缺失（E008）** | **补齐检查表并重新校验字段后再继续** |
| **标题枚举值非法（E009）** | **按统一标准第八节重写检查表枚举值后再继续** |
