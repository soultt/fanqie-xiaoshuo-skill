# 创建流程控制规范

> **模板引用**：本文件由创建类技能引用，定义创建过程中必须执行的流程控制机制。

---

## 核心原则

> **最高优先级说明（强制）**：创建必须完成所有节点，禁止中途跳出。

**问题背景**：
- ❌ 创建时跳过某些步骤
- ❌ 以"token不足"或"时间不够"为由提前结束
- ❌ 只完成部分内容就声称"已完成"

**解决方案**：
- ✅ 每个阶段必须完成才能进入下一阶段
- ✅ 必须输出节点完成确认
- ✅ 禁止以任何理由跳过节点

---

## 一、大纲设计流程控制

### 节点完成确认清单

**大纲设计必须完成以下节点**：

- [ ] **节点0**：阶段零确认（阻塞式创建机制已启用）
- [ ] **节点1**：创建项目目录结构
- [ ] **节点2**：撰写总纲（01-总纲/总纲.md）
- [ ] **节点3**：撰写卷纲（每卷一个文件）
- [ ] **节点4**：添加章节卡片表格（每卷）
- [ ] **节点5**：执行单卷完整性验证（每卷）
- [ ] **节点6**：输出验证（所有文件存在）

**未全部勾选 → 大纲设计未完成，必须继续执行**

### 阻塞触发条件

| 触发条件 | 阻塞级别 | 处理方式 |
|----------|----------|----------|
| 总纲文件创建失败 | 强制阻塞 | 立即停止，修复后重试 |
| 卷纲文件创建失败 | 强制阻塞 | 立即停止，修复后重试 |
| 章节卡片表格行数不等于章节总数 | 强制阻塞 | 立即停止，补充缺失行 |
| 单卷完整性验证失败 | 强制阻塞 | 立即停止，修复后重新验证 |
| 以"token不足"为由跳过 | 强制阻塞 | 禁止跳过，必须完成当前卷 |

## 二、章纲创建流程控制

### 节点完成确认清单

**章纲创建必须完成以下节点**：

- [ ] **节点0**：阶段零确认（强制约束检查通过）
- [ ] **节点1**：阶段一（信息收集完成）
- [ ] **节点2**：阶段二（章节定位完成）
- [ ] **节点3**：阶段三（结构设计完成）
- [ ] **节点4**：阶段四（内容设计完成）
- [ ] **节点5**：阶段五（爽点与伏笔设计完成）
- [ ] **节点6**：阶段六（人物与对话规划完成）
- [ ] **节点7**：阶段七（约束清单生成完成）
- [ ] **节点8**：输出验证（章纲文件+章纲约束清单存在）

**未全部勾选 → 章纲创建未完成，必须继续执行**

### 阻塞触发条件

| 触发条件 | 阻塞级别 | 处理方式 |
|----------|----------|----------|
| 总纲/卷纲/人物设定文件不存在 | 强制阻塞 | 立即停止，报告缺失文件 |
| 章节标题重复 | 强制阻塞 | 立即停止，修改标题 |
| 章纲约束清单生成失败 | 强制阻塞 | 立即停止，重新生成 |
| 阶段七被跳过 | 强制阻塞 | 禁止跳过，必须执行 |

### 批量创建循环控制（强制）

**批量创建说明（强制）**：批量创建多章章纲时，必须严格遵循以下流程。

```
FOR 章节号 = 起始章 TO 结束章:
  步骤1：创建本章章纲（阶段0-6）
     → ❌ 失败 → 立即停止，报告错误
     → ✅ 成功 → 继续步骤2
  步骤2：生成约束清单（阶段7）
     → ❌ 失败 → 立即停止，重新生成
     → ✅ 成功 → 继续步骤3
  步骤3：验证输出（阶段8）
     → ❌ 约束清单不存在 → 立即停止，重新生成
     → ❌ 约束清单不完整 → 立即停止，补充内容
     → ✅ 验证通过 → 继续步骤4
  步骤4：输出章节完成确认
     → ✅ 第XXX章创建完成（章纲+约束清单已验证）
     → ✅ 才能进入下一章
END FOR
```

**禁止行为**：
- ❌ 先创建多章章纲，再统一生成约束清单
- ❌ 约束清单未验证通过时进入下一章
- ❌ 以"效率"为由跳过单章验证
- ❌ 不输出章节完成确认

## 三、正文写作流程控制

### 节点完成确认清单

**正文写作必须完成以下节点**：

- [ ] **节点0**：确认保存位置
- [ ] **节点1**：读取章纲内容（最关键步骤）
- [ ] **节点2**：读取章纲约束清单
- [ ] **节点3**：快速浏览
- [ ] **节点4**：分阶段写作（开头钩子+剧情发展+情绪高潮+章节卡点）
- [ ] **节点5**：字数验证（≥2100非空白字符）
- [ ] **节点6**：章纲符合性检查
- [ ] **节点7**：输出验证（正文文件存在且字数达标）

**未全部勾选 → 正文写作未完成，必须继续执行**

### 阻塞触发条件

| 触发条件 | 阻塞级别 | 处理方式 |
|----------|----------|----------|
| 章纲文件不存在 | 强制阻塞 | 立即停止，先创建章纲 |
| 正文约束清单不存在 | 强制阻塞 | 立即停止，先生成正文约束清单 |
| 字数<2100非空白字符 | 强制阻塞 | 立即停止，扩写后重新验证 |
| 核心事件与章纲不符 | 强制阻塞 | 立即停止，修正后重写 |
| **正文约束清单生成失败** | **强制阻塞** | **立即停止，重新生成，不得进入下一章** |
| **正文约束清单内容不完整** | **强制阻塞** | **立即停止，补充内容后重新验证** |
| **正文约束清单验证未通过** | **强制阻塞** | **立即停止，修复后重新验证，不得输出正文** |

### 正文约束清单强制验证机制（新增）

**正文输出前必须执行以下验证**：

```
┌─────────────────────────────────────────────────────────┐
│  正文约束清单强制验证（输出前必须执行）                    │
├─────────────────────────────────────────────────────────┤
│                                                          │
│ 步骤1：创建正文约束清单目录（强制）                        │
│    → 路径：08-约束清单/正文约束/NN-第X卷-卷名/             │
│    → ❌ 目录不存在 → 必须先创建目录                       │
│    → ✅ 目录存在或创建成功 → 继续步骤2                     │
│                                                          │
│ 步骤2：生成正文约束清单                                    │
│    → 路径：08-约束清单/正文约束/NN-第X卷-卷名/第XXX章-约束清单.md │
│                                                          │
│ 步骤3：验证文件存在（强制）                                │
│    → ❌ 文件不存在 → 立即停止，重新生成                   │
│    → ✅ 文件存在 → 继续步骤4                              │
│                                                          │
│ 步骤4：验证内容完整（强制）                                │
│    → ❌ 内容不完整 → 立即停止，补充内容                   │
│    → ✅ 内容完整 → 继续步骤5                              │
│                                                          │
│ 步骤5：输出验证通过确认                                   │
│    → ✅ 正文约束清单验证通过 → 才能输出正文文件           │
│    → ✅ 正文约束清单验证通过 → 才能进入下一章             │
│                                                          │
│ ❌ 禁止：正文约束清单未验证通过时输出正文或进入下一章       │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 六、流程完整性验证

**创建完成后必须验证**：

```
┌─────────────────────────────────────────────────────────┐
│  🔒 流程完整性验证（输出前强制执行）                        │
├─────────────────────────────────────────────────────────┤
│                                                          │
│ 验证1：所有节点确认清单已勾选？                           │
│    → ❌ 未全部勾选 → 不得输出完成声明                     │
│                                                          │
│ 验证2：所有输出文件存在？                                │
│    → ❌ 任一文件不存在 → 补充创建                        │
│                                                          │
│ 验证3：阻塞条件未触发？                                  │
│    → ❌ 任一阻塞条件触发 → 修复后重新验证                │
│                                                          │
│ ✅ 全部验证通过 → 才能声明"创建完成"                      │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 七、禁止行为清单

### 绝对禁止

```
❌ 禁止行为：

1. 以"token不足"为由跳过节点
   错误示例："token不足，跳过章节卡片表格"
   正确示例：完成当前节点，报告进度，等待继续

2. 以"时间不够"为由提前结束
   错误示例："时间不够，先创建框架"
   正确示例：完成当前节点，保存进度，等待继续

3. 只完成部分内容就声称"已完成"
   错误示例："卷纲已创建"（但章节卡片表格缺失）
   正确示例：完成所有节点，验证通过后声明完成

4. 跳过验证步骤
   错误示例："跳过字数验证"
   正确示例：必须执行验证，验证失败则修复

5. 不输出节点完成确认
   错误示例：直接进入下一阶段
   正确示例：输出节点完成确认，勾选确认清单
```
