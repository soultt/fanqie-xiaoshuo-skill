## 核心定位

基于番茄小说爆款作品（《十日终焉》《我不是戏神》等）的结构方法，设计可执行的完整大纲体系。

> **技能边界说明（强制）**：
> - 人物设定、世界观设定、核心冲突设计已独立为 `novel-setting-designer` 技能
> - 本技能专注于总纲和卷纲的设计
> - 调用本技能前，应先调用 `novel-setting-designer` 完成设定体系设计

## 章节标题命名规范（强制）

> **详细标准**：见 [大纲标准速查](./templates/大纲标准速查.md) 第四节

**核心原则**：章节标题必须描述本章的**具体事件或内容**，禁止使用叙事功能词作为标题。

**❌ 禁止使用**：叙事功能词（如"卷末高潮""开篇""过渡"）、情绪描述词（如"压抑""爆发"）、通用词（如"商行升级""修炼"）、卷/部结构词（如"第一卷""卷末"）、规划编号词（如"伏笔1回收""爽点2"）

**✅ 使用**：具体事件（如"赵家破产"）、人物动作（如"林辰出手"）、悬念钩子（如"神秘买家现身"）、关键物品（如"半块玉佩"）

**标题长度**：2-6字（标准），最多8字（硬性上限）

**标题唯一性**：全书范围内必须唯一，禁止使用弱区分词制造伪差异

---

## 段落描述 vs 章节标题边界（关键区分）

> **核心原则**：卷纲中的"段落描述"与章节"标题"是完全不同的概念，**禁止混用**。

| 维度 | 段落描述（卷级） | 章节标题（章级） |
|------|-----------------|-----------------|
| **用途** | 卷级规划，概括多章内容 | 单章标识，描述具体事件 |
| **允许词汇** | "高潮""铺垫""过渡"等功能词 | **仅允许**具体事件描述 |
| **示例** | "第五段：最终冲突与悬念铺设" | "赵家破产""玄清子命格破碎" |

**❌ 绝对禁止**：将段落描述中的"卷末高潮""第五段"等词汇用于章节标题
**❌ 绝对禁止**：章节"主要事件"出现"卷末高潮主线推进"等概括性描述

## 大纲设计五步法则

### 第一步：确立核心钩子与情绪锚点

开篇前三章必须植入强情绪触发器。根据故事选择合适的开篇钩子（如生存危机、身份反差、悬念谜团等）。

> 具体人物和冲突设计请调用 `novel-setting-designer` 技能

### 第二步：铺设非线性情节地雷阵

每个章节结尾埋设不同类型的伏笔（物品伏笔、对话伏笔、场景伏笔、人物伏笔）。

> **伏笔标准**：10-30章最佳回收周期，每卷新伏笔3-5个（详见 [大纲标准速查](./templates/大纲标准速查.md) 第二节）

### 第三步：构建欲望驱动型卷标题

根据故事风格选择合适的命名方式（动作+目标、悬念+冲突、情感+转折等）。

### 第四步：设置三幕式+单元剧结构

参考《十日终焉》模式，每个副本推进核心暗线，期末拼凑完整真相。

### 第五步：核心爽点规划

> **数值标准**：见 [大纲标准速查](./templates/大纲标准速查.md) 第一节

小爽点每3-5章、中爽点每20-30章、大爽点每50-100章（每卷1-2个）。

节奏公式：压抑 → 铺垫 → 爆发 → 收获 → 新目标

## 分卷设计原则

### 每卷结构参考

一种常见的卷结构参考（非唯一模板，根据题材自定义）：

```
第一卷：崛起（1-100章，20万字）
├── 第1-20章：觉醒金手指
├── 第21-50章：解决第一阶段冲突
├── 第51-80章：冲突升级/格局扩大
└── 第81-100章：最终冲突与悬念铺设
```

> **结构说明（强制）**：以上粗体描述是段落叙事功能说明，不是章节标题。章节标题必须具体描述本章事件。

### 卷与卷之间的衔接

1. 上一卷遗留的问题或悬念
2. 新环境/新格局的引入
3. 主角新的目标或动机变化
4. 新的冲突或对手浮现

## 章节卡片表格格式（强制）

> **模板引用**：详见 [章节卡片模板](./templates/章节卡片模板.md)

每章一行，格式：

```
| 章节号 | 标题 | 衔接信息 | 核心事件 | 人物状态 | 爽点设计 | 卡点设计 |
```

- 每行50-100字符（不超过150字符）
- 衔接信息 = "承接上章：xxx | 开启下章：xxx"
- 标题来源于章节分段总览的关键事件列表

**卷纲 vs 章纲区别**：卷纲章节卡片每行50-100字符（卷级规划），章纲每章250-350字符（写作指导）。

## 大纲自检清单

### 总纲检查
- [ ] 核心钩子是否吸引人？
- [ ] 主角目标是否清晰？
- [ ] 主线脉络是否完整？
- [ ] 分卷规划是否合理？
- [ ] 爽点分布是否均匀？
- [ ] 文件已保存到 `01-总纲/总纲.md`？

### 卷纲检查

**文件结构检查（强制，最优先）**
- [ ] 卷纲文件已实际创建到磁盘？
- [ ] 卷纲文件包含章节卡片表格？
- [ ] 章节卡片表格行数 = 章节总数？

**章节完整性检查（强制）**：
- [ ] 章节起始编号已确认？
- [ ] 章节结束编号已确认？
- [ ] 章节总数已计算？
- [ ] 表格行数 = 章节总数？
- [ ] 章节编号无跳号？

**连贯性检查（强制）**：
- [ ] 每章都有"承接上章"字段？
- [ ] 每章都有"开启下章"字段？
- [ ] 时间标记连续无跳跃？
- [ ] 人物状态衔接合理？

**章节分段与标题一致性检查（强制）**：
- [ ] 章节分段总览中每个段落的核心内容包含关键事件列表？
- [ ] 每个段落的关键事件数量 = 该段章节数？
- [ ] 章节卡片表格的标题来自对应段落的关键事件？

**内容质量检查**
- [ ] 本卷核心任务明确？
- [ ] 情节起承转合完整？
- [ ] 爽点节奏合理？
- [ ] 伏笔埋设有安排？
- [ ] 章节标题长度符合规范（2-6字标准，最多8字）？
- [ ] 已生成标题唯一性检查表，且无重名/高度相似标题？
- [ ] 文件已保存到 `02-卷纲/NN-第X卷-卷名.md`？

### 整体检查
- [ ] 大纲字数是否处于合理区间？
- [ ] 主角成长线清晰？
- [ ] 反派递进合理？
- [ ] 世界观自洽？
- [ ] 能支撑预计字数？

> **检查范围说明**：人物设定检查、世界观检查、反派独立性检验已移至 `novel-setting-designer` 技能

## 执行流程

> **完整执行流程**：见 [执行流程](./templates/执行流程.md)

### 执行概述

1. **阶段零**：启用阻塞式执行机制 → 确认所有规则
2. **步骤1**：创建项目目录结构
3. **步骤2**：撰写总纲（按 [总纲模板](./templates/总纲模板.md)）
4. **步骤3**：撰写卷纲（含章节卡片表格，逐卷创建+验证）
   - 大卷纲（>30章）启用 [分段创建机制](./templates/分段创建规范.md)
   - 逐行验证见 [阻塞式创建规范](./templates/阻塞式创建规范.md)
5. **步骤4-5**：人设一致性审查 + 章节连贯性验证
6. **步骤6-9**：检查优化 → 输出前强制验证 → 输出成果 → 输出约束摘要

> **阻塞机制**：所有步骤必须按序执行，不可跳过。任一验证失败 → 立即停止 → 修复后重新验证。
