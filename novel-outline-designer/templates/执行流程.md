# 大纲设计执行流程

> 本文件由 `novel-outline-designer/SKILL.md` 引用，定义大纲设计的完整执行流程。

---

## 阻塞式执行机制（强制）

**每个步骤必须完成才能进入下一个步骤，不可跳过任何步骤。**

### 执行规则（强制）

- **规则1**：必须按顺序执行，不可跳过任何步骤
- **规则2**：每个步骤必须输出完成确认
- **规则3**：单卷完整性验证未通过 --> 强制阻塞，必须修复后重查
- **规则4**：每个步骤完成后必须勾选确认，才能进入下一步
- **规则5**：最终输出必须包含所有步骤的完成确认

### 节点完成确认清单

**每完成一个步骤，必须勾选确认**：
- [ ] **节点0**：阶段零确认（阻塞式执行机制已启用）
- [ ] **节点1**：创建项目目录结构
- [ ] **节点2**：撰写总纲（01-总纲/总纲.md）
- [ ] **节点3**：撰写卷纲（每卷一个文件）
- [ ] **节点4**：添加章节卡片表格（每卷）
- [ ] **节点5**：执行单卷完整性验证（每卷）
- [ ] **节点6**：输出验证（所有文件存在）已完成

**未全部勾选 --> 大纲设计未完成，不得输出完成声明**

### 阻塞触发条件

| 触发条件 | 阻塞级别 | 处理方式 |
|----------|----------|----------|
| 总纲文件创建失败 | 强制阻塞 | 立即停止，修复后重试 |
| 卷纲文件创建失败 | 强制阻塞 | 立即停止，修复后重试 |
| 章节卡片表格行数不等于章节总数 | 强制阻塞 | 立即停止，补充缺失行 |
| 单卷完整性验证失败 | 强制阻塞 | 立即停止，修复后重新验证 |
| 以上下文限制、篇幅不足等理由跳过关键步骤 | 强制阻塞 | 禁止跳过，必须完成当前卷 |
| 任何步骤未执行 | 强制阻塞 | 补全后才能输出完成声明 |

## 步骤3：撰写卷纲（含章节卡片表格）

> **强制执行说明**：步骤3包含步骤3.1-3.6，所有子步骤必须完整执行，缺一不可
>
> 本步骤将创建：
> - 卷纲文件（含章节卡片表格）
>
> **❌ 禁止行为**：
> - 只创建卷纲文件基础信息，跳过章节卡片表格
> - 章节卡片表格行数不等于章节总数
> - 以上下文限制、篇幅不足或中途分段为由提前结束
>
> **✅ 完成标准**：步骤3.6验证全部通过，才能算步骤3完成

### 多卷创建原则（强制执行）

> **规则引用（强制）**：详见 [阻塞式创建规范-多卷创建强制验证机制](./阻塞式创建规范.md#多卷创建强制验证机制)

**核心原则**：一卷一验证，不通过不下一卷

**强制规则**：
- 必须逐卷完整创建，每卷完成全部验证后才能进入下一卷
- 禁止先为所有卷创建框架再回头补内容（会导致中间卷不完整）
- 每卷创建完成后必须执行单卷完整性验证
- 每卷完成后必须向用户报告进度

**常见错误模式**：
- ❌ 第一卷完整创建，后续卷只创建框架
- ❌ 先为所有卷创建文件，再回头补内容（导致中间卷遗漏）
- ❌ 以上下文限制或篇幅不足为由跳过某些卷的章节卡片表格

**单卷验证清单（强制，每卷必须执行）**：
- [ ] 验证A：卷纲文件行数≥150行？
- [ ] 验证B：章节卡片表格存在？
- [ ] 验证C：表格行数 = 章节总数？
- [ ] 验证D：每行内容≥50字符？
- [ ] 验证E：衔接信息完整？
- [ ] 向用户报告"第X卷创建完成"

**阻塞说明（强制）**：任一验证失败 → 必须修复 → 重新验证 → 通过后才能进入下一卷。

### 步骤3.1：创建卷纲文件

> **路径检查点（强制）**：此步骤防止卷纲文件保存到错误路径

- 按卷纲模板填写所有板块（非可选板块必须全部填写）
- 卷纲模板中的必须项：基本信息、核心任务、章节分段、爽点设计、伏笔规划
- 卷纲模板中的建议项：时间线规划、场景/副本设计、创作备注
- 卷纲文件最低要求（强制）：≥150行（低于此标准视为不完整）
- **保存规则（强制）**：保存为 02-卷纲/NN-第X卷-卷名.md（独立文件）
  - 正确路径示例：`02-卷纲/01-第一卷-觉醒篇.md`
  - ❌ 错误路径：`02-卷纲/01-第一卷-觉醒篇/卷名.md`（放到子目录下）
  - ❌ 错误路径：`02-卷纲/卷名.md`（缺少卷号前缀）
- **验证要求（强制）**：保存后立即验证路径
  - 检查 `02-卷纲/` 目录，确认目标文件已生成
  - 验证：文件名为 `NN-第X卷-卷名.md` 格式

---

### 步骤3.2：确定章节范围

- 确定章节范围（起始章-结束章）
- 计算章节总数
- 确认章节编号连续无跳号

---

### 步骤3.3：段落关键事件提取与标题映射

> **强制执行说明**：此步骤建立"章节分段总览"与"章节卡片表格"的关联，必须执行。

- 读取章节分段总览表格
- 为每个段落提取关键事件列表
  - 从"核心内容"字段提取关键事件
  - 按逗号/顿号分解为多个事件
  - 关键事件数量 = 该段章节数
- 生成段落关键事件映射表
  - 格式：| 段落 | 章节范围 | 关键事件列表 |
- 一致性验证（强制）：
  - 每个段落的关键事件数量 = 该段章节数？
  - ❌ 不相等 → 补充或精简关键事件
  - 所有关键事件都是具体事件（非叙事功能词）？

**模板引用**：详见 [章节卡片模板](./章节卡片模板.md) 中"章节标题来源与提取规则"章节

---

### 步骤3.3a：读取总纲事件归属表

> **强制执行说明**：创建任何卷纲前，必须先读取总纲的事件归属表。

- 读取总纲文件（执行 `Read 01-总纲/总纲.md`）
- 提取"各卷事件归属表"
- 验证事件归属表存在：表格存在 → 继续；❌ 不存在 → 阻塞，必须先在总纲中填写
- 提取当前卷的事件列表 → "当前卷事件范围"
- 提取其他卷的事件列表 → "其他卷事件范围"（当前卷禁止填写）

---

### 步骤3.3b：读取前卷事件状态（跨卷创建时）

> **跨卷执行要求（强制）**：创建第2卷及之后的卷纲时，必须先读取前卷事件状态。

- 判断是否为跨卷创建：当前卷号 = 1？ → 跳过；当前卷号 > 1？ → 执行
- 读取前卷文件（执行 `Read 02-卷纲/NN-第X卷-卷名.md`）
- 提取前卷的"事件顺序链"表格和章节卡片表格中所有核心事件
- 生成前卷事件状态表（格式：| 事件名称 | 完成状态 | 完成章节 | 备注 |）
- 关键约束：本卷事件顺序链必须考虑前卷已完成事件；❌ 不能依赖前卷未完成事件

**模板引用**：详见 [阻塞式创建规范](./阻塞式创建规范.md) 中"跨卷事件状态继承机制"章节

---

### 步骤3.4：建立事件顺序链

> **强制执行说明**：此步骤必须在填写章节卡片前执行，防止事件顺序错乱。
> **跨卷约束**：跨卷创建时，必须先完成步骤3.3b。
> **事件归属约束**：必须先完成步骤3.3a。

- 识别关键事件链：
  - 从卷纲的"核心任务"中提取主线事件
  - 从"爽点设计"中提取爽点事件
  - 从"伏笔规划"中提取伏笔埋设/回收事件
  - 从"境界突破规划"中提取突破事件
- 建立事件依赖关系：
  - 识别事件之间的前置条件（如：商行升级需要先有首次交易）
  - 建立依赖链：事件A → 事件B → 事件C
  - 标注每个事件的最早出现章节
  - 跨卷检查：前置事件是否在前卷已完成？
    - 前卷已完成 → ✅ 可作为前置条件
    - 前卷未完成 → ❌ 本卷不能依赖该事件
- 生成事件顺序链表格：
  - 格式：| 序号 | 事件名称 | 前置事件 | 前置来源 | 最早章节 | 说明 |
  - 前置来源 = "本卷" 或 "前卷已完成"
  - 保存到卷纲文件的"事件顺序链"板块
- 顺序验证规则（强制）：后续事件不能在前置事件之前出现；❌ 违反 → 阻塞

---

### 步骤3.5：填写章节卡片表格

> **强制执行说明**：此步骤是步骤3的核心，必须完整执行，不得跳过。
> **前置条件**：必须先完成步骤3.4建立事件顺序链。
> **跨卷前置条件**：跨卷创建时，必须先完成步骤3.3b。
> **事件归属前置条件**：必须先完成步骤3.3a。

**章节卡片格式（强制）**：
- 每章一行，格式：`| 章节号 | 标题 | 衔接信息 | 核心事件 | 人物状态 | 爽点设计 | 卡点设计 |`
- 衔接信息 = "承接上章：xxx | 开启下章：xxx"
- 核心事件 = 具体事件描述（禁止通用词）
- 每章内容50-100字符（不超过150字符）

**全量填写要求（强制）**：必须填写该卷的所有章节，不得中途停止
- ❌ 填写部分章节后停止 → 禁止
- ❌ 跳过某些章节 → 禁止

**实时校验（强制）**：
- 每填写一章，检查该章核心事件是否在事件顺序链中
- 检查该事件是否早于其前置事件出现 → ❌ 事件超前 → 阻塞
- 事件归属校验：对照"当前卷事件范围"和"其他卷事件范围"
- 标题去重校验：每填写一章，立即与前文所有标题逐项比对
- 本步骤结束前必须生成"标题唯一性检查表"

**模板引用**：
- 详见 [章节卡片模板](./章节卡片模板.md)
- 详见 [阻塞式创建规范](./阻塞式创建规范.md) 中"单章创建验证流程"
- 详见 [分段创建规范](./分段创建规范.md)（当章节数超过30章时启用）

---

### 步骤3.6：卷纲完整性验证

> 创建下一卷前必须通过

- 验证卷纲文件≥150行
- 验证必须项板块全部填写（核心任务/章节分段/爽点/伏笔）
- 验证事件顺序链表格已生成
- 跨卷验证：验证前卷事件状态表已读取（跨卷创建时）
- 事件归属验证：验证总纲事件归属表已读取
- 验证章节卡片表格已添加
- 验证表格行数 = 章节总数
- 验证无通用标题
- 标题唯一性验证：已生成"标题唯一性检查表"？所有标题出现次数 = 1？
- 标题一致性验证：每个段落的关键事件数量 = 该段章节数？章节标题来自对应段落的关键事件？
- 事件顺序验证：所有事件按事件顺序链出现？
- 事件归属正确性验证：所有核心事件都属于当前卷？

**模板引用**：详见 [阻塞式创建规范](./阻塞式创建规范.md) 各阶段验证流程
**常见错误说明**：
- ❌ 章节卡片表格行数不等于章节总数 → 必须修复
- ❌ 章节卡片内容过多（>150字符）或过少（<50字符）→ 必须调整
- ❌ 衔接信息缺失 → 必须填写
- ❌ 章节标题使用通用词 → 必须替换为具体事件
- ❌ 先建所有卷框架再补内容 → 禁止，必须逐卷完整创建
- ❌ 卷纲文件<150行 → 内容不完整，必须补充

## 步骤4：人设一致性审查（卷纲完成后执行）

**审查时机**：卷纲设计完成后、章纲设计开始前

### 审查维度

1. **主角人设一致性**
   - [ ] 性格特点是否与核心冲突匹配？
   - [ ] 成长轨迹是否连贯（无跳跃式成长）？
   - [ ] 能力获取是否有合理来源和过程？
   - [ ] 核心价值观是否在关键决策中保持一致？

2. **配角人设一致性**
   - [ ] 每个配角是否有明确的角色定位？
   - [ ] 配角与主角的关系发展是否有合理铺垫？
   - [ ] 配角的行为动机是否与其背景一致？

3. **反派人设独立性**
   - [ ] 反派动机是否独立于主角金手指？
   - [ ] 反派威胁来源是否多元？
   - [ ] 反派能力体系是否与主角解绑？

4. **人物关系合理性**
   - [ ] 关系转变是否有足够的情感铺垫？
   - [ ] 人物互动是否符合其关系阶段？
   - [ ] 是否存在关系发展过快？

### OOC预警机制
- 成长速度预警：角色在缺少关键铺垫的情况下连续跨越两个以上成长阶段时标记预警
- 关系发展预警：人物关系阶段变化过快时标记预警
- 性格偏离预警：大纲中人物行为明显偏离初始设定时标记预警

```

禁止跳过说明：以下任一验证项失败，必须修复后才能输出，不得跳过

验证项1：总纲文件存在？
├── 检查 01-总纲/总纲.md 是否存在
└── ❌ 不存在 → 必须创建

验证项2：设定文件存在？（由 novel-setting-designer 创建）
├── 检查 03-人物设定/ 目录是否存在
├── 检查 04-世界观/ 目录是否存在
└── ❌ 不存在 → 建议先调用 novel-setting-designer 技能创建设定

验证项3：所有卷纲文件存在？
├── 检查 02-卷纲/NN-第X卷-卷名.md 是否存在（所有卷）
└── ❌ 任一不存在 → 必须创建

验证项4：所有卷纲文件包含章节卡片表格？（核心验证）
├── 检查每个卷纲文件是否包含章节卡片表格
├── 统计表格行数，与章节总数对比
├── 强制验证点 D：逐行验证
│   ① 读取卷纲文件中的章节卡片表格
│   ② 验证每行内容50-150字符
│   ③ 验证衔接信息（承接上章、开启下章）已填写
│   ④ 验证标题在本卷内无完全重复、无主干重复、无弱区分词伪差异
│   ⑤ ❌ 任一行验证失败 → 阻塞，修复该行
│
├── 强制验证点 E：数量一致性检查
│   ① 从卷纲文件中提取章节卡片表格
│   ② 统计表格行数
│   ③ 表格行数 = 章节总数？必须相等
│   ④ ❌ 不相等 → 阻塞，补充缺失章节
│
├── 强制验证点 F：标题去重扫描
│   ① 提取本卷全部章节标题，生成标题清单
│   ② 输出"标题唯一性检查表"并标记每个标题的章节号
│   ③ 检查完全重复、主干重复、人物动作重复、弱区分词伪差异
│   ④ ❌ 任一标题未通过 → 阻塞，逐章重写后重新扫描
│
└── ❌ 任一不存在 → 必须创建

输出前提：以上4项验证全部通过后，才能输出成果
阻塞规则：任一❌项出现 → 立即修复 → 重新验证 → 验证通过后才能继续
```
