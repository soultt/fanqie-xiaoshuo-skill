# 大卷纲分段创建机制

> **当卷纲章节数超过30章时，必须使用分段创建机制，避免因token限制导致生成不完整或质量下降。**

## 触发条件

| 卷纲章节数 | 创建模式 | 说明 |
|-----------|---------|------|
| ≤30章 | 一次性创建 | 一次性完成全部章节卡片 |
| 31-60章 | 分2段创建 | 每段约30章 |
| 61-100章 | 分3段创建 | 每段约30-35章 |
| >100章 | 分4+段创建 | 每段不超过30章 |

## 总量守恒原则（强制）

> **执行要求（强制）**：所有分段加起来的章节数必须严格等于该卷的总章节数，不得多一章也不得少一章。
>
> - 分段只是创建策略，不改变章节总量
> - 每段创建完成后必须核对：已创建章节数 + 剩余待创建章节数 = 总章节数
> - ❌ 违反总量守恒 → 必须立即修正

## 分段规则

```
分段计算公式：
段数 = ceil(总章节数 / 30)

分段示例：
- 50章卷纲：分2段（第1-25章 / 第26-50章）
- 80章卷纲：分3段（第1-27章 / 第28-54章 / 第55-80章）
- 125章卷纲：分5段（每段25章）
```

## 分段创建流程

> **关键澄清（强制）**：分段创建的目的是避免 token 限制，但**不是**为了批量创建。
> 
> **正确理解**：
> - 将100章分成3段（第1-30章、第31-60章、第61-100章）
> - **每段仍然逐行添加**，每章一行
> - 每行添加后立即验证
> 
> **❌ 绝对禁止**：
> - ❌ "由于篇幅限制，采用更高效的方式批量创建剩余章节"
> - ❌ "将多章合并到一行中"
> - ❌ "先生成所有章节内容，再统一添加表格行"
> - ❌ 任何试图"优化"或"简化"逐行添加流程的行为

## 分段完成 ≠ 任务完成（强制）

> **完成某一段的创建不等于卷纲任务完成，必须继续创建下一段，直到所有分段全部完成。**
>
> - 分段创建是一个连续过程，中间不得停止或退出
> - 每完成一段后，必须立即开始下一段的创建
> - ❌ 完成一段后停止 → 视为任务未完成，必须继续
> - ❌ 以"已创建部分章节"为由结束 → 禁止，必须创建全部章节
> - ❌ 以"token不足""时间不够"为由结束 → 禁止，必须创建全部章节

## 总量守恒验证（强制，关键拦截点）

> **所有分段加起来的章节数必须严格等于该卷的总章节数，这是防止"只创建部分章节"的核心机制**

### 总量守恒公式

```
总章节数 = 第1段行数 + 第2段行数 + ... + 第N段行数

验证方法：
1. 记录每段实际添加的行数（通过Read工具统计）
2. 计算总和：各段行数之和
3. 对比：总和 = 总章节数？
4. ❌ 不相等 → 阻塞，找出差异并修复
```

### 总量守恒检查表（每段完成后必须填写）

| 段号 | 应添加行数 | 实际添加行数 | 检查方法 | 是否通过 |
|------|-----------|-------------|---------|---------|
| 第1段 | X行 | __行 | Read工具统计 | ☐ |
| 第2段 | X行 | __行 | Read工具统计 | ☐ |
| 第3段 | X行 | __行 | Read工具统计 | ☐ |
| ... | ... | ... | ... | ... |
| **总计** | **N行** | **__行** | **总和对比** | **☐** |

> **填写要求（强制）**：禁止仅口头声明"数量正确"，必须在表格中填写实际数字。

### 总量守恒失败处理

如果总量不守恒（总和 ≠ 总章节数）：

1. **找出差异**：
   - 执行 `Read 02-卷纲/NN-第X卷-卷名.md` 读取章节卡片表格
   - 提取所有章节编号
   - 对比预期章节列表，找出缺失的章节号

2. **补充缺失**：
   - 对每一缺失章节，按章节卡片表格格式添加行
   - 每添加一行执行Read验证
   - 补充完成后重新执行总量守恒验证

3. **验证通过后才能继续**：
   - ❌ 总量不守恒 → 阻塞，禁止进入下一步
   - ✅ 总量守恒 → 允许进入下一步

## 分段创建注意事项

1. **卷纲文件一次性创建**：保存 `02-卷纲/NN-第X卷-卷名.md`（含章节卡片表格）
2. **基础框架一次性完成**：卷名、核心任务、人物、爽点、伏笔等基础信息在步骤1一次性确定，确保各段方向一致
3. **每段必须读取上段结尾**：确保衔接信息准确，避免人物状态、时间线断裂
4. **每行≥50字符**：分段创建时仍需遵守章节卡片表格字数要求，不得因分段而降低质量
5. **表格完整性验证不可跳过**：步骤5必须逐项验证表格是否存在且行数正确
6. **进度反馈**：每完成一段向用户报告进度和本段概况
7. **创建时验证**：每添加一行立即验证内容完整，详见 [阻塞式创建规范](./阻塞式创建规范.md)
