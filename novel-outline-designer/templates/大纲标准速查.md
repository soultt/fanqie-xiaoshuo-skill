# 大纲设计标准速查

> 本文件内联 `统一标准.md` 中与大纲设计相关的关键标准，避免跨目录引用。

---

## 一、爽点间隔标准

| 爽点类型 | 间隔标准 | 说明 |
|---------|---------|------|
| 小爽点 | 3-5章 | 常规爽点，保持读者兴趣 |
| 中爽点 | 20-30章 | 阶段性爽点，推动剧情发展 |
| 大爽点 | 50-100章（每卷1-2个） | 卷级高潮，重大转折 |

---

## 二、伏笔管理标准

| 周期 | 处理方式 |
|------|---------|
| 10-30章 | 最佳回收周期 |
| 30-50章 | 需中期强化（回顾/提及） |
| >50章 | 有被遗忘风险，应尽量避免 |

- **每卷新伏笔数量**：3-5个

---

## 三、签约节点标准（番茄官方）

- **第一次申请**：2万字
- **第二次申请**：5万字
- **第三次申请**：8万字（失败则永久失去签约资格）
- **建议提交时机**：建议写到3万字再申请

## 四、章节标题唯一性标准（强制执行）

### 核心规则

> **全书范围内，所有章节标题必须唯一，禁止重复。**

### 禁止使用的标题类型

| 禁止类型 | 错误示例 | 问题 |
|---------|---------|------|
| 叙事功能词 | 卷末高潮、卷末铺垫、卷末、卷首、开篇、过渡、转折 | 不是具体事件，读者无法产生兴趣 |
| **卷末/卷首类** | **模式匹配：卷末XX、卷首XX**（XX为任意词） | **导航性词汇，破坏沉浸感** |
| 情绪描述词 | 压抑、爆发、爽点、高潮 | 太抽象，没有信息量 |
| 结构描述词 | 承上启下、衔接、收尾 | 纯功能性描述，无内容 |
| 重复标题 | 连续多章使用相同标题 | 读者无法区分章节 |
| 空泛标题 | 新的开始、新的挑战、新的敌人 | 没有具体信息 |
| **通用词标题** | **商行升级、四阶、天赋交易、修炼、突破** | **多章使用同一通用词，无法区分具体内容** |
| **规划编号词** | **伏笔1回收、伏笔2、爽点1、卡点3** | **创作规划术语+数字，暴露创作痕迹** |

### 正确的标题类型

| 正确类型 | 正确示例 | 优点 |
|---------|---------|------|
| 具体事件 | 赵家破产、商行升级、古武臣服 | 读者一眼知道本章内容 |
| 人物动作 | 林辰出手、苏晚跪求、李叔归顺 | 有画面感，引发好奇 |
| 悬念钩子 | 神秘买家现身、天道之门微启、暗中的敌人 | 制造期待感 |
| 关键物品 | 半块玉佩、商行来信、气运之眼 | 以物引事 |
| 场景转换 | 进京、酒吧开业、古武世界 | 标志格局变化 |

### 标题长度规范（强制执行）

- **标准长度**：2-6个字（黄金区间）
- **最大长度**：不超过8个字（硬性上限）
- **推荐长度**：3-5个字（最佳可读性）

### 标题唯一性规则

- 全书范围内，章节标题必须唯一
- 禁止任何位置出现完全重名标题，不限是否连续、不限是否跨卷
- 禁止使用仅替换"再""又""继续""新的"等弱区分词制造伪差异标题
- 禁止同一人物+同一动作组合反复作为标题主干
- 允许使用"上/下"表达单次事件拆分，但同一主干标题最多出现2次，且不得在其他章节再次复用
- 发现冲突时，禁止通过加序号、加副标题、临时改后缀的方式放行，必须回到卷纲层修复

### 叙事功能词标题替换示例

| 原写法 | 替换为 |
|---------|--------|
| "卷末高潮" | "赵家覆灭" / "天道之门开启" |
| "卷末铺垫" | "神秘来信" / "暗流涌动" |
| "卷末" | "最终对决" / "格局初定" |
| "卷末收尾" | "京城暗流" / "新的征途" |
| "卷首" | "初入京城" / "风起云涌" |
| "新的挑战" | "武天行的试探" / "京城豪门出手" |
| "伏笔1回收" | "玉佩显威" / "血誓应验" |
| "爽点1" | "打脸李少" / "境界突破" |

### 标题长度精简示例

| 原标题（冗长） | 精简后 | 精简方法 |
|--------------|--------|---------|
| 林辰被公司辞退的那一天 | 被辞退 | 删除人物名+时间修饰 |
| 神秘买家终于现身了 | 神秘买家 | 删除"终于""了" |
| 赵家彻底破产倒闭 | 赵家破产 | 删除"彻底""倒闭" |
| 苏晚跪求林辰原谅 | 苏晚跪求 | 删除"林辰""原谅" |
| 商行终于升级成功了 | 商行升级 | 删除"终于""成功了" |
| 古武世界向林辰臣服 | 古武臣服 | 删除"世界""向林辰" |

### 标题冲突检查表格式

`| 序号 | 标题 | 来源位置 | 冲突对象 | 问题类型 | 处理结论 |`

**问题类型固定枚举**：`通过` / `完全重复` / `主干重复` / `人物动作重复` / `伪差异` / `禁用词`

**处理结论固定枚举**：`保留` / `重写标题` / `回退卷纲层修复` / `回退章纲层修复` / `阻塞待修`

## 五、卷定位与目录排序规则

### 卷纲文件命名规范（强制执行）

```
卷纲文件命名：NN-第X卷-卷名.md  （NN为两位数字，从01开始）
```

**示例**：
```
02-卷纲/
├── 01-第一卷-觉醒篇.md
├── 02-第二卷-崛起篇.md
└── ...
```

### 卷定位规则（强制执行）

当需要根据章节号确定所属卷时：

```
步骤1：读取总纲（01-总纲/总纲.md），获取分卷规划表
步骤2：从分卷规划表中提取每卷的卷编号、卷名、章节范围
步骤3：根据目标章节号匹配所属卷：卷起始章 ≤ 目标章节号 ≤ 卷结束章
步骤4：用匹配到的卷编号构建完整路径
```

**分卷规划表格式**（总纲中必须包含）：
```
| 卷编号 | 卷名 | 章节范围 | 卷纲文件名 |
|--------|------|---------|-----------|
| 01 | 第一卷 | 第1-100章 | 01-第一卷-觉醒篇.md |
| 02 | 第二卷 | 第101-200章 | 02-第二卷-崛起篇.md |
```
