# 日更4200字符实战方案

> **说明**：本文档包含日更4200非空白字符的实战方案和策略。

---

## 一、时间安排

### 推荐方案

```
上午时段（1小时）：
├── 章纲规划（第1章） 5分钟
├── 章纲审查（第1章） 3分钟
├── 正文写作（第1章） 40分钟
├── 正文审查（第1章） 10分钟
└── 保存文件 2分钟

晚上时段（1小时）：
├── 章纲规划（第2章） 5分钟
├── 章纲审查（第2章） 3分钟
├── 正文写作（第2章） 40分钟
├── 正文审查（第2章） 10分钟
└── 保存文件 2分钟

总计：2小时/天，产出4200非空白字符
```

### 文件保存流程

```
上午：
├── 保存章纲 → 05-章纲/NN-第X卷-卷名/第XXX章-标题.md
├── 保存审查报告 → 07-审查报告/章纲审查/第XXX章-审查报告.md
├── 保存正文 → 06-正文/NN-第X卷-卷名/第XXX章-标题.md
└── 保存审查报告 → 07-审查报告/正文审查/第XXX章-审查报告.md

晚上：
└── 同上
```

## 二、批量制作方案

### 周末批量准备

```
周六上午：
├── 制作下周7章章纲 35分钟（5分钟/章）
│   └── 保存到 05-章纲/NN-第X卷-卷名/
├── 审查7章章纲 21分钟（3分钟/章）
│   └── 保存到 07-审查报告/章纲审查/
└── 修改章纲问题 20分钟

周日上午：
└── 存稿1-2章 80分钟
    ├── 写作 → 06-正文/NN-第X卷-卷名/
    └── 审查报告 → 07-审查报告/正文审查/

下周每天：
└── 只需写作+审查 50分钟/章
```

## 四、写作阶段时间分配

### 正文写作（40分钟）

```
开头钩子（10分钟）→ 约250非空白字符
剧情发展（15分钟）→ 约650非空白字符
情绪高潮（10分钟）→ 约600非空白字符
章节卡点（5分钟）→ 约400非空白字符
总计：40分钟 → 2100非空白字符

注：以上字数为正文写作目标，章纲分配基准为1900非空白字符（250+650+600+400），写作时各部分自然扩展至2100非空白字符。

注：以上字数为非空白字符数（统计方法：`len([c for c in body if not c.isspace()])`），包含汉字、标点、数字、字母等所有非空白字符。
```

### 写作技巧

- 短句短段，每段≤3行
- 对话占比≥60%
- 多用动作+心理结合
- 先完成，再完美

## 五、常见问题处理

### 问题1：卡文怎么办？

**解决方案**：
1. 看章纲，理清思路（1分钟）
2. 往前翻，找写作感觉（2分钟）
3. 跳过卡的地方，先写后面（继续写）
4. 休息10分钟，出去走走
5. 看同类作品找灵感

### 问题2：偏离章纲怎么办？

**决策流程**：
```
发现偏离
    ↓
是否影响后续？
    ├── 是 → 必须修改正文回归章纲
    │       ↓
    │   修改 06-正文/NN-第X卷-卷名/第XXX章-标题.md
│   更新 05-章纲/NN-第X卷-卷名/第XXX章-标题.md
    │
    └── 否 → 是否提升质量？
            ├── 是 → 保留，更新章纲
            │       ↓
            │   更新 05-章纲/NN-第X卷-卷名/第XXX章-标题.md
            │
            └── 否 → 删除偏离内容
```

### 问题3：质量与速度如何平衡？

**原则**：
- 初稿：先完成，再完美
- 修改：放置10分钟后再改
- 存稿：保持5-10章缓冲 → `06-正文/`
- 节奏：稳定比爆发更重要

### 问题4：如何保持长期创作？

**建议**：
1. 制定合理更新计划（日更4200非空白字符）
2. 保持存稿，避免断更 → `06-正文/`
3. 定期回顾大纲，调整方向 → `01-总纲/`、`02-卷纲/`
4. 关注读者反馈，但不盲从
5. 注意休息，避免 burnout
